# NAN 2026 게임 주제 선정 리서치

조사일: 2026-07-22

## 결론

NAN 2026 사전 과제에는 거대한 게임보다 **10초 안에 이해되는 한 가지 상호작용을 3~8분 동안 완결성 있게 확장한 브라우저 게임**이 유리하다고 판단했다.

최종 5개는 다음과 같다.

1. 한 글자 구조대
2. 소음 정원
3. 23시 59분 관제실
4. 반쪽 사진관
5. 바람의 부고

세 에이전트가 대회 신호, 성공작 패턴, 기술·일정 위험을 각각 독립 조사했고, 루트 에이전트가 유사작 검색과 반증 심사를 추가했다. `superpowers`의 발산·독립 검증 방식, `office-hours`의 “누구를 위한 어떤 순간인가” 질문, `plan-ceo-review`의 스코프·차별성·실패 모드 검토를 선정 기준에 반영했다.

## 가장 중요한 판단

게임 실행 중 AI를 호출하는 기능은 공개 규정에서 필수로 확인되지 않았다. 반면 AI 도구, 주요 프롬프트·지시, 활용 내역, 외부 에셋·오픈소스 출처를 기술 문서에 적는 것은 명시된 요구다. 따라서 런타임 AI를 억지로 넣기보다, AI 에이전트를 이용한 설계·구현·테스트 과정을 추적 가능하게 남기고 안정적인 로컬 게임 루프를 완성하는 편이 합리적이다.

이 해석은 공개 문구를 바탕으로 한 판단이며, 주최 측의 별도 확답이나 공개 심사 배점표는 아니다.
