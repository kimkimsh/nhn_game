# 기존 50개 아이디어 중복 지도

## 조사 범위

## 이번에 찾은 빈칸

기존안은 대체로 캐릭터의 능력, 화면 정보, 물체의 소유권을 바꿨다. 이번 최종안은 **현상과 표면 자체를 플레이어의 몸으로 바꾼다.**

| 최종안 | 플레이어가 직접 조작하는 것 | 조작 뒤 남는 상태 |
|---|---|---|
| 금이 간다! | 성장하는 균열 끝 | 분기와 닫힌 파편 |
| 바람난 바닥 | 바닥 아래 공기 주머니 | 부푼 지형과 누출 구멍 |
| 지우개 눈사태 | 지우개와 가루 더미 | 줄어든 세계와 이동하는 잔해 |
| 뒤집어쓴 던전 | 안팎이 바뀌는 경계 | 삼켜진 적과 토해낸 함정 |
| 지퍼 난투극 | 두 가장자리를 묶는 슬라이더 | 결합체와 축적된 반동 |

완전한 무중복을 주장하지 않는다. 다만 기존 50개와 비교했을 때 최종 5개는 조작 대상과 남는 상태를 동시에 공유하는 안이 없다.
