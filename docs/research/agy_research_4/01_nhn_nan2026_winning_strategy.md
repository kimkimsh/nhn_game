## 1. NHN NAN 2026 사전심사 핵심 성격 및 제출 요건 분석

### 1.1 핵심 과제 정의
* **과제**: AI를 활용한 게임 제작 (게임 제작 과정에 Claude, AGY 등 AI 에이전트를 풀 가동하여 1주일 내 개발).
* **중요 특징**: 
  - 게임의 **내부 소재/주제가 AI와 연관될 필요는 전혀 없음**.
  - **오프라인 싱글플레이 웹 게임** 형태.
  - 브라우저 실행(GitHub Pages 등)을 통한 **무설치 클릭 즉시 플레이** 구조.

### 1.2 사전심사위원의 심사 행동 패턴 (3-Second Visual Hook Rule)
1. **시간적 제약**: 수백 개의 심사 제출작 중 1차 검증은 **30~60초 실제 플레이 영상**을 통해 이루어집니다.
2. **3초 법칙**: 영상을 재생하자마자 **3초 이내에 시각적/메커닉적 훅(Visual Hook)**이 터지지 않으면 심사위원의 흥미는 급격히 떨어집니다.
3. **직관성 (Zero Tutorial)**: 텍스트 설명이나 긴 튜토리얼 없이도 **"버튼 누름 -> 즉각적이고 황당무계한 물리/시각 피드백"**이 화면 가득 펼쳐져야 합니다.

## 2. 인디 게임 & 바이럴 게임잼 최상위 우승작 성공 패러다임

최근 GMTK, Steam Next Fest, itch.io에서 폭발적인 인기를 끌었던 오프라인 싱글플레이 성공작의 공통 메커닉 요소를 분석한 결과, 다음 4가지 요소의 극대화가 핵심이었습니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      바이럴 게임 핵심 승리 공식 4대 요소                    │
├─────────────────────────────────────┬───────────────────────────────────────┤
│ 1. 상식의 파격적 전복 (Subversion)  │ - 체스판에 총을 들고 나타남 (Shotgun King)│
│                                     │ - 찰나의 사진 셔터 타임만 사기치기    │
├─────────────────────────────────────┼───────────────────────────────────────┤
│ 2. 극강의 래그돌 물리 (Physics)     │ - 시체 100개가 튕겨 다니며 장갑이 됨  │
│                                     │ - 가구/건물이 산산조각 나는 파괴력   │
├─────────────────────────────────────┼───────────────────────────────────────┤
│ 3. 실시간 극단적 스피드/체중 변환   │ - 300kg 스모 짓밟기 <-> 3kg 종이 비행 │
│                                     │ - 초고속 피드백 콤보                 │
├─────────────────────────────────────┼───────────────────────────────────────┤
│ 4. 타임라인 역재생 (Time Subversion)│ - 적의 시체에서 총알이 되돌아오는 역발상│
└─────────────────────────────────────┴───────────────────────────────────────┘
```

## 3. 1주일 AI 에이전트 개발 파이프라인 & 오프라인 기술 스택

### 3.1 기술 스택 (Zero-External Dependency)
- **Engine**: Phaser 3 (2D physics) 또는 Three.js + Matter.js / Cannon.js (3D WebGL physics)
- **Audio**: Web Audio API + Tone.js / Sfxr (절차적 사운드 효과 자동 생성)
- **Deployment**: GitHub Pages (웹 오프라인 싱글플레이 100% 보장)

### 3.2 7일 AI 에이전트 최적화 마일스톤
- **Day 1~2**: 물리 엔진 코어 메커닉 구축 및 조작 피드백 검증
- **Day 3~4**: 화면 진동(Screen Shake), 파티클 폭발, 슬로모션, 파괴 연출 집약 (Juiciness 200% 달성)
- **Day 5**: 아케이드 무한 스테이지 & 난이도 곡선 밸런싱
- **Day 6**: UI/UX, 하이스코어 리더보드, 사운드 폴리싱
- **Day 7**: 시크릿 브라우저 검증 및 60초 영상 녹화 연출
