## 이 리서치가 뒤집은 것

### 1. 영상 길이 — 30~60초가 맞다

저장소의 기존 문서 `agy_research/hackathon_analysis.md:24`에 "1~3분"이라고 적혀 있었다. **이 파일에는 URL이 단 하나도 없다**(`grep 'http'` 결과 0건).

공식 사이트 원문을 직접 확인한 결과 **두 곳에 중복 명시**되어 있다 — 제출물 표의 "30~60초 플레이 영상", 항목별 상세의 "30~60초 분량으로, 실제 게임 플레이 장면을 중심으로 제작해 주세요."

"1~3분"을 전제로 짜인 연출 구성과 일정은 전면 폐기해야 한다.

### 2. AI 활용의 정의 — 제작 도구다

약관 제4조 1항: "출품작 제출 시 출품작 개발에 사용한 주요 AI 도구의 명칭과 활용 방식 등을 고지하여야 한다."
AI 활용 기술 문서의 요구 항목은 **"구조 설명, 주요 프롬프트"와 "외부 에셋/오픈소스 출처" 단 2개**다.

게임 내부에 AI 런타임을 넣으라는 요구 문구는 사이트·약관 어디에도 없다. (다만 "런타임 AI 불필요"라고 명시한 문장도 없으므로, 정확한 표현은 **"명시적 요구 없음"**이다.)

### 3. 심사 배점표는 존재하지 않는다

약관 제5조 2항이 비공개 권한을 유보한다. 사이트 전체·FAQ 19문항·언론 12곳 어디에도 배점이 없다.

**배점 역산 전략은 원천적으로 불가능하다.** 00번 문서의 가중치는 전부 추정이며, 후보 간 상대 순위 도구로만 유효하다.

### 4. 퍼즐은 허용된다 — 단 조건이 붙는다

두 리포트가 정반대 결론을 냈는데, **서로 다른 것을 측정하고 있었다.**

| | 포화 리포트 | 한국 심사 리포트 |
|---|---|---|
| 측정 대상 | 20,282편 중 **발견될 확률** | 전문가가 **반드시 열어보는** 심사 결과 |
| 데이터 | 퍼즐 14/4,022 = 0.34% | BIC 2025 상위 4상 중 3개가 퍼즐 |
| 우리 상황 | **적용 안 됨** | **적용됨** |

NAN 사전심사에는 발견 가능성 문제가 구조적으로 존재하지 않는다. 심사자가 링크를 반드시 연다. 실제 금지 대상은 **퍼즐 플랫포머**(GMTK 주최자 Mark Brown이 "it's kind of a meme"이라 표현, itch.io 태그 15,633개)와 **장르 관습 재현형 퍼즐**이다.

### 5. 스택 — Phaser를 배제한 결정적 근거

npm `phaser` dist-tag `latest`가 **4.2.1**이다(2026-07-28 조회). 에이전트가 `npm install phaser`를 치면 v4가 들어온다.

그리고 Phaser 공식 문서에 이렇게 적혀 있다 — **"Math.TAU (now correctly PI × 2)"**. v3에서는 PI/2였다. **이름은 그대로인 채 값만 바뀌었다.** 예외도 콘솔 에러도 없이 각도만 조용히 틀어진다. 에이전트는 절대 못 잡고 사람이 눈으로 보고 원인부터 찾아야 한다.

반면 Canvas 2D API(`CanvasRenderingContext2D`, `requestAnimationFrame`, `AudioContext`)는 십수 년간 바뀌지 않았고 **버전 모호성이 구조적으로 0**이다.

### 6. AI 생성 에셋은 약관과 충돌한다

한국 저작권법상 AI 생성물은 저작물이 아니다(문체부·한국저작권위원회 안내서, 2025.6). 그런데 약관 제4조 2항은 **"출품작은 참가자 본인의 순수 창작물이어야 하며"**를 요구한다.

화면에 보이는 에셋을 AI로 채우면 두 조항 사이의 설명 책임이 참가자에게 떨어진다. **도형·단색·절차 생성으로 가면 이 리스크가 구조적으로 0이 된다.**

## 조사 한계

- **심사 배점표는 없다.** 00번 문서의 가중치는 전부 추정이다.
- **Google Form 실물 문항을 확인하지 못했다**(로그인 필요, HTTP 401). PDF 페이지 수·용량 제약, 포트폴리오 필수 여부가 미확인이다. 폼 URL은 01번 문서에 있다.
- 본선 제출물 "에이전트 설계서·디렉팅 명세서"는 **언론 보도에만** 있고 공식 사이트에 없다.
- 빅커넥터즈 리뷰는 BIC 정식 심사위원단이 아니라 커뮤니티 리뷰단이다. 다만 BIC 공식 사이트에 게시되고 시상 근거가 되므로 한국 게임업계의 평가 어휘 표본으로는 유효하다고 판단했다.
