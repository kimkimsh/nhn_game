## 2. 기존 묶음의 공통 한계

모든 제안이 나쁘다는 뜻은 아니다. 다만 사용자가 “다 마음에 들지 않는다”고 명시했으므로 다음 성향을 반복하지 않았다.

- 퍼즐 플랫포머에 한 가지 규칙을 붙이는 구조
- 시간, 중력, 소리, 단어처럼 게임잼에서 자주 쓰이는 추상 소재
- 텍스트나 긴 설명을 읽은 뒤에야 재미가 드러나는 구조
- 관제, 대기열, 이메일처럼 정적인 인터페이스가 주 화면인 구조
- 감성적 결말이 핵심 보상이고 순간 손맛이 약한 구조
- “장르 + 특이한 배경”에 그치고 조종 대상은 그대로인 구조

## 3. 새 아이디어를 고른 빈 공간

새 최종안은 캐릭터의 능력보다 **플레이어가 직접 만지는 대상**을 바꾼다.

| 최종안 | 직접 만지는 대상 | 기존 20개와의 거리 |
|---|---|---|
| 장판 배달부 | 적 공격의 경고 영역 | 소리 파동이나 표적 반전이 아니라 적의 공격 예고 자체 |
| 검은띠 방송사고 | 화면을 가리는 검열 영역 | 단어 삭제가 아니라 화면 공간과 충돌의 삭제 |
| 데미지 반송센터 | 피해를 표시하는 숫자 | 숫자 계산이 아니라 피해 확정 전의 물리 쟁탈 |
| 그림자 압정 | 적의 그림자와 광원 | 중력 반전이 아니라 그림자-본체 구속과 탄성 |
| 진공포장 기사 | 여러 개체의 진행 중 행동 묶음 | 원소 카드 조합이 아니라 물리 상태의 동시 포장·방출 |

## 4. 중복 방지 결론

최종 5개에는 시간 이동, 중력 전환, 단어 변경, 소리 파동, 교통 관제, 대기열, 이메일 UI, 사진 접합, 원소 상성, 자동 전투를 핵심 규칙으로 쓰지 않았다. 또한 다섯 주제끼리도 같은 조종 대상을 공유하지 않는다.
