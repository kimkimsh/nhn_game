점수는 공식 배점이 아니다. 순수 재미·참신함을 우선해 만든 내부 비교 도구이며, 구현 난이도와 제작량은 점수에 넣지 않았다.

## 가장 강하게 추천하는 한 개

**장판 배달부**를 1순위로 추천한다. 빨간 경고 영역은 이미 대부분의 게이머가 “피해야 할 곳”으로 이해한다. 그 영역을 직접 잡아 적 밑으로 옮기는 장면은 설명 없이도 관습의 배반, 플레이어의 능동성, 결과의 쾌감이 한 번에 보인다. 단순한 말장난이 아니라 서로 다른 장판의 중첩과 보스 아군 피해로 시스템적 깊이도 만들 수 있다.
