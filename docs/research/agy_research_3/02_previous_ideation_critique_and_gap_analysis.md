## 1. 기존 기획안 20여 종의 핵심 문제점 분석 (Why User Rejected Them)

기존 다른 에이전트들이 도출한 아이디어들을 분석한 결과, 다음 4가지 핵심적인 매너리즘과 한계에 빠져 있었습니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    기존 기획안들의 4대 구조적 탈락 원인                 │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. [퍼즐 매너리즘] 정적이고 머리 쓰는 퍼즐 위주 -> 도파민/손맛 부족     │
│ 2. [행정/업무 심뮬레이션] 콜센터, 관제실 등 -> 플레이어가 스트레스 받음 │
│ 3. [추상적 규칙] 텍스트 설명 없이는 3초 영상에서 이해 불가능            │
│ 4. [약한 시각적 타격감] 피드백이 약해 30초 영상에서 밋밋함              │
└─────────────────────────────────────────────────────────────────────────┘
```

### 상세 유형별 분석

#### 1) 전형적인 퍼즐/플랫포머 매너리즘 (agy_ideation 1기, claude 1기)
* **해당 주제**: Chronos Echo (시간 복제), Graviton Shift (중력 반전), 받침 (한글 받침 쌓기), 칸 긋기 등.
* **문제점**: 게임잼에서 수천 번 우려먹은 흔한 퍼즐 기믹입니다. 머리를 써야 하고 움직임이 정적이어서, 30초 영상으로 볼 때 도파민 피드백이나 흥미도가 현저히 떨어집니다.

#### 2) 행정/업무 스트레스형 시뮬레이션 (agy_ideation 2기, codex 1/2기)
* **해당 주제**: Inverse Call Center (역거절 콜센터), 23시 59분 관제실, 데미지 반송센터, 장판 배달부 등.
* **문제점**: 게이머가 게임을 하는 목적은 "즐거움과 스트레스 해소"인데, 고객센터 응대, 관제실 타이머 관리, 택배/배달 등 업무를 모사한 메커닉은 플레이어를 피로하게 만듭니다.

#### 3) 난해하거나 텍스트 의존적인 추상적 메커닉 (claude 2기, codex 1/2기)
* **해당 주제**: 바람의 부고, 소음 정원, 한 글자 구조대, 검은띠 방송사고, 쥐면 뭉개진다 등.
* **문제점**: 30초 영상을 봤을 때 "지금 무슨 일이 일어나고 있는지" 직관적으로 파악되지 않으며, 긴 텍스트 설명이나 규칙 학습이 필수적입니다. 심사위원이 3초 만에 이해할 수 없습니다.

## 2. AGY Ideation 3가 반드시 갖춰야 할 5대 불변 원칙 (The 5 Golden Rules)

사용자의 요청사항: **"개발 리소스 신경 쓰지 말고 순수 재미와 참신함에 초점 맞춰줘. 엄청 재밌고 참신하고 사전심사에서 1등할 수 있는 주제여야 해."**

이에 따라 **AGY Ideation 3**의 5가지 주제는 아래 5대 원칙을 100% 충족하도록 설계합니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     AGY Ideation 3의 5대 핵심 원칙                     │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. [3초 비주얼 폭발력] 영상 재생 3초 만에 "ㅋㅋㅋ 미쳤다!" 탄성 유발   │
│ 2. [파격적 쾌감과 도파민] 쏘고, 부수고, 튕겨 나가고, 꺾이는 압도적 손맛  │
│ 3. [황당무계 엉뚱함] 상식을 완전히 깨뜨리는 유쾌한 슬랩스틱 물리 콤미디│
│ 4. [직관적 1초 학습] 설명서 없이 플레이 버튼 누르자마자 100% 이해      │
│ 5. [오프라인 싱글 완성도] 웹 브라우저 무한 재플레이 및 높은 중독성       │
└─────────────────────────────────────────────────────────────────────────┘
```
