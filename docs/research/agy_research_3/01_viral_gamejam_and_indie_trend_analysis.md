# NHN NAN 2026: 바이럴 게임잼 및 인디 트렌드 심층 분석 리포트

> **작성일**: 2026-07-30  
> **목적**: NHN NAN 2026 (NHN Game × AI Hackathon) 사전심사 1위 통과를 위한 트렌드 및 심사 메커니즘 심층 분석  
> **제작 조건**: 오프라인 웹 싱글플레이 게임, 제작 기간 1주일 (AI 에이전트 풀 가동), 순수 재미와 참신함 극대화

## 1. NHN NAN 2026 사전심사 핵심 가이드라인 및 평가 메커니즘

### 1.1 필수 제출물 요약
1. **웹 실행 빌드 (GitHub Pages)**: 별도 다운로드/설치/로그인 없이 브라우저 URL 클릭 즉시 플레이 가능 (PC .exe 불허).
2. **30~60초 실제 플레이 영상 (YouTube)**: 심사위원이 가장 먼저 접하는 1차 검증 매체. 영상 인트로 3초 이내에 메커닉과 시각적 조작의 재미가 직관적으로 전달되어야 함.
3. **게임 소개 PDF**: 목표, 조작법, 승리/패배 규칙, 핵심 재미 포인트.
4. **AI 활용 기술 PDF**: AI 에이전트(Claude 등) 프롬프트 및 도구 활용 프로세스, 에셋 출처.

### 1.2 사전심사 심사위원 행동 패턴 및 3초 법칙 (3-Second Rule)
* **심사위원의 시간 제약**: 수백 개 제출작을 심사하는 심사위원은 각 게임당 플레이 시간을 1~2분 이상 할애하기 어렵습니다.
* **3초 시각적 훅 (Visual Hook)**: 30초 영상을 재생하자마자 **"어? 이게 뭐야?! 엄청 특이하고 재밌겠는데!"** 라는 직관적 탄성이 나와야 합격선 상위 1% 진입이 가능합니다.
* **텍스트 최소화, 행동 중심 구조**: 게임 규칙을 길게 설명해야 이해되는 게임(complex rulebook)은 패배합니다. **"누르면 부서진다", "쏘면 튀어나간다", "접으면 연결된다"**처럼 직관적인 행동-반응(Action-Feedback) 중심이어야 합니다.

## 2. 바이럴 인디 게임 & 게임잼 우승작 성공 패턴 분석

최근 GMTK, Ludum Dare, Steam Next Fest, CrazyGames 등에서 폭발적인 인기를 끌거나 우승한 오프라인 싱글플레이 게임들의 핵심 메커닉 패턴을 4가지로 요약할 수 있습니다.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      바이럴 게임 핵심 승리 공식                        │
├───────────────────────────────────┬─────────────────────────────────────┤
│ 1. 황당무계한 물리학 (Physics)    │ Goat Simulator, Teardown, Gang Beasts│
│    - 예측 불가능한 래그돌/파괴    │ -> 짤방(GIF/Shorts) 생성력 극대화    │
├───────────────────────────────────┼─────────────────────────────────────┤
│ 2. 상식의 파격적 전복 (Subversion)│ Shotgun King, Baba Is You, Superhot │
│    - 체스말이 총을 든다면?        │ -> 3초 만에 뇌를 타격하는 컨셉      │
├───────────────────────────────────┼─────────────────────────────────────┤
│ 3. 도파민 연쇄 반응 (Chaining)    │ Peglin, Balatro, Katamari Damacy    │
│    - 한 번의 조작으로 수십 개 연속│ -> 시각/청각 쥬시함(Juiciness) 폭발  │
├───────────────────────────────────┼─────────────────────────────────────┤
│ 4. 극강의 타격감과 조작 손맛     │ Vampire Survivors, Broforce         │
│    - 화면 진동, 슬로모션, 파티클  │ -> 감각적 피드백의 극대화           │
└───────────────────────────────────┴─────────────────────────────────────┘
```

### 핵심 요소 1: 황당무계 물리 엔진 & 파괴의 쾌감 (Physics & Destruction)
* **예시**: *Teardown*, *Goat Simulator*, *Totally Accurate Battle Simulator*
* **특징**: 단순 목표 달성보다 **"파괴되는 과정", "래그돌 몬스터들이 사방으로 튕겨 나가는 희열"** 자체가 압도적인 재미를 제공합니다.
* **적용**: 몬스터나 장애물이 타격받을 때 유쾌하게 튕겨 나가거나 산산조각 나는 파티클 피드백 추가.

### 핵심 요소 2: 기존 장르/상식의 파격적 전복 (Subversive Twist)
* **예시**: *Shotgun King* (체스판 위에서 국왕 혼자 산 탄 총을 쏘며 판을 뒤엎음), *Superhot* (내가 움직일 때만 시간이 흐름).
* **특징**: "누구나 아는 익숙한 규칙" + "말도 안 되는 파격적 무기/능력 1개"의 결합.
* **적용**: 가구 이사, 핀볼, 자석, 종이접기, 플런저(뚫어뻥) 등 일상적 오브젝트나 고전 장르에 파격적 변형 부여.

### 핵심 요소 3: 극강의 시각/청각 쥬시함 (Visual & Auditory Juiciness)
* **예시**: *Peglin*, *Balatro*
* **특징**: 화면 셰이크(Screen Shake), 슬로모션 히트스톱(Freeze-frame), 콤보 카운트 텍스트 팝업, 8-bit 파티클 폭발, 팝핑 사운드.
* **적용**: 단 한 번의 성공적인 조작만으로도 화면 전체가 피드백으로 요동치게 설계.

## 3. 1주일 AI 에이전트 개발 맞춤형 웹 오프라인 기술 스택

### 3.1 1주일 풀가동 웹 기술 스택 (Zero-Asset Cost, Pure Code)
1. **코어 엔진**: **Phaser 3 (2D)** 또는 **Three.js (WebGL 3D physics)** + **Matter.js / Cannon.js (물리 엔진)**
   * 오프라인 브라우저 실행 100% 보장.
   * 복잡한 에셋 다운로드 없이 HTML5 Canvas / WebGL 셰이더와 코드 기반 파티클로 고품질 비주얼 구현 가능.
2. **사운드**: **Web Audio API + Tone.js + jsfxr**
   * 외부 음원 저작권 이슈 0%. 코드로 동적 절차적 사운드 효과(SFX) 및 BGM 생성.
3. **물리 반응**: Matter.js / Cannon.js 래그돌 및 충돌 처리
   * AI 에이전트가 코드로 100% 정밀 제어 가능.

### 3.2 AI 에이전트를 통한 개발 마일스톤 (7일 스코프)
* **Day 1~2**: 코어 메커닉 및 물리 충돌/조작감 완성 (Prototype loop)
* **Day 3~4**: 파티클, 화면 진동, SFX, 슬로모션 등 쥬시함(Juiciness) 집약
* **Day 5**: 스테이지/웨이브/아케이드 모드 레벨 디자인 밸런싱
* **Day 6**: UI/UX 폴리싱, 튜토리얼 팝업, 하이스코어 시스템
* **Day 7**: GitHub Pages 배포, 시크릿 모드 웹 실행 및 60초 영상 연출 녹화
