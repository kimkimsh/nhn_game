## 이번 조사에서 나온 결정적인 사실 다섯 개

### 1. GMTK 2026의 테마는 `Count Down`이었다 (붙여쓴 Countdown이 아님)

2026-07-22~26, 96시간, 제출작 **10,600편**. 띄어쓰기 때문에 "Count(백작·드라큘라)를 Down시킨다"는 말장난으로 최소 13개가 확인됐다.

**S등급 포화** (그 자체로 감점 요인):
- 화면 상단 타이머가 0이 되면 죽는다
- "Count" 말장난
- 로켓 T-마이너스 카운트다운
- 폭탄 해체 / 내가 폭탄이다
- **적을 죽이면 타이머가 늘어난다 (타이머 = 체력)**

그리고 이번 잼의 규칙 변화 하나가 우리 과제와 직접 관련된다 — **생성형 AI로 아트·오디오 제작 시 실격**(명시적 disqualification). 잼 씬의 온도를 보여주는 지표다.

### 2. 기존 리서치의 "빈칸" 6개 중 2개는 이미 점유돼 있었다

| 빈칸 | 판정 | 죽인 것 |
|---|---|---|
| 설정 메뉴 값이 곧 게임 규칙 | **점유됨** | Lozange Lab의 `Game Settings` — **상업 출시 예정작**이고 컨셉이 사실상 동일 |
| Blippo+식 실시간 편성 | **점유됨** | 편성 메커닉만 떼면 완전한 레드오션 |
| 게임 A + 게임 B = 게임 C 합성 | 부분 점유 | `game-combinator`, `Genre Pooper` |
| 규칙 발견 + 플레이 로그 반응 | 부분 점유 | `UNDEFINED: ILS`, **`NonCompliant`(2번과 6번을 한꺼번에 반증)** |
| 가설 검증 게이지를 언어에 | 부분 점유 | 잔여 슬라이스가 6개 중 가장 날카롭다 |
| 0PLAYER식 피드백 제로 | **비어 있음** | 단 "0PLAYER를 실행형으로"는 잘못된 목표 설정 |

**반증 담당 에이전트를 따로 두지 않았으면 두 개를 그대로 썼을 것이다.**

### 3. "AI로 밸런스를 수치 증명할 수 있음"과 "손에 재미가 있음"은 음의 상관을 보였다

1차 라운드 9개를 심사한 결과다. 규칙이 깔끔할수록 헤드리스 검증은 쉬운데 손이 심심했다. 이 대회에서 두 축(S1 AI 지휘 방법론 25% / 재미)이 구조적으로 충돌한다는 뜻이다.

**둘을 동시에 만족한 안이 존재하기는 한다** — 테트리스가 그렇다. 2차 라운드에 이 상관을 깨는 데 전용 렌즈를 하나 배정했다.

### 4. 전통놀이를 뒤집었다고 믿는 것이 원래 규칙일 수 있다

`옆치기`가 그렇게 죽었다. 한국민족문화대백과사전의 딱지치기 **정의문 첫 문장**:

> "종이로 만든 딱지를 땅바닥에 놓고 다른 딱지로 **그 옆을 쳐서**, 땅바닥의 딱지가 **뒤집히거나** 일정한 선 밖으로 나가면 따먹는 어린이놀이"

2차 라운드 검증관 지시에 조항을 추가했다: **"전통놀이·고전 스포츠가 소재면 원전(백과사전·규칙서)을 확인하라."**

### 5. 검증한 24개 컨셉 중 CLEAN이 0개다

전부 WOUNDED 아니면 KILLED였다. "규칙 한 줄로 설명되는 새 코어 동사"의 공간은 이미 다 훑어졌다.

**남은 선택지는 선행작이 없는 것이 아니라, 선행작을 먼저 인용하고 정면으로 싸우는 것이다.** 부정행위 시 "인재 풀 등록 제외"가 명시된 채용 선발에서, 검증 가능한 주장이 검증되어 틀리는 것이 가장 비싼 실수다. 먼저 인용하면 감점 하나로 끝나고, 오히려 "N회 찾아봤다"는 신뢰 신호가 된다.

## 조사의 한계

- **GMTK 2026 상위 순위는 확인 불가.** 투표가 진행 중이라 결과 페이지가 없다. 포화 목록은 제출작 설명문 원문 수집으로 구성했다
- `ldjam.com` 결과 페이지는 인증서 만료 + 크롤 타임아웃으로 3회 시도 모두 실패. Ludum Dare 59는 Wikipedia와 참가자 블로그 3건으로 대체
- 심사 점수는 **에이전트 심사관의 판정**이지 실제 심사 결과가 아니다. 상대 순위 도구로만 유효하다
- 심사관 일부가 100점 척도 대신 10점 척도를 써서 정규화(×10)했다. 해당 항목은 문서에 원값과 함께 표기돼 있다
- 배점표는 존재하지 않는다(약관 제5조 2항이 비공개 권한 유보). 가중치 언급은 전부 추정이다
