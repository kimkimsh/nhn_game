### 판단이 필요했던 자리

**`types.ts` 분할.** 한 파일 400줄 상한(03 §6)에 걸려 도메인별 6파일 + 배럴 1파일로 나눴다.
`types-gameplay` · `types-content` · `types-cards` · `types-feel` · `types-ui` · `types-audio`.
`config/`의 다른 파일은 여전히 `./types` 하나만 import한다.

**같은 숫자가 두 파일에 살던 자리 7곳을 식으로 묶었다.** `config/` 파일끼리의 import는
계층 규칙이 허용한다(막는 것은 `config/` 밖으로 나가는 import뿐이다). 여섯 파일이
"config끼리는 import 못 한다"는 틀린 전제로 값을 복사해 두고 있었다.

| 파일 | 무엇 |
|---|---|
| `telegraph.ts` | `SPREAD_TELL_SEC`·`SLASH_TELL_SEC` 삭제 — `difficulty.ts`가 같은 이름으로 같은 값을 이미 내보냈다 |
| `bosses/patterns.ts` | 예고 지속 시간 4개를 리터럴에서 식으로 |
| `audio.ts` | 관통·돌진 경고음 길이를 `TELEGRAPH.shapes.*.durationSec`으로 |
| `parry.ts` | `HARD_LIMITS.reflectSpeedMaxUPerSec = REFLECT.speedMaxUPerSec` |
| `reflect.ts` | `scoreRatio = SCORING.reparryRatio` |
| `ui.ts` | 유도 좌표 14곳이 걸려 있던 `PLAYFIELD` 폭·높이와 `PARRY.cooldownSec` |

값은 하나도 바뀌지 않았다. 임시 테스트로 8개 값이 옛 리터럴과 같은지 대조하고 지웠다.

**주석 언어.** 전역 규칙은 "코드 주석은 항상 영어"인데 이 프로젝트는 한국어로 쓴다.
근거는 `docs/plan/03_파일_구조.md` §4.5 — 유일한 원본 계약 문서가 한국어이고,
주석의 핵심 기능이 그 문서의 어느 절과 이어지는지 밝히는 것이라 절 제목을 번역하면 대조가 끊긴다.
기술 용어와 API 이름은 영어 그대로 둔다.
