### 판단이 필요했던 자리

**`types.ts` 분할.** 한 파일 400줄 상한(03 §6)에 걸려 도메인별 6파일 + 배럴 1파일로 나눴다.
`types-gameplay` · `types-content` · `types-cards` · `types-feel` · `types-ui` · `types-audio`.
`config/`의 다른 파일은 여전히 `./types` 하나만 import한다.

**같은 숫자가 두 파일에 살던 자리 7곳을 식으로 묶었다.** `config/` 파일끼리의 import는
계층 규칙이 허용한다(막는 것은 `config/` 밖으로 나가는 import뿐이다). 여섯 파일이
"config끼리는 import 못 한다"는 틀린 전제로 값을 복사해 두고 있었다.

| 파일 | 무엇 |
|---|---|
| `telegraph.ts` | `SPREAD_TELL_SEC`·`SLASH_TELL_SEC` 삭제 — `difficulty.ts`가 같은 이름으로 같은 값을 이미 내보냈다 |
| `bosses/patterns.ts` | 예고 지속 시간 4개를 리터럴에서 식으로 |
| `audio.ts` | 관통·돌진 경고음 길이를 `TELEGRAPH.shapes.*.durationSec`으로 |
| `parry.ts` | `HARD_LIMITS.reflectSpeedMaxUPerSec = REFLECT.speedMaxUPerSec` |
| `reflect.ts` | `scoreRatio = SCORING.reparryRatio` |
| `ui.ts` | 유도 좌표 14곳이 걸려 있던 `PLAYFIELD` 폭·높이와 `PARRY.cooldownSec` |

값은 하나도 바뀌지 않았다. 임시 테스트로 8개 값이 옛 리터럴과 같은지 대조하고 지웠다.

**주석 언어.** 전역 규칙은 "코드 주석은 항상 영어"인데 이 프로젝트는 한국어로 쓴다.
근거는 `docs/plan/03_파일_구조.md` §4.5 — 유일한 원본 계약 문서가 한국어이고,
주석의 핵심 기능이 그 문서의 어느 절과 이어지는지 밝히는 것이라 절 제목을 번역하면 대조가 끊긴다.
기술 용어와 API 이름은 영어 그대로 둔다.

### 게이트 판정 — 브라우저에서 실제로 확인했다

코드 읽기가 아니라 실측이다. Vite dev server + Playwright로 하네스를 띄워 재현했다.

| 게이트 문장 | 근거 |
|---|---|
| 키보드로 움직인다 | ArrowLeft 400ms → x 540 → 332 · ArrowUp 400ms → y 1225 → 1017 |
| Space로 패리한다 | 20초 구동에서 `parry` 이벤트 11건 |
| 등급 세 개가 거리에 따라 다르게 나온다 | GREAT 6 · GOOD 1 · NOT BAD 4 (26 / 45 / 66u 임계에서 눌러 유도) |
| 되받아친 탄이 적을 죽인다 | `reflectLaunched` 11 → `reflectHit` 11 → `enemyKilled` 8 |
| 빈 패리는 무적을 주지 않는다 | 400u 밖에서 4회 눌러 `parryWhiff`만 증가, `parry` 0건, `parryInvulnUntilSec`이 4회 내내 0 |

마지막 줄이 이 게임의 유일한 억제 장치다(§5.4). `parry.isActive`는 true가 되되 무적이 안 붙는다 —
발동과 성립이 갈라져 있다는 것이 코드에서 확인됐다.

### 판단이 필요했던 자리

**결정론 스캔이 주석까지 잡았다.** `tests/determinism.test.ts`의 D-05 소스 스캔이
`config/feel.ts`·`types-feel.ts`를 빨간불로 만들었는데, 걸린 것은 **금지 API를 쓰지 말라고 적은
주석 문장 자체**였다.

테스트를 느슨하게 하지 않았다. 근거 셋:
- `docs/plan/09_검증_전략.md` §3.6의 예시 코드가 바로 그 정규식을 소스 텍스트에 줄 단위로 건다.
  주석을 걷어내는 단계가 스펙에 없다 — 테스트는 스펙을 정확히 옮겼다
- `src/core/rng.ts`가 그 결과로 생긴 규약을 이미 명문화하고 스스로 지키고 있었다:
  "금지 API 이름을 이 파일 안에 온전한 형태로 적지 않는다"
- 02 §4.1과 12는 스캔 **범위**만 정하고 주석 예외를 두지 않는다

그래서 스캔은 그대로 두고 주석 표현을 `rng.ts`와 같은 형태로 맞췄다. 금지 의미는 그대로 남았다.

**`main.ts`의 문자열 조회를 정적 import로 바꿨다.** P0이 `import.meta.glob` + 문자열 `'bakeSprites'`
조회로 비워 둔 자리인데, 파일이 생긴 지금 그대로 두면 **typecheck가 그 호출을 전혀 검사하지 못한다** —
export 이름이 바뀌면 컴파일이 아니라 런타임에 던진다. `screens/manager.ts`는 아직 없으므로 그 한 줄만
glob으로 남겼다.

**리사이즈 콜백을 배선했다.** `sprite-bake.ts`의 `handleViewChanged()`가 해칭 패턴을 무효화하는데
`main.ts`가 그것을 안 넘기고 있었다. `createPattern`은 만든 ctx에 묶이므로, 안 넘기면 DPR 변경 뒤
해칭이 옛 축척에 묶인 채 남는다.
