### 판단이 필요했던 자리

**`types.ts` 분할.** 한 파일 400줄 상한(03 §6)에 걸려 도메인별 6파일 + 배럴 1파일로 나눴다.

계층 규칙이 허용한다(막는 것은 `config/` 밖으로 나가는 import뿐이다). 여섯 파일이
"config끼리는 import 못 한다"는 틀린 전제로 값을 복사해 두고 있었다.

|---|---|

값은 하나도 바뀌지 않았다. 임시 테스트로 8개 값이 옛 리터럴과 같은지 대조하고 지웠다.

**주석 언어.** 전역 규칙은 "코드 주석은 항상 영어"인데 이 프로젝트는 한국어로 쓴다.

### 잡은 결함

**탄환 층이 흔들림 밖으로 빠져나가고 있었다.** `drawBulletGlowPass`/`drawBulletBodyPass`가
`setTransform`으로 **절대** 변환을 세워 호출부가 걸어 둔 카메라 변위를 매 프레임 지웠다.
06 §2의 "흔들림이 1~9층을 감싼다"가 탄환 한 층에서만 깨졌고, 증상이 "흔들 때 탄만 안 미끄러진다"라
눈으로 잡기 어렵다. 두 함수에서 배율 인자를 없애고 진입 시 `getTransform()`으로 기준을 읽게 고쳤다.

**시각 회귀 하네스가 목업의 비결정성을 잡았다.** `12_parry_moment`가 같은 프레임을 두 번 띄우기만
해도 1,335px 달라지는데, 파티클을 빼면 0px이다 — 목업 `burst`의 `Math.random()`(engine.js:1927-1928)이
유일한 흔들린 층이다. D-05가 금지한 바로 그것이고, 이식판은 주입 RNG를 쓴다.
