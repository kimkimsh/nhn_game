# [주제 4] 단어 딜리션: 폰트 파괴범 (Typo Carnage)

## 1. 9단어 핵심 요약 (Core Pitch)
> **"화면 대사 글자를 총으로 쏘아 물리 규칙을 바꿔라!"**

---

## 2. 게임 개요 및 핵심 컨셉
* **장르**: 텍스트 딜리션 물리 액션 / 퍼즐 런앤건 아케이드
* **컨셉**: 이 게임에서 모든 발판, 장애물, 몬스터의 성질은 화면 위 텍스트 문장으로 결정된다. 플레이어는 단어 파괴총(Typo Blaster)을 가진 문법 파괴범이 되어, 문장 속 특정 단어나 접두사를 쏘아 파괴(Delete)함으로써 실시간으로 상식을 뒤엎는 물리 판정을 만들어내야 한다.
* **익숙한 문법**: Baba Is You의 언어 변형 메커니즘 + 2D 액션 슈팅.
* **파격적 배반**: 텍스트를 읽는 퍼즐이 아니라, **문장을 총으로 쏴서 물리 판정을 즉시 실시간 변형시키는 하이퍼 액션**!

---

## 3. 핵심 재미 요소 & 3초 비주얼 후크 (Dopamine & Hook)
1. **Visual Hook**: 거대한 거인 보스 위에 "INVINCIBLE GIANT (무적의 거인)"이라는 텍스트 띠가 붙어있음.
2. **Action Hook**: 플레이어가 'IN' 글자를 샷건으로 맞춰 날려버리는 순간, 보스가 "VINCIBLE GIANT (처치 가능한 거인)"으로 변하며 즉시 1초 만에 폭파됨!
3. **Dopamine Hook**: 벼랑 끝에 서 있는 적 군단 밑 발판 문장 "SOLID STONE BRIDGE"에서 'SOLID'를 쏘아 없애면 "STONE BRIDGE"가 모래처럼 부서지며 적들이 일제히 추락!

---

## 4. 플레이 코어 루프
1. **상황 파악**: 막힌 문이나 강력한 적, 접근 불가능한 지역 탐색.
2. **단어 파괴 (Deletion)**:
   - `LOCKED DOOR` -> 'LOCKED' 파괴 -> `DOOR` (문 열림).
   - `HEAVY BOULDER` -> 'HEAVY' 파괴 -> `BOULDER` (가벼워져 바람에 날아감).
   - `DEADLY LAVA` -> 'DEADLY' 파괴 -> `LAVA` (헤엄칠 수 있는 안전한 용암으로 변신).
3. **목표 지점 도달**: 변형된 세계를 통과하여 골인 지점 탈출.

---

## 5. 30초 영상 스크립트 구성안
* **00~05초**: 주인공 앞에 가로막힌 "SUPER HARD WALL".
* **05~15초**: 주인공이 총으로 "SUPER HARD"를 사격해 글자 조각들을 튕겨냄 -> "WALL"만 남더니 종이처럼 찢어짐.
* **15~25초**: 불 뿜는 드래곤 "FIRE DRAGON" 등판. 주인공이 'FIRE'를 날리고 주변에 'WATER' 글자 파편을 접착 -> "WATER DRAGON"으로 변해 물뿌리개가 됨.
* **25~30초**: "GRAMMAR DESTROYED - LEVEL CLEAR!" 문구와 함께 유쾌한 클리어 연출.
