# [주제 4] 단어 딜리션: 기능 명세서

## 1. 시스템 구조 및 화면 레이아웃
* **플랫폼**: Web Browser (HTML5 Canvas 2D)
* **화면 구도**: 2D 횡스크롤 액션 스테이지
  - 주인공 캐릭터 (이동, 점프, 단어 사격)
  - 스테이지 내 오브젝트 및 몬스터 머리 위에 폰트 텍스트 렌더링
  - 상단: 잔여 파괴탄 수량 및 콤보 점수

---

## 2. 주요 메커니즘 & 조작 명세
1. **마우스 / 키보드 조작**:
   - `A / D`: 좌우 이동.
   - `Spacebar`: 점프.
   - `Mouse Aim + Left Click`: 단어 딜리션 탄환 발사 (텍스트 히트박스 판정).
2. **텍스트 반응 엔진 (String-to-Physics Parser)**:
   - 텍스트 파싱 로직: 오브젝트에 연결된 String 태그에서 소멸된 단어를 제거하고 남은 단어의 속성(Attribute)을 오브젝트 물리 컴포넌트에 즉시 재할당.

---

## 3. 오디오 & 시각 효과 명세
* **SFX**: 글자가 쪼개지는 파쇄기 소리, 퐁- 퐁- 타자기 총성, 속성 변경 시 마법 샤랑 효과음.
* **VFX**: 글자 획들이 깨져서 흩어지는 폰트 파티클, 속성 전환 시 오브젝트 컬러 변환 이펙트.
