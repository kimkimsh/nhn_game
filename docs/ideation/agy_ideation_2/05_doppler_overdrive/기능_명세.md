# [주제 5] 빛보다 빠른 불협화음: 기능 명세서

## 1. 시스템 구조 및 화면 레이아웃
* **플랫폼**: Web Browser (HTML5 Canvas 2D)
* **화면 구도**: 2D Top-down 네온 레이싱 트랙
  - 제트기 기체 (마우스 커서 방향 회전 및 가속)
  - 확장되는 원형 소리 파동 파티클 (Sonic Rings)
  - 상단: 마하 계기판 (Mach Speedometer), 도플러 주파수 오실로스코프 그래프

---

## 2. 주요 메커니즘 & 조작 명세
1. **키보드 / 마우스 조작**:
   - `Mouse Movement`: 기체 조향 (Steering).
   - `W / Up`: 가속 (Thrust).
   - `Left Click`: 소닉 펄스 탄환 발사 (방출 시점 펄스 링 생성).
2. **도플러 파동 이동 물리 (Wave Physics)**:
   - 발생한 소리 링은 $v_{sound} = 300\text{px/s}$ 로 일정하게 사방 확산.
   - 플레이어 기체 속도 $v > v_{sound}$ 일 경우 후방 소리 링이 기체 전방으로 모여 충돌 판정 형성.

---

## 3. 오디오 & 시각 효과 명세
* **SFX**: Web Audio API 주파수 발신기(Oscillator) 기반 신스웨이브 BGM, 마하 진입 시 충격파 소닉붐 음향, 도플러 변조 피치 SFX.
* **VFX**: 네온 그리드 시각화, 도플러 주파수 오실로스코프 파동 링, 속도감 연출을 위한 잔상 딜레이 라인.
