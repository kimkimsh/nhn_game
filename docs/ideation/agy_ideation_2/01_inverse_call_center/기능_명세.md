# [주제 1] 역거절 딜레마: 기능 명세서

## 1. 시스템 구조 및 화면 레이아웃
* **플랫폼**: Web Browser (HTML5 Canvas 2D + Web Audio API)
* **화면 구도**: 90년대 전화 상담 시스템 UI (단일 화면 고정)
  - 상단: 나의 스트레스 게이지 (0% ~ 100%), 남아있는 진상 고객 수
  - 중앙: 현재 통화 중인 고객 카드 (얼굴 표정, 대화 텍스트, 인내심 게이지)
  - 하단: 액션 패널 (1~4번 숫자가 배치된 전화 스킬 버튼)
  - 우측: 대기 중인 전화 라인 리스트 (멀티태스킹 위험 표시)

---

## 2. 주요 메커니즘 & 조작 명세
1. **키보드 단축키 조작 (1, 2, 3, 4 키 or 마우스 클릭)**:
   - `[1] Hold Music`: 보류음 재생 (초당 인내심 -15).
   - `[2] Department Transfer`: 부서 무작위 넘기기 (50% 확률로 즉시 끊음, 50% 확률로 다른 라인으로 복귀).
   - `[3] Static Noise`: 음영지역 흉내 (고객 딜레이 유발).
   - `[4] False Promise`: 감언이설 (즉시 끊게 만들지만 다음 스테이지 난이도 상승).
2. **고객 유형 (Enemy Types)**:
   - *성급한 직장인*: 인내심이 짧음. 보류음 2초 만에 끊음 (쉬움).
   - *불도저 진상*: 보류음에 안 속음. 부서 넘기기 스킬로만 처치 가능.
   - *의심 많은 VIP (Boss)*: 스킬 사용 시 내 스트레스를 역으로 올림. 3가지 스킬 연쇄 콤보 사용 필요.

---

## 3. 오디오 & 시각 효과 명세
* **SFX**: 8-bit 합성음으로 구현된 전화 벨소리, 수화기 딸깍 끊는 소리, 엘리베이터 보류음(Muzak sound loop), 분노 폭발 찌릿 효과음.
* **VFX**: 고객 얼굴의 정수리에서 김이 모락모락 나는 파티클, 화면 전체 진동(Screen Shake), 전화가 끊어질 때 'REJECTED' 텍스트 팝업 연출.
