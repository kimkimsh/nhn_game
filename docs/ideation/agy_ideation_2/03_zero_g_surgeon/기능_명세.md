# [주제 3] 관성 수술실: 기능 명세서

## 1. 시스템 구조 및 화면 레이아웃
* **플랫폼**: Web Browser (HTML5 Canvas 2D 정밀 2D 물리 엔진)
* **화면 구도**: 무중력 우주선 수술실 내부 2D Side View
  - 의사 캐릭터 (Ragdoll / RigidBody 물리 적용)
  - 환자 캐릭터 (중앙 고정 or 와이어로 느리게 변동)
  - 상단 UI: 환자 심박수(ECG 그래프), 잔여 시간, 현재 들고 있는 수술 도구

---

## 2. 주요 메커니즘 & 조작 명세
1. **마우스 / 키보드 조작**:
   - `Mouse Aim`: 의사의 손/도구 방향 겨냥.
   - `Left Click`: 도구 사용 (사용 즉시 겨냥 반대 방향으로 추진력 Impulse 발생!).
   - `Spacebar`: 가까운 구조물 잡기/고정 (Tether).
   - `1, 2, 3, 4`: 수술 도구 교체 (주사기, 제세동기, 핀셋, 산소 스프레이).
2. **물리 반응 규칙**:
   - 도구마다 고유의 Impulse 벡터 및 회전 Torque 발생.
   - 벽면 부딪힘 시 튕김 계수(Bounciness) 0.8 적용.

---

## 3. 오디오 & 시각 효과 명세
* **SFX**: 우주선 경보음, 삐- 삐- 심박 모니터 소리, 고무 오리 소리 같은 유쾌한 쿵 소리, 제세동기 전기 쿠쿵 소리.
* **VFX**: 무중력 알약 파티클, 둥둥 떠다니는 붕대와 장기 그래픽, 충돌 시 코믹 텍스트("KABOOM!", "BONK!") 연출.
