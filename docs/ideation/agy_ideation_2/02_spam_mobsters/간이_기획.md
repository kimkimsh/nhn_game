# [주제 2] 스팸 메일함의 갱스터 (Spam Syndicate)

## 1. 9단어 핵심 요약 (Core Pitch)
> **"이메일함으로 쏟아지는 스팸을 슈팅 총알로 박살내라!"**

---

## 2. 게임 개요 및 핵심 컨셉
* **장르**: OS 메일함 인터페이스 기반 탄막 슈팅 / 덱빌딩 아케이드
* **컨셉**: 당신의 이메일 클라이언트가 악성 스팸 마피아들에게 점령당했다! 마우스 커서가 샷건/레이저 탑재 전투 커서가 되어, 실시간으로 쏟아지는 피싱 메일, 나이지리아 왕자 유산 메일, 광고 팝업 몬스터들을 격파하고 메일함을 사수해야 한다.
* **익숙한 문법**: 탄막 슈팅 (Vampire Survivors / Enter the Gungeon) + 이메일/웹 OS 브라우저 환경.
* **파격적 배반**: 이메일의 각종 기능(수신함, 스팸함, 휴지통, 바이백)이 곧 **전투 스킬과 탄환/무기 시스템**이 되는 파격적 기믹!

---

## 3. 핵심 재미 요소 & 3초 비주얼 후크 (Dopamine & Hook)
1. **Visual Hook**: 익숙한 이메일 수신함 UI 상단에서 "Re: Urgent Password Reset", "CONGRATULATIONS $1,000,000" 같은 메일 바(Bar)들이 거대한 적 기체처럼 쏟아져 내림.
2. **Action Hook**: 마우스 커서 클릭 시 픽셀 탄환이 폭발하며 메일 텍스트들이 잘려나가고, 메인 버튼 "수신 거부 (Unsubscribe)"를 누르면 화면 전체에 무지개색 핵폭발 레이저가 나가면서 메일함이 청소됨!
3. **Dopamine Hook**: 메일을 물리치면 얻는 '캐시(Cents)'로 무기 필터를 강화: "백신 자동 사격", "스팸 분류 미사일", "쿠키 차단 방패" 등 사기적인 시너지 조합 구축 가능.

---

## 4. 플레이 코어 루프
1. **메일 몬스터 웨이브**: 수신함에 이메일 몬스터들이 정해진 시간 동안 계속 수신됨.
2. **사격 및 격파**: 마우스로 커서를 조종하여 공격. 특정 메일(예: 악성 첨부파일 .exe)은 격파 시 분열하므로 우선 타격 필요.
3. **휴지통 비우기 (Bomb)**: 위기 시 게이지를 소모해 'Empty Trash'를 눌러 화면 상의 모든 스팸 적 폭파.
4. **보스전**: 100GB 용량의 거대 피싱 왕자 메일 보스 등판! 패턴 회피 후 전멸시칸 뒤 스테이지 승리.

---

## 5. 30초 영상 스크립트 구성안
* **00~05초**: 깔끔한 이메일함 UI에 갑자기 Red Alert 경보음이 울리며 50개의 스팸 메일이 화면을 뒤덮음.
* **05~15초**: 마우스 커서가 미니건으로 변신해 스팸 메일 글자들을 산산조각 내는 하이퍼 탄막 사격 연출.
* **15~25초**: 팝업창 10개가 겹치며 화면을 가리자, 플레이어가 "Shift + Delete (영구 삭제)" 필살기 발동 -> 팝업들이 화려한 파티클로 폭발.
* **25~30초**: "INBOX CLEANED - 0 SPAM REMAINING" 로고와 함께 통쾌한 쾌감 마무리.
