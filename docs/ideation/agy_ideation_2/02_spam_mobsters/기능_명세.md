# [주제 2] 스팸 메일함의 갱스터: 기능 명세서

## 1. 시스템 구조 및 화면 레이아웃
* **플랫폼**: Web Browser (HTML5 Canvas 2D)
* **화면 구도**: 이메일 소프트웨어 윈도우 UI (단일 씬)
  - 좌측 사이드바: Inbox (체력), Sent, Spam, Trash (필살기 게이지)
  - 상단 툴바: 검색창 (업그레이드 장착 슬롯), [Empty Trash] 필살기 버튼
  - 중앙 메인 필드: 적(이메일 몬스터)들이 낙하 및 진입하는 탄막 전투 구역

---

## 2. 주요 메커니즘 & 조작 명세
1. **마우스 / 키보드 조작**:
   - `Mouse Movement`: 전투 커서 조종.
   - `Left Click / Hold`: 기본 탄환 사격 (연사).
   - `Right Click`: 마킹 소멸탄 (근접 스킬).
   - `Spacebar`: Empty Trash (화면 전멸기).
2. **적 메일 객체 유형**:
   - *광고 스팸*: 직선으로 내려오는 기본 몬스터.
   - *피싱 낚시 메일*: 플레이어의 커서를 낚아채 위치를 강제로 뺏는 유도형 몬스터.
   - *바이러스 첨부파일 (.exe)*: 처치 시 4개의 유포자 파편으로 분열.
   - *랜섬웨어 보스*: 메일함 전체를 암호화 모자이크로 가리며 패턴 공격.

---

## 3. 오디오 & 시각 효과 명세
* **SFX**: 키보드 타자 소리 피드백과 샷건 타격음의 융합, 메일 수신음("유갓메일!"), 파괴 시 팝업 팝 소리.
* **VFX**: 텍스트 파시클 분해 그래픽, 메일함 모자이크 암호화 연출, 무지개 빛깔 백신 레이저 Beam 효과.
