# NHN NAN 2026 사전제출 게임 기획 5선 (AGY Ideation 2)

> **전면 개편 최종 선정 5종**  
> 선정 기준: **순수 재미 (Pure Fun)** + **압도적 참신함 (Novelty)** + **3초 시각적 폭발력 (3-Sec Hook)** + **저작권 0% 리스크**

---

## 1. 선정 배경 및 차별점

기존 `docs/ideation` 내 기획안들(1기 agy, claude, codex)은 전형적인 게임잼 퍼즐 매너리즘이나 다소 정적이고 도파민 피드백이 약한 구조였습니다.

이번 **AGY Ideation 2**에서는 심사위원이 30~60초 영상과 웹 플레이를 접하는 순간 **"미쳤다! 개재밌겠는데?!"** 라며 사전심사 1위를 주저 없이 부여할 수 있는 **압도적 액션성, 병맛 해학, 도파민 피드백, 파격적 상식 배반**을 갖춘 5가지 독창적 주제를 도출했습니다.
