# 진공포장 기사 — 간이 기능 명세

## 조작

- 이동과 짧은 회피
- 봉투 펼치기와 포획 범위 휘두르기
- 진공 압축
- 패키지 조준, 던지기, 원격 개봉

## 핵심 시스템

- 봉투 안에 들어온 적, 투사체, 환경 물체의 다중 포획
- 포획 순간의 행동 상태, 방향, 타이머 보존
- 여러 대상을 하나의 물리 패키지로 압축
- 패키지 회전과 개봉 방향에 따른 동시 방출
- 내용물 상호작용으로 발생하는 연쇄 충돌과 합성

## 포장 재료

- 돌진병: 개봉 방향으로 즉시 돌진
- 대포병: 봉인 직전 조준 방향으로 발사
- 폭탄: 남은 타이머를 이어서 폭발
- 방패병: 다른 내용물을 튕기거나 보호
- 탄성 생물: 패키지 전체를 튀게 만듦

## 위험과 보스

- 수용 한계를 넘으면 봉투가 예고 후 파열
- 날카로운 적은 포장 유지 시간을 줄임
- 보스가 패키지를 빼앗거나 개봉 위치를 바꿈
- 부위별 요구 조합이 다른 다단계 보스

## 피드백과 화면

- 투명 패키지 안에 내용물, 방향, 타이머를 그대로 표시
- 진공도와 파열 위험을 봉투 팽창과 소리로 전달
- 압축 순간의 과장된 크기 변화와 개봉 순간의 짧은 정지
- 연쇄 반응 경로와 조합 이름을 간결하게 표시

## 게임 구조

- 완전 오프라인 싱글 플레이
- 재료를 하나씩 소개한 뒤 자유 조합을 요구하는 아레나
- 최대 동시 포장 수, 최고 연쇄 반응, 창의 조합 도감 기록
- 키보드·마우스와 게임패드 지원
