# 장판 배달부 — 간이 기능 명세

## 조작

- 캐릭터 이동과 짧은 회피
- 경고 장판 잡기, 끌기, 놓기
- 장판 방향 회전과 순간 던지기
- 즉시 재시작과 보스 페이즈 재도전

## 핵심 시스템

- 경고 장판 상태: 생성 → 이동 가능 → 위치 확정 → 공격 실행
- 보스 공격과 적 사이의 완전한 아군 피해
- 장판끼리 겹칠 때 발생하는 합성·상쇄·연쇄 반응
- 끌기 속도와 장판 크기에 따른 관성 및 손맛
- 공격 유도 결과를 누적하는 콤보와 점수

## 장판 종류

- 원형 폭격: 기본형, 던지기 쉬움
- 직선 베기: 각도 조절이 핵심
- 도넛 폭발: 가운데 안전지대를 함께 운반
- 추적 장판: 플레이어와 장판이 줄다리기
- 연쇄 장판: 실행 후 다음 위치로 파동이 이어짐

## 적과 보스

- 장판을 향해 돌진하거나 피하는 일반 적
- 장판을 밀어내거나 고정하는 특수 적
- 보호 부위와 약점이 장판 패턴에 반응하는 다단계 보스
- 마지막 공격을 자기 몸에 맞혀야 끝나는 피니시 페이즈

## 피드백과 화면

- 이동 가능 시간과 확정 순간을 색, 테두리, 진동으로 구분
- 공격 예상 궤적과 장판 투척 방향 표시
- 아군 피해가 이어질수록 커지는 화면 정지, 충격파, 콤보 연출
- 색만 보지 않아도 구분되는 장판 무늬와 형태

## 게임 구조

- 완전 오프라인 싱글 플레이
- 짧은 튜토리얼 뒤 서로 다른 성격의 보스 연전
- 보스별 최고 콤보, 피격 횟수, 클리어 시간 기록
- 키보드·마우스 기준, 게임패드 대응 가능
