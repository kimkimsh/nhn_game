# 데미지 반송센터 — 간이 기능 명세

## 조작

- 이동, 회피, 슬라이딩 캐치
- 숫자 들기, 조준, 던지기
- 들고 있는 숫자로 다른 숫자 밀치기
- 빠른 재도전

## 핵심 시스템

- 공격 충돌과 실제 체력 차감을 분리하는 보류 피해
- 충돌 위치에서 체력 바까지 이동하는 물리 숫자
- 체력 바 도착, 플레이어 캐치, 적 피격에 따른 피해 소유권 이전
- 숫자 크기에 따른 무게, 속도, 넉백 차이
- 숫자끼리의 합체, 분열, 궤도 변경

## 전투 요소

- 작은 숫자를 빠르게 쏟는 연속 공격
- 느리지만 거대한 숫자를 만드는 강공격
- 숫자를 가로채거나 쳐내는 적
- 체력 바 위치를 바꾸는 보스 패턴
- 마지막 치명타를 반송해야만 끝나는 보스 피니시

## 피드백과 UI

- 보류 중인 피해와 확정된 피해를 체력 바에서 분리 표시
- 숫자의 목적지와 남은 도착 시간을 궤적으로 표시
- 캐치 직전 짧은 시간 압축과 강한 타격음
- 큰 숫자의 무게가 이동, 카메라, 바닥 균열에 반영

## 게임 구조

- 완전 오프라인 싱글 플레이
- 짧은 연습 아레나와 개성이 다른 보스 연전
- 최고 반송 피해, 연속 캐치, 고의 피격 성공률 기록
- 숫자 색뿐 아니라 형태와 테두리로 소유권 구분
