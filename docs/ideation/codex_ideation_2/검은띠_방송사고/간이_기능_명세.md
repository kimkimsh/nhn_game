# 검은띠 방송사고 — 간이 기능 명세

## 조작

- 검열 띠 드래그 이동
- 가로·세로 방향 전환
- 특정 대상을 따라가도록 잠깐 고정
- 일시 정지 없는 즉시 재시작

## 핵심 시스템

- 화면 좌표의 검열 영역과 게임 세계 충돌을 연결하는 공간 마스크
- 마스크 내부 지형, 투사체, 감지선, 신체 부위의 충돌 무효화
- 마스크가 떠난 순간 원래 상태로 복구되는 일관된 규칙
- 자동 이동하는 출연자와 예약된 적 행동
- 연속 사고와 구출을 평가하는 방송 시청률 점수

## 상호작용 대상

- 벽과 발판: 즉석 통로 또는 추락 함정 생성
- 총알과 레이저: 필요한 구간만 통과
- 적 신체: 무기, 다리, 눈 등 특정 부위 무효화
- 스위치와 감지선: 경보와 장치 작동 차단
- 화면 UI: 후반부에는 로고, 자막, 보스 체력 표시도 세계 규칙에 참여

## 스테이지 구성

- 한 화면에서 규칙을 익히는 짧은 방송 세트
- 이동 카메라와 다중 위협이 등장하는 추격 방송
- 두 화면을 동시에 관리하는 분할 방송
- 부위별로 검열해야 하는 거대 앵커 보스전

## 피드백과 접근성

- 검열 경계에 사라질 충돌의 단면을 선명하게 표시
- 복구 직전의 위험을 외곽선과 카운트 펄스로 예고
- 흑백 대비 외에도 패턴과 왜곡으로 상태 구분
- 실패 즉시 원인을 짧은 슬로 모션으로 재생

## 게임 구조

- 완전 오프라인 싱글 플레이
- 마우스 중심 조작, 터치와 게임패드 포인터 대응 가능
- 스테이지 선택, 최고 시청률, 최소 이동 횟수 기록
