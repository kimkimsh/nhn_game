# 검은띠 방송사고

> 생방송 화면의 검은 검열 띠로 가린 영역이 현실에서도 사라지는 스크린 공간 액션 퍼즐.

## 한눈에 보는 게임

- 장르: 실시간 스크린 공간 퍼즐 / 자동 진행 액션
- 플레이어 판타지: 방송을 망치면서 출연자를 구하는 사고 전문 검열 기사
- 핵심 규칙: 검은 띠가 덮은 화면 영역에서는 지형, 충돌, 공격이 존재하지 않는다.
- 승리 조건: 한 개뿐인 검열 띠를 옮겨 출연자를 탈출시키고 방송을 장악한 보스를 무너뜨린다.

## 핵심 재미

주인공과 적들은 생방송 세트에서 계속 움직이고, 플레이어는 화면 위의 검은 띠 하나를 직접 끌어다닌다. 날아오는 미사일의 중간을 가리면 그 구간만 사라져 주인공을 통과하고, 벽의 일부를 가리면 즉석 통로가 생긴다. 보스의 발목을 가려 지지점을 없애거나 레이저의 발사구만 지우는 식으로 “보이지 않으면 존재하지 않는다”를 공격과 이동 양쪽에 쓴다.

띠를 다른 곳으로 옮기면 가렸던 공간이 즉시 돌아온다. 따라서 한 위협을 지우는 동안 다른 통로가 닫히고, 영구 삭제가 아닌 빠른 우선순위 교대가 핵심 기술이 된다.

## 한 판의 흐름

1. 자동으로 움직이는 출연자와 적, 함정의 다음 행동을 읽는다.
2. 검열 띠를 이동·회전해 필요한 화면 조각만 무효화한다.
3. 사라진 충돌을 이용해 통과시키거나 적의 공격을 적에게 되돌린다.
4. 띠를 옮기는 순간 복구되는 지형과 공격까지 계산해 연쇄 사고를 만든다.
5. 보스의 여러 부위를 순서대로 가려 자기 무대에 깔리게 하면 승리한다.

## 확장되는 놀라움

- 띠 안에서 몸 일부만 사라져 균형을 잃는 거대 보스
- 검열 영역을 통과하는 동안 두 조각처럼 보이는 열차와 미사일
- 카메라 줌으로 같은 띠의 세계 속 크기가 달라지는 방송 연출
- 화면 분할 뉴스에서 한 띠를 두 패널 사이로 넘기는 스테이지
- 엔딩에서 방송 로고와 결과 UI까지 가려 게임 규칙을 무너뜨리는 피니시

## 심사 영상의 대표 장면

검은 띠가 미사일 한가운데를 가리자 탄두가 주인공을 통과한다. 띠를 보스의 다리로 옮기는 순간 미사일이 다시 나타나고, 다리를 잃은 보스가 자기 포탄에 깔린다. 화면만 봐도 “가린 곳은 없다”가 즉시 전달된다.

## 이 주제가 강한 이유

- UI 장식이던 검열 막대를 세계 편집 도구로 바꾼 시각적 훅이 강하다.
- 한 개의 띠를 어디에 둘지 계속 바꾸므로 관찰과 순발력이 동시에 필요하다.
- 같은 규칙이 이동, 방어, 공격, 보스 해체에 모두 쓰여 기능 나열 없이 깊어진다.
- 스크린샷 한 장에서도 검은 띠에 의해 잘린 세계가 궁금증을 만든다.
