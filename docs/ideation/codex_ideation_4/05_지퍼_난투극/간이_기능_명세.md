# 지퍼 난투극 — 간이 기능 명세

## 목표

두 대상의 가장자리를 지퍼로 결합해 움직임을 방해하거나 충돌시키고, 해제 반동으로 적을 제거한다.

## 조작

- 마우스 이동: 지퍼 슬라이더 이동
- 누르고 이동: 가까운 두 가장자리 자동 포착 후 잠그기
- 반대 방향으로 드래그: 지퍼 열기
- 짧게 클릭: 현재 결합을 고정하거나 해제

## 핵심 규칙

- 슬라이더는 서로 가까운 두 호환 가장자리를 자동으로 잡는다.
- 잠긴 구간은 하나의 관절성 물리체처럼 움직인다.
- 서로 다른 움직임이 클수록 결합부에 장력이 쌓인다.
- 지퍼를 열면 축적된 장력이 반동으로 방출된다.
- 장력 한도를 넘기면 지퍼가 중간에서 터진다.

## 성공과 실패

- 성공: 목표 적을 지형에 고정하거나 해제 반동으로 전장 밖에 보낸다.
- 실패: 슬라이더가 공격에 맞거나 모든 지퍼 이빨을 소모한다.

## 필수 화면 피드백

- 자동 포착될 두 가장자리의 명확한 강조
- 잠기는 톱니의 연속 애니메이션과 소리
- 장력에 따른 지퍼 색·진동과 해제 순간의 강한 반동
