# 바람난 바닥 — 간이 기능 명세

## 목표

바닥 아래 공기를 이동·팽창시켜 적을 튕기고, 누출 분사를 이용해 모든 적을 전장 밖이나 함정으로 보낸다.

## 조작

- 마우스 이동: 공기 주머니 이동
- 누르고 있기: 현재 위치에서 팽창
- 빠르게 드래그: 공기 주머니 분할
- 주머니끼리 접촉: 하나로 합치기

## 핵심 규칙

- 공기 주머니 크기가 클수록 바닥의 밀어내는 힘이 강하다.
- 가시 공격은 바닥에 영구 구멍을 남긴다.
- 구멍에서는 남은 공기량에 비례한 방향성 분사가 생긴다.
- 공기가 모두 빠지면 위험하지만, 새 공기방울을 흡수해 회복할 수 있다.

## 성공과 실패

- 성공: 스테이지의 모든 적을 제거하거나 보스를 반복해서 튕겨 약점을 노출한다.
- 실패: 공기량이 완전히 소진된다.

## 필수 화면 피드백

- 반투명 표면 아래 공기 실루엣
- 팽창 압력과 파열 직전 떨림
- 구멍별 분사 방향과 세기
