# 시선 도둑 — 간이 기능 명세

## 조작

- 마우스로 보여주는 손 조작과 소품 발동
- 키보드로 숨기는 손 또는 조수 이동
- 발각 직전 물건을 공개 위치로 옮기는 즉흥 수습
- 장면 즉시 재시작

## 핵심 시스템

- 객석 집단별 현재 주의 대상, 전환 속도, 의심도
- 아이·회의론자·경비의 개별 주의 상태
- 얼굴·손짓·소리·움직임에 대한 주의 가중치
- 관객 사이의 시선 전염
- 반복 미끼에 대한 적응
- 시선 밀도 기반 비밀 행동 진행도
- 이상 행동 발견과 지속 응시가 올리는 단일 누적 의심
- 누적 의심 한계 도달에 따른 경보와 막 실패
- 발각 물건을 공개 위치로 되돌려 마술 동작으로 재분류하는 수습 창
- 수습 시 해당 물건의 절도 진행 초기화
- 관객이 기억하는 공개 소품 상태와 실제 무대 상태 분리
- 탈출 수레의 목표 물건 충족과 공연 종료 승리 판정

## 관객 유형

- 군중형: 주변 사람을 따라봄
- 회의론자: 가장 화려한 곳의 반대편을 감시
- 아이: 빠르게 옮겨 다니지만 오래 기억하지 않음
- 왕실 경비: 금고와 왕관을 우선 감시

## 피드백

- 고개와 눈동자의 집단 파동
- 주의가 모이는 곳의 무대 조명과 소리 변화
- 숨기는 손이 위험해질수록 객석 소음이 줄어듦
- 발각 직전 해당 관객만 짧게 선명해짐
- 공연 종료 후 `관객이 본 쇼`와 `실제로 일어난 일`을 나란히 재생

## 게임 구조

- 한 명의 관객을 속이는 연습
- 여러 관객과 조수의 동시 행동
- 회의론자가 섞인 공연
- 극장 전체 절도 피날레

## 승패

- 목표 물건을 탈출 수레에 싣고 공연을 끝내면 해당 막 성공
- 이상 행동과 절도 응시로 누적 의심이 한계에 닿아 경비 종이 울리면 해당 막 재시작
- 수습은 경보를 취소하지만 발각된 물건의 절도 진행과 현재 콤보를 잃음

## 범위 밖

- 자유 대사 입력
- 실제 시선 추적 카메라
- 카드 게임
- 잠입용 전투
- 정답 소품 순서를 외우는 QTE
