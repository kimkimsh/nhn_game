# 반띵 대왕 — 간이 기능 명세

## 조작

- 대상 선택
- 드래그로 직선 절단
- 남은 조각 잡기·휘두르기·던지기
- 짧은 회피와 즉시 재시작

## 핵심 시스템

- 절단 가능한 복합 오브젝트와 내부 재료 데이터
- 절단선 기준 양쪽 면적·질량·속성값 계산
- 현재 욕망에 따른 보스의 결정론적 선택
- 잘린 조각의 모양, 충돌, 운동량, 기능 보존
- 조각 부착과 임시 무기화
- 남은 조각의 충돌로 표적 표면 레일의 재료 부위를 이동
- 삼킨 조각 내부의 지연 반응
- 피날레에서 선택한 반쪽으로 이동하는 보스 생명 핵

## 가치 기준

- 질량
- 금속 또는 보석 함량
- 온도
- 살아 있는 개체 수
- 현재 보스에게 필요한 기능

한 교전에서는 기준 하나만 활성화하고 화면에 항상 노출한다.

## 피드백

- 절단 전 양쪽 예상 가치 막대
- 보스의 눈과 손이 선택할 절반을 미리 추적
- 절단 순간 단면과 내부 재료 강조
- 선택, 강탈, 남은 조각 장착을 빠른 세 박자로 연출
- 잘못된 선택도 원인이 남도록 결과 직전 짧은 재생

## 게임 구조

- 단일 속성 절단 연습
- 움직이는 복합 물체 교전
- 플레이어가 속성 배치를 바꾸는 교전
- 보스 자기 절단 피날레

## 승패

- 남은 조각으로 교전 목표를 파괴하면 다음 대상으로 진행
- 보스가 삼킨 조각의 위험이 폭발하기 전에 플레이어가 쓰러지면 해당 교전 재시작
- 피날레에서 보스 생명 핵이 이동한 반쪽을 내부 폭발로 파괴하면 승리

## 범위 밖

- 픽셀 단위 자유 파괴 샌드박스
- 욕망을 숨기는 추리 규칙
- 일반 검술 콤보
- 아이템 제작 메뉴
- 서로 다른 절단 도구 수집
