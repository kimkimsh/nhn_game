# 심장 공기놀이 — 간이 기능 명세

## 조작

- 조준 후 심장 던지기
- 몸 이동, 대시, 방향성 타격
- 심장 캐치와 위험한 박수 캐치
- 심장 회수와 즉시 재시작

## 핵심 시스템

- 심장의 탄도, 반사, 낙하 예상 지점
- 심장 소지·공중·바닥 도주·적 소유 상태
- 소지 상태에 따른 몸의 이동·공격 전환
- 몸, 적, 지형과의 심장 연쇄 반사
- 공중 공격의 밀치기와 박동 표식 임시 저장
- 캐치 성공 시 표식의 연쇄 피해 확정
- 캐치 실패 시 표식 소멸과 약화 회수 구간
- 충돌 횟수에 따른 심장 속도와 궤적 불안정 증가

## 적 재료

- 위로 잘 뜨는 가벼운 적
- 심장을 각도대로 반사하는 방패 적
- 심장에 달라붙어 무게를 늘리는 적
- 낙하 지점을 밀어내는 바람 적
- 심장을 직접 잡으려는 보스 손

## 피드백

- 심장 전체 궤적과 다음 충돌점
- 낙하가 가까워질수록 화면 박동과 음정 상승
- 캐치 가능 영역을 손 모양으로 표시
- 임시 콤보와 확정 콤보를 형태로 구분
- 놓친 뒤에도 심장 위치를 화면 밖 화살표가 아닌 박동 파동으로 표시

## 게임 구조

- 던지기와 받기 연습
- 한 번의 반사
- 몸과 심장 교대 콤보
- 심장 탈취 보스

## 승패

- 캐치로 확정한 연쇄 피해가 교전 목표를 쓰러뜨리면 다음 구역으로 진행
- 심장을 놓치면 즉사하지 않고 표식을 잃은 약화 회수 구간으로 전환
- 약화 상태에서 몸까지 쓰러지면 해당 교전 재시작

## 범위 밖

- 음악 박자 판정
- 시간 정지
- 무기 인벤토리
- 장기 성장 트리
- 실제 생체 데이터 입력
