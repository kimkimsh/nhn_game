# [주제 5] 미러 시공간: 반대로 쏘는 마왕 (Reverse Hero: Backwards Dungeon)

> **한 줄 컨셉**: 게임이 엔딩(마왕 사망)부터 시작한다! 시간이 역방향으로 흐르며, 적의 시체에서 총알이 역으로 빨려 들어와 내 총구로 복원되고 적들이 죽었다가 살아서 철수하는 신개념 타임라인 역재생 액션 슈팅!

---

## 1. 게임 개요 & 핵심 메커닉

```
[엔딩 장면: 마왕이 산산조각 나며 쓰러진 상태로 시작!]
               │
               ▼  (시간 역재생 발동! 총탄과 혈흔이 역으로 빨려 들어옴)
[총을 쏘면 발사되는 게 아니라, 적 시체에서 총알이 되돌아와 내 무기에 충전!]
               │
               ▼  (총알을 다 빨아들이면 적이 살아나서 도망침!)
[모든 적을 '안전하게 되살려서 철수시키는' 머리 깨지는 역발상 쾌감!]
```

* **장르**: 역방향 타임라인 액션 슈팅 (Singleplayer Offline Web)
* **목표**: 적의 시체 및 사방에 흩어진 총탄의 역발사 궤적을 맞추어 총알을 수집하고 적들을 되살려 무사히 맵 밖으로 퇴근시키는 엉뚱한 임무!
* **핵심 재미**:
  - 기존의 모든 슈팅 게임 상식을 180도 뒤집은 파격적인 역재생 비주얼과 플레이 규칙.
  - 사방으로 흩어졌던 100개의 파편과 총알이 한 점(내 총구)으로 역으로 쏘아져 들어오는 경이로운 비주얼 연출.

---

## 2. 간략 기능 명세 (Feature Spec)

1. **역방향 총탄 수집 & 탄환 복원 (Reverse Recoil Shooting)**:
   - 플레이어가 마우스 클릭 시, 총알이 맵 바닥/적 시체에서 출발하여 플레이어의 총구로 슈웅~ 들어옴.
   - 적 시체가 총알을 맞아 체력이 회복되며 되살아나는 유쾌한 애니메이션.
2. **타임라인 조작 (Timeline Scrubber)**:
   - 마우스 휠로 시간을 앞으로/뒤로 살짝 감으면서 적이 맞았던 위치의 '총탄 역발사 라인'을 예측 조준.
3. **완벽한 역배치 클리어 판정**:
   - 마왕부터 시작해서 잡몹까지 모두 되살려 맵 시작점(입구)으로 안착시키면 미션 성공!

---

## 3. 3초 비주얼 훅 & 사전심사 1위 핵심 포인트
* **3초 영상 훅**: 30초 영상을 켜자마자 마왕의 산산조각 난 파편이 어벤져스처럼 역으로 합체되며 총알들이 내 총구로 빨려 들아가 적들이 "어? 나 살아났네?" 하면서 도망치는 기발하고 뇌를 강타하는 인트로!
