# [주제 2] 목숨값 경매장: 데스 아머 스왑 (Death Bid: Corpse Swapper)

> **한 줄 컨셉**: 죽을 때마다 내 시체가 바닥에 쌓인다! 3초 속전속결 리스폰 후 이전 내 시체 50개를 자석처럼 끌어당겨 시체 거인 아머로 장착 후 보스 짓밟기!

---

## 1. 게임 개요 & 핵심 메커닉

```
[보스전 돌입 -> 초고속 사망 (3초 만에 리스폰)]
               │
               ▼  (보스 룸 바닥에 쌓이는 내 물리 래그돌 시체들!)
[자석 자력 작동! 시체 10개를 끌어당겨 래그돌 아머 장착]
               │
               ▼  (몸집이 3배 커지며 체력/공격력 10배 폭증!)
[시체 거인이 되어 보스를 짓밟고 물리 파편 폭발!]
```

* **장르**: 래그돌 시체 체이닝 로그라이크 보스전 (Singleplayer Offline Web)
* **목표**: 100번 죽더라도 바닥에 남은 시체들을 합체/착용하여 압도적인 물리 거인이 되어 보스를 섬멸하기.
* **핵심 재미**:
  - 죽음이 실망이 아니라 **"새로운 아머 파츠를 적립하는 쾌감"**으로 전복.
  - 바닥에 바글거리는 50개의 내 시체가 날아와 내 몸에 찰싹 붙으며 거대 시체 로봇이 되는 압도적 visual!

---

## 2. 간략 기능 명세 (Feature Spec)

1. **초고속 사망 & 시체 누적 로직**:
   - 사망 시 로딩 없이 0.5초 만에 원점 리스폰.
   - 죽은 위치에 방어구/무기를 착용한 래그돌 시체가 그대로 보존됨 (최대 100개 동시 상주).
2. **시체 흡수 & 체중/스탯 팽창**:
   - [Spacebar] 입력 시 자력 장(Magnetic Field) 발생 -> 바닥의 시체들이 유기적으로 내 몸에 결합.
   - 시체 5개: '시체 숄더 패드' (방어력 UP)
   - 시체 20개: '시체 거인 모드' (몸집 5배, 발구르기 시 보스 기절)
3. **시체 사격 (Corpse Launcher)**:
   - 붙어있는 시체를 보스 입안에 미사일처럼 단체 투척하여 물리 폭발 유발.

---

## 3. 3초 비주얼 훅 & 사전심사 1위 핵심 포인트
* **3초 영상 훅**: 3초 만에 연속 10번 죽어서 보스 방이 시체 바닥이 되더니, 버튼 하나로 시체 50개가 날아와 거대 시체 골렘으로 합체하여 보스를 대가리 찍기로 박살 내는 미친 타격감!
