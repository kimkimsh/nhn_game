# [주제 3] 전지전능 칼로리 배틀: 돼지 던전 (Calorie Alchemist: Fat & Furious)

> **한 줄 컨셉**: 음식 와구와구 먹고 300kg 거구가 되어 몬스터 50명을 짓밟아버리고, 0.1초 만에 체중을 뿜어내 3kg 종이인형으로 바람 타고 던전을 뚫는 극단적 체중 물리 브롤러!

---

## 1. 게임 개요 & 핵심 메커닉

```
[300kg 거구 돼지 모드: 케이크/치킨 섭취!]
               │
               ▼  (몬스터/강철 문/장애물을 몸통 드롭킥으로 박살!)
[체중 뿜어내기(Fat Blast)! 0.1초 만에 3kg 종이 체형 변신]
               │
               ▼  (바람 타고 공중 비행 & 1cm 좁은 틈새 쾌속 통과!)
[던전 하이스피드 쾌속 돌파 & 체중 전환 극상 도파민!]
```

* **장르**: 실시간 체중 물리 변환 브롤러 (Singleplayer Offline Web)
* **목표**: 칼로리를 흡수/방출하여 300kg(무거운 물리 파괴)과 3kg(초고속 종이 비행) 사이를 자유자재로 넘나들며 던전을 유쾌하게 클리어하기.
* **핵심 재미**:
  - 0.1초 만에 거대 돼지에서 종이인형으로 체형이 실시간 물리 morphing 되는 시각적 경이로움.
  - 300kg 바디스프래시로 몬스터 50명이 화면 밖으로 튕겨 나가는 무자비한 손맛.

---

## 2. 간략 기능 명세 (Feature Spec)

1. **실시간 체중 스위칭 물리 엔진**:
   - **300kg 초헤비 모드**: 
     - 충돌 판정 확대, 질량 100배 증가.
     - [Down Arrow] 입력 시 '엉덩이 드롭' -> 주변 땅이 흔들리며 파티클 폭발 및 적 밀쳐내기.
   - **3kg 라이트 종이 모드**:
     - 질량 0.01배, 공기 저항 받음.
     - 환풍구 바람을 타고 공중 플라잉, 미세한 가시 밭길을 나비처럼 피하기.
2. **칼로리 체인 시스템**:
   - 던전 안의 몬스터, 총알, 심지어 나무 상자까지 냠냠 먹어서 칼로리로 전환.
   - 칼로리를 사방으로 분사하여 적들에게 '지방 폭탄' 투척 가능.

---

## 3. 3초 비주얼 훅 & 사전심사 1위 핵심 포인트
* **3초 영상 훅**: 핏자 먹고 몸집이 화면 반만 해진 돼지 기사가 몬스터 무리를 쓸어버리더니, 불꽃 뿜으며 3kg 종이인형이 되어 좁은 열쇠구멍을 슝 하고 날아 통과하는 미친 비주얼 스피드감!
