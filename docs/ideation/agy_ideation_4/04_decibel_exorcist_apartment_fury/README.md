# [주제 4] 소음 전염병: 쿵쾅이 집주인 (Decibel Exorcist: Apartment Fury)

> **한 줄 컨셉**: 아파트 층간소음 몬스터 퇴치! 바닥을 쿵! 굴르면 건물 안 모든 가구/사람이 공중 부양! 떠오른 냉장고/소파를 야구방망이 샷건으로 휘둘러 옆집 몬스터 대가리에 꽂아 넣는 극상의 건물 물리 브롤러!

---

## 1. 게임 개요 & 핵심 메커닉

```
[아파트 세입자 몬스터들의 층간소음 진동 발생]
               │
               ▼  (발구르기 Jump Stomp! 쿵!!!)
[건물 1층~5층 안의 가구, 소파, 래그돌 세입자들 공중 부양!]
               │
               ▼  (야구방망이/골프채로 공중 오브젝트 스파이크 콤보!)
[냉장고가 샷건처럼 튀어나가 몬스터 세입자를 벽에 구속!]
```

* **장르**: 층간소음 물리 딜리버리 & 오브젝트 샷건 (Singleplayer Offline Web)
* **목표**: 층간소음을 유발하는 빌런 몬스터 세입자들을 아파트 가구 물리 폭격으로 모조리 응징하기.
* **핵심 재미**:
  - 발 한 번 굴렀을 때 건물 안 모든 물리 오브젝트가 동시에 위로 붕 뜨는 시각적 스케일감.
  - 떠 있는 소파, TV, 사람을 홈런 타자로 날려 벽을 뚫고 적을 때려잡는 압도적 타격감.

---

## 2. 간략 기능 명세 (Feature Spec)

1. **건물 전체 진동 & 공중 부양 물리 (Earthquake Stomp)**:
   - 플레이어가 점프 후 착지 시 [Stomp Wave] 발동.
   - 단면도(Cross-section) 아파트 건물 내부의 모든 단단한/부드러운 물체가 0.5초간 무중력 상태로 붕뜸.
2. **오브젝트 스파이크 샷건 (Object Home-Run)**:
   - 마우스 궤적으로 야구방망이를 휘두르면, 근처에 떠 있는 오브젝트들이 타격 방향으로 초고속 발사됨.
   - 가구 종류별 특수 피드백:
     - **냉장고**: 관통 물리 대미지
     - **침대**: 적을 감싸서 벽에 고정
     - **소파**: 연속 튕김 핀볼 효과
3. **데시벨(dB) 게이지 & 건절 파괴 연출**:
   - 콤보 성공 시 데시벨 게이지 상승 -> [피크 타임] 진입 시 건물 벽면이 산산조각 나며 8-Bit 슬로모션 피드백.

---

## 3. 3초 비주얼 훅 & 사전심사 1위 핵심 포인트
* **3초 영상 훅**: 발 쿵 굴러서 아파트 한 층의 모든 침대와 냉장고가 공중에 둥둥 떠오르고, 그걸 빠따로 차례대로 쳐서 몬스터 세입자 대가리에 쏘아 넣는 미친 슬랩스틱 쾌감!
