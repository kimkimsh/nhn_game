# [기능 명세] 슬랩스틱 트랩 브롤러: 플런저 마스터 (Slapstick Trap Brawler)

> **구현 기술 스택**: HTML5 Canvas 2D / Phaser 3 + Matter.js Ragdoll Physics + Web Audio API  
> **실행 환경**: 오프라인 웹 브라우저 (GitHub Pages 싱글플레이)

---

## 1. 주요 기능 명세

### 1.1 래그돌 물리 & 플런저 로프 시스템
* **Multi-body Ragdoll Physics**: 몬스터 바디는 머리, 몸통, 팔, 다리의 5개 관절 물리 링커로 연결되어 비틀거리는 몸개그 모션 자동 생성.
* **Plunger Distance Constraint**: 뚫어뻥 흡착 시 플레이어와 몬스터 사이에 Distance Constraint 형성. 텐션 조절 및 회전 원심력 가속도 연산.

### 1.2 함정 연쇄 메커닉 (Hazard Chaining Mechanics)
* **Waffle Iron Hazard**: 몬스터 접촉 시 0.2초간 Z-scale 축소(납작해짐) 후 반발 가속도(Repulsion Vector) 부여.
* **Trampoline Hazard**: 몬스터 충돌 각도에 따라 입사각=반사각 200% 속도로 튕김 연산.

### 1.3 시각/청각 연출 (Juiciness)
* **플런저 흡착음**: 뿅- (Pop SFX), 튕김음(용-용-), 함정 타격 시 만화 스타일 과장음(Biff! Pow! 텍스트 팝업).
* **만화 이펙트 파티클**: 충돌 위치에 옐로우/오렌지 스타 파티클 + Comic Text Particle.

---

## 2. 조작 방식 & UI/UX

| 입력 방식 | 조작 행동 |
|---|---|
| **W, A, S, D** | 래그돌 플레이어 이동 |
| **마우스 이동** | 뚫어뻥 조준선 (Aiming Crosshair) |
| **마우스 좌클릭 (홀드)** | 뚫어뻥 발사 및 몬스터 회전 잡기 (Hold to Grab) |
| **마우스 좌클릭 (떼기)** | 잡은 몬스터 던지기 (Release to Launch) |

* **HUD 메인 UI**: 함정 콤보 횟수 (Combo Chain Counter x1 ~ x10), 래그돌 체력 게이지, 아케이드 타임 어택 타이머.
