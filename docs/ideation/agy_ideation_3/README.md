# NHN NAN 2026 사전제출 게임 기획 5선 (AGY Ideation 3)

> **사전심사 1위 도달 전면 개편 5대 초강력 주제**  
> **선정 기준**: **순수 재미 (Pure Fun)** + **압도적 참신함 (Novelty)** + **3초 시각적 폭발력 (3-Sec Visual Hook)** + **100% 오프라인 웹 싱글 플레이어 완벽 대응**

---

## 1. 개요 및 기획 패러다임 전환

기존 `docs/ideation` 내 20여 개의 기획안(1기/2기 agy, claude, codex)은 퍼즐 매너리즘, 행정/콜센터 스트레스 시뮬레이션, 난해한 텍스트 의존성 등의 한계가 있었습니다.

이번 **AGY Ideation 3**에서는 개발 리소스 제약을 전면 배제하고, 오직 **"순수한 재미와 타격감, 압도적 참신함, 보자마자 터지는 폭소와 도파민"**에만 100% 초점을 맞춰 사전심사 1위를 확정할 수 있는 5가지 초강력 주제를 완성했습니다.
