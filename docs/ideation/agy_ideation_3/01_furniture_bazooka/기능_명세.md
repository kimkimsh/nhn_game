# [기능 명세] 가구 로켓포: 딜리버리 데모놀리션 (Furniture Bazooka)

> **구현 기술 스택**: HTML5 Canvas 2D + Phaser 3 / Matter.js 물리 엔진 + Web Audio API (Tone.js/jsfxr)  
> **실행 환경**: 오프라인 웹 브라우저 (GitHub Pages 싱글플레이)

---

## 1. 주요 기능 명세

### 1.1 물리 엔진 & 가구 탄환 시스템 (Matter.js 기반)
* **발사체 물리 정의**: 각 가구 오브젝트는 독자적인 질량(Mass), 탄성(Restitution), 마찰력(Friction) 보유.
  * 소파: 높은 반발계수 (Restitution: 0.85)로 벽과 적 사이를 여러 번 튕김.
  * 피아노: 높은 질량 (Mass: 50.0)으로 몬스터 물리 바디를 즉시 압착시킴.
* **래그돌 파괴 피드백**: 몬스터 충돌 시 단순 체력 감소가 아닌 몬스터 세그먼트가 래그돌(Ragdoll) 상태로 변환되어 관성에 의해 물리적으로 튕겨 나감.

### 1.2 시각 효과 (Visual Juiciness & FX)
* **화면 진동 (Screen Shake)**: 피아노 착지 시 15px 진동, 소파 튕길 때 5px micro-shake.
* **파티클 시스템 (Particle Emitter)**:
  * 피아노: 음표 파티클 30개 + 8bit 건반 파편.
  * 냉장고: 흰색 얼음 조각 파티클 + 탄산음료 캔 10개 팝업.
* **슬로모션 히트스톱 (Freeze-Frame)**: 콤보 5연속 성공 시 0.15초간 게임 스케일 0.1배속 전환.

### 1.3 사운드 & 청각 피드백 (Web Audio API)
* **발사음**: 가구 묵직함에 응당하는 저음 쿵- 사운드.
* **충돌음**: 피아노음(불협화음 쿵창-), 변기 수압음(수플래시 SFX), 소파(통통 튀는 통-).

## 2. 조작 방식 & UI/UX

| 입력 방식 | 조작 행동 |
|---|---|
| **마우스 이동** | 가구 로켓포 조준선 (Crosshair) 조작 |
| **마우스 좌클릭** | 가구 발사 (기본 쿨타임 0.4초) |
| **숫자키 1~4 / 휠** | 가구 무기 교체 (1: 소파, 2: 피아노, 3: 냉장고, 4: 변기) |
| **Spacebar** | 가구 폭파 (공중에서 가구 재클릭 시 자파 충격파) |

* **HUD 메인 UI**: 현재 탄창(가구 쿨다운 링), 연계 콤보 스코어 카운터, 몬스터 웨이브 게이지.
