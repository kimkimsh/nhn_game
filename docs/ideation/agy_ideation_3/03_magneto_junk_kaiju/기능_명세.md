# [기능 명세] 마그네틱 괴수: 자력 대격돌 (Magneto Junk Kaiju)

> **구현 기술 스택**: HTML5 Canvas 2D / Three.js 2.5D + Matter.js / Cannon.js 물리 엔진 + Web Audio API  
> **실행 환경**: 오프라인 웹 브라우저 (GitHub Pages 싱글플레이)

---

## 1. 주요 기능 명세

### 1.1 자력 물리 혜성/흡착 시스템
* **자기장 물리 스프링 (Magnetic Spring Constraint)**:
  * N극(Attract) 활성화 시 맵 내 RigidBody 오브젝트에 캐릭터 방향으로 거리 반비례 가속도 힘($F = G \cdot \frac{m_1 m_2}{r^2}$) 부여.
  * 캐릭터에 도달 시 물리 스프링 링커로 묶여 360도 회전 구체 형태 레이어 구성.
* **S극(Repel) 캐논 발사체 변환**:
  * 흡착된 각 오브젝트의 스프링 해제 후 관성 가속도 Vector(x, y) 3000px/s 로 사격.
  * 자동차: 충돌 시 주황색 화염 폭발 파티클 + AOE 데미지.
  * 철근: 직선 관통(Piercing) 속성.

### 1.2 시각 연출 (Visual Juiciness)
* **자기장 전기 파티클 (Electric Arc Particle)**: 흡착 진행 중 캐릭터와 금속 물체 사이에 푸른색 자력 전기 스파크 셰이더 렌더링.
* **화면 셰이크**: 50개 오브젝트 일제 사격 시 20px 격렬한 셰이크 + 줌인 카메라 렌즈 이펙트.

## 2. 조작 방식 & UI/UX

| 입력 방식 | 조작 행동 |
|---|---|
| **W, A, S, D** | 마그네틱 괴수 이동 |
| **Spacebar (홀드)** | N극 자력 흡착 (Attract Mode - 주변 물체 당기기) |
| **마우스 좌클릭** | S극 자력 발사 (Repel Mode - 흡착물 조준사격) |
| **E 키** | 마그네틱 펄스 충격파 (주변 360도 즉시 밀쳐내기) |

* **HUD 메인 UI**: 스크랩 볼 중량 게이지 (Scrap Mass Counter: 0 ~ 5,000kg), 현재 흡착된 금속 수량, 괴수 방어막 전력.
