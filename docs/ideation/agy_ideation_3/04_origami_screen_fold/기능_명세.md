# [기능 명세] 접어서 타격: 오리가미 팩토리 (Origami Screen Fold)

> **구현 기술 스택**: HTML5 Canvas 2D + WebGL 메시 변형(Mesh Deformation) / Phaser 3 + Web Audio API  
> **실행 환경**: 오프라인 웹 브라우저 (GitHub Pages 싱글플레이)

---

## 1. 주요 기능 명세

### 1.1 WebGL 화면 메시 변형 & 접기 렌더링
* **2D Texture Flipper & Mesh Fold**:
  * 화면 캔버스를 2개의 Render Target 텍스처로 분할.
  * 접기 선(Fold Line) 기준 3D 종이 꺾임 회전 매트릭스 계산 (0도 -> 180도 접힘 메시는 0.2초 트랜지션).
* **좌표계 맵핑 (Coordinate Mapping)**:
  * 물리 바디는 접힌 스크린 상의 로컬 좌표계로 실시간 바운딩 박스 변환.
  * 접힘선 경계 통과 시 탄환 Vector 방향 계산: $V_{new} = V_{old} - 2(V_{old} \cdot N)N$.

### 1.2 시각 연출 (Visual Juiciness)
* **종이 주름 이펙트 (Paper Crease Shadow)**: 화면이 접히는 중심선에 깊은 3D 그림자 셰이더 적용.
* **접기 시 스파크**: 접히는 순간 종이 마찰 파티클과 함께 공간 왜곡 렌즈 효과.

---

## 2. 조작 방식 & UI/UX

| 입력 방식 | 조작 행동 |
|---|---|
| **W, A, S, D** | 플레이어 캐릭터 이동 |
| **마우스 드래그** | 화면 접기 축 드래그 (세로 접기 / 가로 접기) |
| **마우스 좌클릭** | 탄환 발사 |
| **Right Click / R 키** | 접힌 화면 원복 (Unfold Screen) |

* **HUD 메인 UI**: 접기 잔여 횟수(Fold Stamina), 접힘 각도 인디케이터, 공간 왜곡 미니맵.
