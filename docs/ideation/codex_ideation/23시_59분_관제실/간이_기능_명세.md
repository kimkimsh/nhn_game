# 23시 59분 관제실 — 간이 기능 명세

## 필수 기능

- 사전 제작된 노선 그래프와 곡선 경로
- 열차 스폰 시간표와 일정 속도 이동
- 클릭 가능한 분기기 4개
- 분기 상태에 따른 다음 경로 선택
- 교차로 예약 또는 충돌 판정
- 승객 탑승, 환승, 목적지 도착 상태
- 다음 10초의 열차 도착 경고
- 90초 타이머, 일시정지, 즉시 재시작
- 승객 도착 시 아파트 창문 점등과 짧은 사운드
- 종료 결과와 최고 귀가 인원 로컬 저장

## 기술 제안

- PixiJS 8 또는 Phaser 3.90 + TypeScript + Vite
- 자유 길찾기 없이 노드와 사전 계산 곡선만 사용
- 충돌은 교차로 구간 예약 방식으로 결정론적으로 처리
- 고정 시드·고정 시간표로 모든 실패를 재현 가능하게 유지

## 7일 컷

- Day 1: 노선 렌더링, 열차 이동, 웹 배포
- Day 2: 분기 전환, 충돌, 한 판 루프
- Day 3: 승객과 목적지, 90초 시간표
- Day 4: 튜토리얼과 도전 패턴 2개
- Day 5: 경고 UI, 창문 점등, 사운드
- Day 6: 시간표 밸런스, 결정론 테스트, 브라우저 QA
- Day 7: 버그 수정, 영상, 문서

## 삭제 우선순위

두 번째 도전 패턴, 최고 기록 저장, 승객별 추가 대사 순으로 제거한다. 본 게임 90초의 완결성과 경로 가독성은 유지한다.
