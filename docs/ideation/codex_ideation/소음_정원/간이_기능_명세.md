# 소음 정원 — 간이 기능 명세

## 필수 기능

- 8방향 이동과 짧은 대시
- 이동 속도에 비례하는 원형 소리 파동
- 파동과 꽃·정원사 간 충돌 판정
- 꽃의 휴면, 개화, 연쇄 개화 상태
- 정원사의 수면, 조사, 추적, 복귀 상태
- 정원사가 마지막 소리 발생 지점으로 이동하는 단순 AI
- 피격, 즉시 재시작, 체크포인트
- 모든 필수 꽃 개화 후 출구 활성화
- 음향과 동일 정보를 제공하는 시각 파동
- 음량, 음소거, 화면 흔들림 감소 옵션

## 기술 제안

- Phaser 3.90 + TypeScript + Vite
- NavMesh 없이 고정 웨이포인트와 마지막 소리 위치를 사용
- 파동은 실제 오디오 분석이 아닌 확장되는 원형 판정체
- 꽃 화음은 미리 제작된 짧은 음원 5~7개를 조합

## 7일 컷

- Day 1: 이동, 파동, 꽃 개화, 웹 배포
- Day 2: 정원사 상태 머신과 실패·재시작
- Day 3: 튜토리얼과 본 정원 1개
- Day 4: 본 정원 최대 3개, 연쇄 꽃
- Day 5: 빛, 파티클, 화음, 명확한 위험 피드백
- Day 6: 난이도 조정, 무음·저사양 QA
- Day 7: 버그 수정, 영상, 문서

## 삭제 우선순위

연쇄 꽃, 세 번째 본 정원, 결과 등급 순으로 제거한다. 파동의 이중 효과와 정원사 유인 루프는 반드시 유지한다.
