## 한 개만 고른다면

**한 글자 구조대**를 우선 추천한다. 한국어 자체가 게임 규칙이므로 정체성이 강하고, 첫 변환을 10초 안에 보여줄 수 있으며, 자유 입력을 버리고 제작된 카드만 사용하면 웹에서 안정적으로 완성할 수 있다.

단, Day 1에 `불 → 물` 변환 한 장면이 재미있고 명확하게 보이지 않으면 **23시 59분 관제실**로 전환하는 것이 안전하다. 관제실은 차별성은 상대적으로 낮지만 플레이 재미, 테스트 가능성, 영상 전달력이 가장 안정적이다.

## 모든 안에 공통으로 적용할 범위

- 브라우저에서 바로 실행되는 오프라인 싱글 플레이
- 전체 플레이 3~8분 또는 90초 런의 반복 구조
- 핵심 입력 1개, 보조 입력 최대 1개
- 한 화면 또는 수제 퍼즐 최대 4~5개
- 런타임 AI, 서버, 계정, 온라인 저장 없음
- 첫날부터 배포 URL을 만들고 매일 실제 브라우저에서 확인
- Day 2 종료 시 핵심 루프가 재미없으면 기능 추가가 아니라 후보 교체
- 마지막 2일은 콘텐츠 추가를 멈추고 피드백, QA, 영상, PDF에 사용

점수와 탈락 근거는 [후보 검증 매트릭스](../../research/codex_research/04_후보_검증_매트릭스.md)에 정리했다.
