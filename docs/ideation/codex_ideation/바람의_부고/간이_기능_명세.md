# 바람의 부고 — 간이 기능 명세

## 필수 기능

- 마우스·터치 드래그를 바람 벡터로 변환
- 입자 위치, 속도, 감쇠, 속도 상한
- 플레이어 바람과 사전 제작된 환경 바람의 합성
- 실루엣 내부·거리 기반 흡착력
- 실루엣 충족률과 유지 시간 판정
- 기억 복원, 짧은 애니메이션, 해체 전환
- 퍼즐 재시작과 이전 기억 다시 보기
- 저사양 모드에서 입자 수 축소
- 화면 흔들림 감소와 음량 조절

## 기술 제안

- Phaser 3.90 + TypeScript + Vite
- 파티클 엔진의 완전한 유체 계산 대신 독립 점 입자와 단순 힘장 사용
- 목표 실루엣은 저해상도 마스크 또는 샘플 포인트 집합
- 충족률은 전체 픽셀 비교가 아니라 목표 셀 점유율로 판정

## 7일 컷

- Day 1: 바람, 입자, 한 실루엣, 웹 배포
- Day 2: 흡착, 충족률, 성공·해체 루프
- Day 3: 기억 2개와 방해물
- Day 4: 최대 4개와 마지막 결합 퍼즐
- Day 5: 색, 트레일, 사운드, 감정 연출
- Day 6: 조작감 테스트, 입자 성능, 브라우저 QA
- Day 7: 버그 수정, 영상, 문서

## 삭제 우선순위

세 번째·네 번째 기억, 보조 방해물, 다시 보기 순으로 제거한다. 바람 조작감과 마지막 해체 장면은 유지한다.
