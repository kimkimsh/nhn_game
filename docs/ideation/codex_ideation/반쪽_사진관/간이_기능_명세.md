# 반쪽 사진관 — 간이 기능 명세

## 필수 기능

- 동일 구도의 과거·미래 장면 레이어
- 드래그 가능한 세로 경계선과 실시간 클리핑 마스크
- 경계 위치에 따른 활성 충돌 지형 계산
- 셔터 확정과 사진 모드·이동 모드 전환
- 좌우 이동, 점프 또는 단순 탑다운 이동 중 하나
- 출구 도달과 퍼즐 완료 판정
- 한 번 입력으로 사진 모드 복귀와 즉시 재시작
- 튜토리얼 오버레이와 경계 강조
- 4개 이하 수제 퍼즐 데이터

## 기술 제안

- Phaser 3.90 또는 PixiJS 8 + TypeScript + Vite
- 아트는 SVG 또는 제한 팔레트 벡터로 제작
- 픽셀 분석 없이 경계 좌표와 사전 정의된 충돌 조각으로 판정
- 장면별 조합을 생성하지 않고 동일 오브젝트의 과거·미래 상태만 교체

## 7일 컷

- Day 1: 마스크, 경계, 충돌 스파이크와 웹 배포
- Day 2: 사진·이동 모드와 완료 루프
- Day 3: 튜토리얼과 본 퍼즐 1개
- Day 4: 본 퍼즐 최대 3개와 마지막 장면
- Day 5: 전환 연출, 벡터 아트, 사운드
- Day 6: 경계 엣지 케이스와 브라우저 QA
- Day 7: 버그 수정, 영상, 문서

## 삭제 우선순위

세 번째 본 퍼즐, 캐릭터 애니메이션, 추가 서사 순으로 제거한다. 같은 방·두 시대·한 경계라는 제한은 완화하지 않는다.
