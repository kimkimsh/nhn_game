# 한 글자 구조대 — 간이 기능 명세

## 필수 기능

- 시작, 재시작, 다음 퍼즐, 종료 화면
- 마우스 드래그 또는 클릭으로 글자 카드 선택
- 허용된 글자 조합만 판정하는 수제 규칙 테이블
- 단어 변환 전후 애니메이션
- 변환 결과에 따른 오브젝트 상태 교체
- 방향키 또는 WASD 기반 구조 로봇 이동
- 구조 대상 도달 및 퍼즐 완료 판정
- 오답 카드의 짧고 명확한 피드백
- 음량 조절, 전체 음소거, 키보드 재시작

## 데이터 구조

각 퍼즐은 다음 정보만 데이터로 가진다.

- 시작 단어와 목표 단어
- 제공 카드 2~3개
- 변환 전·후 오브젝트 상태
- 플레이어, 구조 대상, 출구 위치
- 성공 조건과 1문장 힌트

## 기술 제안

- Phaser 3.90 + TypeScript + Vite
- 충돌은 단순 사각형 기반 Arcade Physics
- 한글 폰트는 재배포 가능한 라이선스를 확인하고 로컬 번들에 포함
- 퍼즐별 특수 코드를 만들지 말고 상태 전환 컴포넌트로 통일

## 7일 컷

- Day 1: 첫 변환과 웹 배포
- Day 2: 이동, 충돌, 완료 루프
- Day 3: 퍼즐 3개와 데이터 구조
- Day 4: 피날레 포함 최대 5개, 튜토리얼
- Day 5: 변환 연출, 사운드, 글자 가독성
- Day 6: 외부 플레이테스트, 브라우저 QA
- Day 7: 버그 수정, 영상, 소개서, AI 활용 문서

## 삭제 우선순위

일정이 밀리면 피날레 퍼즐, 보조 애니메이션, 추가 힌트 순으로 줄인다. 첫 변환의 명확성과 조작 안정성은 줄이지 않는다.
