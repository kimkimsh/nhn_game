# 한 글자 구조대 — 간이 기획

## 한 줄 소개

재난 현장의 표지판에서 한글 한 글자를 바꿔 `불`을 `물`로, `벽`을 `별`로 바꾸며 사람을 구조하는 짧은 환경 퍼즐.

## 플레이어 경험

플레이어는 작은 구조 로봇과 위험물 이름이 적힌 표지판을 본다. 준비된 자모 또는 음절 카드 하나를 표지판에 끌어 놓으면 단어가 바뀌고, 화면 속 대상도 즉시 새 의미로 변한다. 변환된 물체를 이용해 구조 대상까지 길을 만든다.

핵심 감정은 “내가 한글을 읽었기 때문에 세계의 해법을 발견했다”는 짧고 선명한 깨달음이다.

## 핵심 루프

1. 위험 현장과 표지판을 관찰한다.
2. 2~3개의 글자 카드 중 하나를 고른다.
3. 글자 하나를 교체한다.
4. 단어와 세계가 동시에 변하는 장면을 확인한다.
5. 구조 로봇을 출구까지 이동시킨다.

## 권장 콘텐츠

- 튜토리얼: `불 → 물`
- 응용 1: `벽 → 별`
- 응용 2: `덫 → 돛`
- 응용 3: 서로 다른 변환 중 하나만 선택
- 피날레: 앞에서 배운 두 변환을 순서대로 사용

실제 단어 쌍은 구현 전에 한국어 자연스러움과 화면 변환 가능성을 함께 검토해 확정한다.

## 기억에 남을 장면

화염이 가득한 길의 `불`에서 획 하나가 바뀌는 순간 불꽃이 거대한 물결로 무너지고, 갇힌 사람이 물길을 타고 구조 로봇 쪽으로 온다.

## 범위 밖

- 자유 한글 입력 및 사전 전체 검색
- 자연어 처리 또는 런타임 LLM
- 단어마다 전혀 다른 조작 규칙
- 5개를 넘는 수제 퍼즐
- 전투, 인벤토리, 분기 서사

## 성공 기준

- 첫 20초 안에 설명 없이 첫 변환을 성공한다.
- 모든 퍼즐이 `글자 변경 → 즉시 물리 변화 → 이동` 문법을 공유한다.
- 5분 내 완주하고 마지막 퍼즐에서 두 규칙을 결합한다.
- 30초 영상에 변환 전후 장면을 최소 3회 담을 수 있다.

## 가장 큰 위험과 중단 조건

말장난이 임의적으로 느껴지면 단어 퀴즈에 그친다. Day 1에 `불 → 물` 한 장면을 만든 뒤 5명의 테스트 중 4명이 별도 설명 없이 변화와 목적을 이해하지 못하면 이 주제를 중단한다.
