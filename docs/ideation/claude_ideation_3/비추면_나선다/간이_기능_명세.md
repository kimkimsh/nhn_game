# 비추면 나선다 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 카메라 이동 없음. 씬 전환은 타이틀 / 플레이 / 최종 화면 셋뿐이다.

```
┌──────────────────────────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓ 막 (위에서 내려온다) ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← 내려온 높이 = 잃은 게이지
│    ☖ 무대 뒤 (완전한 검정)   ☖        ▪ 상자   ☖      │
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │  ← 무대 바닥 (옅은 회색)
│░░░░░░☖░░░░░╭──────────╮░░░░░░░░░░░░░░░░☖░░░░░░░░░░░ │    실루엣은 빛 밖에서도 보인다
│░░░░░░░░░░░│   빛 원    │░░░░░░░♪ ← 가수 (빛을 피한다)  │
│░░░░☖░░░░░░╰──────────╯░░░░░░░░░░░░░░░░░░░░░☖░░░░░░░ │  커서는 그리지 않는다
│──────────────── 무대 앞 가장자리 ──────────────────── │
│  ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫ ▫   │  ← 객석 첫 줄 (완전한 검정)
└──────────────────────────────────────────────────────┘
```

전부 도형·단색·절차 생성이다. 외부 에셋 0개.

| 요소 | 어떻게 그리는가 |
|---|---|
| 빛 원 | 반지름 `LIGHT_R` 방사 그라디언트 원 1개. **밝은 원의 반지름과 판정 반지름이 같은 값이다** |
| 사람 | 세로 캡슐 + 머리 원. 포즈는 팔다리 선분 4개의 각도 조합 12종 |
| 가수 | 사람 + 마이크(짧은 선분). 빛을 받으면 밝아지지 않고 **뒷걸음질 친다** |
| 상자 옮기는 사람 / 청소부 | 사람 + 사각형 / 사람 + 긴 선분. 각성하면 들고 있던 것을 내려놓는다 |
| 객석 | 화면 하단 작은 사각형 24개. 하나만 상태를 갖는다 |
| 무대 바닥 | 옅은 회색 사다리꼴 1개. **항상 보인다 — 어두운 화면 대비책이자 스텔스 오독 방지책** |
| 막 | 화면 폭 사각형. 아래 가장자리는 Verlet 12점 사슬 |
| 커서 | **그리지 않는다.** 빛 원이 커서보다 늦게 오는 것이 눈에 보여야 한다 |

**HUD 없음.** 점수도 타이머 숫자도 배우 수 표시도 없다. 남은 게이지는 막이 내려온 높이이고, 배우 수는 화면의 사람을 세면 된다. 무음으로 이해 가능해야 한다는 제약이 HUD를 지운다.

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 빛 원의 목표 위치. **이것이 전부다** |
| 배우 위 `BOW_HOLD` 체류 → 반대 방향 플릭 | 인사시키기. 그 배우가 인사하고 앉는다 |
| 커서를 `FLOOR_BAND`(화면 하단 8%)에 `FLOOR_HOLD` 유지 | 조명 눕히기. 전원 엎드린다 (스테이지 6 해금) |
| 아무 키 / 클릭 | 결과 화면에서 즉시 재시작 |

**버튼이 없다.** 두 특수 동작도 커서의 체류 시간과 속도로만 판정한다. 손을 쉬게 하는 입력이 하나도 없다는 것이 설계 의도다.

## 핵심 시스템

물리 엔진 없음. 아래 7계층 전부 합쳐 120줄 안쪽이다.

```
[0] 고정 타임스텝 누산기 (1/120초)
[1] 입력층   raw 마우스 → 지수감쇠 스무딩 → 큰 호 구간 원호 보정
[2] 조명층   스무딩된 커서 → 빛 원. t3ssel8r 2차 시스템 + 배우 끌림 배율
[3] 조도층   빛 원 vs 사람 원. 체류 시간 누산. 프레임 사이 4등분 보간
[4] 사람층   결정론 FSM. 랜덤 없음
[5] 가수층   회피 걷기 + 빛 안 판정 → 게이지
[6] 막층     Verlet + 거리제약. 하강 높이만 게임에 유효
```

### [1] 입력 미화 — 지수감쇠 1줄

```
sx += (mx - sx) * (1 - Math.exp(-dt / INPUT_SMOOTH_TAU));
```

여기에 원호 보정을 얹는다. 커서 속도가 `SWEEP_MIN_SPEED`를 넘은 프레임부터 `SWEEP_ARC_MS` 동안, 스무딩된 궤적을 시작점·현재점·속도 방향으로 만든 원호로 대체한다. **미화는 반드시 물리 앞에 온다.** 없으면 손 떨림이 빛 원 가장자리에서 그대로 확대돼 의도하지 않은 각성이 계속 나온다. 억울한 각성은 웃기지 않다.

### [2] 빛 원 — 2차 시스템 4줄 + 끌림 배율

```
k1 = z / (Math.PI * f);  k2 = 1 / ((2 * Math.PI * f) ** 2);  k3 = r * z / (2 * Math.PI * f);
y += dt * yd;  yd += dt * (x + k3 * xd - y - k1 * yd) / k2;
```

**`z`를 1 근처로 높게 잡는다는 점이 다른 안과 반대다.** 조명 기구는 무겁고, 출렁이면 빛이 제자리에서 같은 사람을 두 번 깨워서 플레이어가 원인을 못 읽는다. 필요한 건 오버슛이 아니라 **지연 하나**다.

배우 끌림은 이 계층에서 `dt`에 배율을 곱해 넣는다 — `drag = Π CLING_DRAG` (빛 원 중심이 `CLING_R` 안에 든 배우마다 곱한다). 빛만 느려지고 사람·가수·막은 그대로 흐른다. 배우 밭 한가운데서는 빛이 거의 멈춘다. **느려지면 체류가 길어지고, 체류가 길어지면 근처 사람이 더 깨어난다.** 이 자기강화가 "경로가 비용"의 실체다.

### [3] 조도 — 체류 시간 누산

```
inside ? p.litTime += dt : p.litTime = Math.max(0, p.litTime - dt * LIT_DECAY);
if (p.litTime >= WAKE_LATENCY) wake(p);
```

프레임당 빛 원 이동량이 클 수 있으므로 이전 위치와 현재 위치 사이를 4등분해 검사하고 각 스텝에 `dt/4`씩 누산한다. 이 보간이 없으면 **빠른 스윕이 사람을 통째로 건너뛰어** 게임이 "빨리만 움직이면 공짜"가 된다. 판정 반지름은 `LIGHT_R` 하나뿐이다.

### [4] 사람 — 결정론 FSM

랜덤 없음. 같은 입력이면 같은 무대가 나온다.

| 상태 | 행동 |
|---|---|
| `IDLE` | 무대 일을 한다. 상자 옮기기 / 빗자루질 / 서 있기. 1.4~2.2초 주기 반복 |
| `LIT` | 빛 안. `litTime` 누산 중. **아직 아무 일도 일어나지 않는다** |
| `ACTOR` | `litTime ≥ WAKE_LATENCY`. `POSE_MS`(0.9초) 포즈 후 그 자리에 **영구 고정.** `CLING_R` 발생 |
| `READY` | 빛 원 중심이 `BOW_R` 안에 `BOW_HOLD` 연속 체류. 몸을 살짝 숙인다 |
| `BOW` | `READY` 중 플릭 성립. `BOW_MS`(1.0초) 인사 연출 |
| `SEATED` | 무대 뒤로 물러나 앉는다. `CLING` 해제. 다시 각성하지 않는다 |
| `CLIMB` | 객석 전용. `CLIMB_MS`(1.4초)에 걸쳐 무대로 기어오른 뒤 `ACTOR`가 된다 |
| `PRONE` | 조명 눕히기. `PRONE_MS`(1.2초) 엎드림 + 1.5초 `CLING` 해제. 이후 `ACTOR` 복귀 |

`ACTOR`는 스스로 `IDLE`로 돌아가지 않는다. **해제 수단은 인사시키기(영구)와 조명 눕히기(1.5초)뿐이다.**

### [5] 가수

빛 원 중심이 `SHY_R` 안에 들어오면 중심의 반대 방향으로 `SINGER_SPEED`로 걷는다. 배우나 무대 경계에 막히면 벽을 따라 미끄러진다. 그 외에는 무대를 좌우로 천천히 배회한다.

**가수는 빛에 닿아도 각성하지 않는다.** 자기 차례인 걸 이미 알고 있고, 다만 부끄러워한다. 이 예외 하나가 "유일하게 빛을 받아야 할 사람만 빛을 피한다"는 그림을 만든다.

### [6] 막 — Verlet + 거리제약 6줄

아래 가장자리에만 쓴다. 점 12개 사슬, 위쪽 끝 고정. 관성 적분 1줄 + 거리제약 3회 반복 5줄. 게임플레이에 영향 없고, 막이 흔들리며 내려오는 것이 시간 압력을 눈에 보이게 만드는 용도다.

### 히트스톱

**정지 대상은 빛 원과 그 사람 둘뿐이다.** 화면 전체를 멈추면 가수와 막이 같이 멈춰서 시간 압력이 죽는다.

| 등급 | 프레임 (60fps) | 언제 |
|---|---|---|
| 약 / 중 / 대 | 3 / 6 / 10 | 각성 / 인사 성립 / 객석 침입·전원 엎드리기 |

## 판정 규칙

| 사건 | 조건 | 결과 |
|---|---|---|
| 각성 | 사람 중심이 빛 원 안 · `litTime ≥ WAKE_LATENCY` | `IDLE` → `ACTOR`. 0.9초 포즈 후 영구 고정 + `CLING` 발생 |
| 스쳐 지나감 | 사람 중심이 빛 원 안 · `litTime < WAKE_LATENCY` | 아무 일도 없다. `litTime`이 `LIT_DECAY` 배속으로 되돌아간다 |
| 인사 준비 | 빛 원 중심이 `ACTOR`의 `BOW_R` 안에 `BOW_HOLD` 연속 체류 | `READY`. **이 0.4초 동안 가수는 어둠에 있다** |
| 인사 성립 | `READY` · 커서 속도 ≥ `FLICK_MIN_SPEED` · 방향이 그 사람 반대쪽 | 1.0초 인사 → `SEATED`. `CLING` 해제 |
| 인사 실패 | `READY` 중 빛 원 중심이 `BOW_R` 밖으로 느리게 이탈 | `ACTOR`로 복귀. 0.4초를 그냥 버렸다 |
| 빛 끌림 | 빛 원 중심이 `ACTOR`의 `CLING_R` 안 | 추종 속도 × `CLING_DRAG`. **겹치면 곱해진다** |
| 객석 침입 | 빛 원이 객석 띠를 `WAKE_LATENCY`의 2배 이상 덮음 | 관객 1명이 `CLIMB`. 판당 최대 2명 |
| 조명 눕히기 | 커서가 `FLOOR_BAND` 안에 `FLOOR_HOLD` 유지 | 무대 전원 `PRONE`. 스테이지 6 해금, 횟수 제한 없음 |
| 가수 조도 | 가수 중심이 빛 원 안 | 게이지 감소 **정지** |
| 가수 회피 | 빛 원 중심이 가수의 `SHY_R` 안 | 가수가 반대 방향으로 걷는다 |
| 어둠 | 가수 중심이 빛 원 밖 | 게이지 초당 `DIM_RATE` 감소 = 막이 그만큼 내려온다 |
| **승리** | `SONG_LEN` 경과 시점에 게이지 > 0 | 막이 정상적으로 내린다 → 다음 스테이지 |
| **패배** | 게이지 0 | 막이 조기에 내린다 → 재시작 |

**`SHY_R < LIGHT_R`이 이 명세에서 가장 중요한 한 줄이다.** 가수를 빛 한가운데 두면 도망가고, 원 가장자리에 걸쳐 두면 원의 반대편 가장자리가 다른 사람을 깨운다. **조명이 안정적으로 정지할 수 있는 위치가 규칙상 존재하지 않는다.** 손이 2분 내내 움직이는 이유가 여기 하나에 다 들어 있다.

**게이지는 회복되지 않는다.** 빛 안이면 정지, 밖이면 감소, 그게 전부다. `DIM_RATE`가 초당 12%이므로 **판당 어둠 예산은 약 8.3초로 고정된다.** 인사 한 번에 0.4초, 우회 한 번에 0.4~0.6초 — **판당 15~20회분이 예산 전부다.** 점수도 감점도 없고 자원은 이것 하나다.

배우 수 자체에는 페널티가 없다. 배우는 벌점이 아니라 마찰이다. 그래서 무대를 잔뜩 채우는 웃긴 플레이와 이기는 플레이가 정면으로 충돌하지 않는다.

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 무엇을 정하는가 |
|---|---|---|
| `LIGHT_R` | 화면폭의 11% | 빛 원 반지름. **그림과 판정이 같은 값** |
| `LIGHT_F / Z / R0` | 1.1~1.6 Hz / 0.75~0.95 / 0.0~0.3 | 추종 빠르기 / 감쇠비 / 초기 응답. **`Z`는 1 근처 — 출렁이면 같은 사람을 두 번 깨운다** |
| `INPUT_SMOOTH_TAU` | 60~90 ms | 입력 미화 강도. 너무 크면 조작이 무뎌진다 |
| `SWEEP_MIN_SPEED / ARC_MS` | 화면폭의 1.0배/초 / 140 ms | 원호 보정을 켜는 속도와 구간 길이 |
| `WAKE_LATENCY` | 0.15초 | **빛이 얼마나 머물면 오해가 시작되는가. 폐기 기준의 직접 대상** |
| `LIT_DECAY` | 2.0배 | 빛에서 벗어난 뒤 `litTime`이 되돌아가는 속도 |
| `BOW_HOLD` | 0.4초 | 인사 준비 체류. **이 값이 곧 정리 한 번의 가격** |
| `BOW_R` | `LIGHT_R`의 0.5배 | 인사 준비 판정 반경 |
| `FLICK_MIN_SPEED` | 화면폭의 1.6배/초 | 플릭으로 인정하는 커서 속도 |
| `CLING_R / DRAG` | `LIGHT_R`의 0.8배 / 0.45 | 배우가 빛을 붙잡는 반경과 배율. **겹치면 곱해진다** |
| `SHY_R` | `LIGHT_R`의 0.55배 | 가수가 도망가는 거리. **반드시 `LIGHT_R`보다 작다** |
| `SINGER_SPEED` | 화면폭의 0.18배/초 | 가수가 걷는 속도 |
| `DIM_RATE` | 게이지의 초당 12% | 어둠 예산을 8.3초로 고정하는 값 |
| `SONG_LEN` | 15~20초 | 스테이지 길이 |
| `FLOOR_HOLD` | 0.6초 | 조명 눕히기 체류 |
| `POSE / BOW / CLIMB / PRONE_MS` | 900 / 1000 / 1400 / 1200 ms | 각성 포즈 / 인사 / 객석 침입 / 전원 엎드리기. **전부 0.8초 이상** |
| `LAUGH_PERIOD` | 15~18초 | 웃음 사이클 = 스테이지 하나의 길이와 맞춘다 |

## 콘텐츠 분량

- 스테이지 **6개** + 명시적 최종 화면 (막이 내린 순간의 정지 컷)
- 1스테이지 **15~20초**, 전체 완주 **100~120초** — 1회 플레이 2분 이내
- 무한 아케이드 없음. 6판을 끝내면 확실히 끝난다
- 레벨 셀렉트 필수. 심사자가 최종 화면에 도달하지 못하면 만든 것의 절반이 평가에서 사라진다

| 스테이지 | 새로 들어오는 것 |
|---|---|
| 1 | 사람 3명. 가수는 도망가지 않는다. **빛이 스치면 무슨 일이 일어나는지만** |
| 2 | 사람 5명. `SHY_R` 활성 — 가수가 수줍어진다. 첫 인사시키기 |
| 3 | 사람 8명 밀집. **`CLING`이 처음으로 길을 막는다** |
| 4 | 객석 첫 줄 활성. 규칙이 무대 밖으로 샌다 |
| 5 | 상자 옮기는 사람 + 청소부. `IDLE` 동작 반경이 커져서 가만히 있어도 빛에 걸린다 |
| 6 | 12명. 조명 눕히기 해금. **마지막 그림이 여기서 나온다** |

## 오디오 (Web Audio 절차 생성, 외부 파일 0개)

| 사건 | 소리 |
|---|---|
| 빛 이동 | 조명 기구 모터 — 아주 작은 톱니파, 커서 속도에 비례 |
| 각성 | 짧은 상승 3음. **사람마다 시작음이 반음씩 다르다** — 몇 명이 깼는지 귀로 센다 |
| 인사 준비 (0.4초) | 저역 사인이 서서히 커진다. **0.4초의 길이를 귀로 세게 만든다** |
| 인사 성립 | 하강 2음 + 짧은 박수 (노이즈 버스트 3개) |
| 빛 끌림 | 저역 사인, 끌리는 배우 수에 비례해 두꺼워진다 |
| 객석 침입 | 대역 좁힌 노이즈 1.4초. 웅성거림 |
| 전원 엎드리기 | 저역 퍽 + **1.2초 정적** |
| 가수 노래 | 단순한 사인 멜로디. **어둠에 있으면 볼륨이 준다** |
| 막 하강 | 톱니파 글리산도 하강 |

**무음으로도 전부 이해된다.** 가수 노래 볼륨이 말하는 것은 막 높이가 이미 그리고 있고, 각성 음정이 말하는 것은 화면의 포즈가 이미 그리고 있다. 소리는 전부 화면 정보의 중복이다. 심사 자료인 30~60초 영상이 무음으로 재생될 것을 전제로 만든다.

## 승패와 흐름

```
  타이틀 ──▶ 스테이지 선택 ──▶ 플레이 ──┬──▶ 승리 ──▶ 다음 스테이지
    ▲              ▲                   │              │
    │              │                   └──▶ 패배 ──┐  │ (6판 끝)
    │              └───────────────────────────────┘  ▼
    └──────────────────────────────────────────── 최종 화면
                                            (막이 내린 순간 정지 컷)
```

- **재시작 0.5초 이내.** 패배 연출은 막이 끝까지 내려오는 것 하나뿐이고, 그 뒤 즉시 초기 배치로 돌아간다
- 최종 화면은 정지 컷 하나. **열두 명이 전부 다른 포즈로 굳어 있고, 그 사이 어둠 속에 진짜 가수 하나만 마이크를 든 채 서 있다.** 빛 원은 무대 구석 청소부 위에 얹혀 있고 그 청소부도 포즈를 잡고 있다
- **막은 최종 화면에서 끝까지 내려오지 않는다.** 화면 상단 30%에서 멈춘다. 다 내려오면 마지막 그림이 가려진다

## 검증 훅 (AI 활용 기술 문서 재료)

`window.__game`에 노출한다.

```
{ actors, seated, litPeople, singerLit, gauge, curtainY, clingCount,
  pathGraze, detourRatio, lightSpeed, elapsed, stage, seed }
```

- `pathGraze` — 직전 A→B 이동에서 `litTime`이 `WAKE_LATENCY`를 넘긴 사람 수. **폐기 기준 측정 1의 값**
- `detourRatio` — 무접촉 경로 소요 시간 / 직선 경로 소요 시간. **폐기 기준 측정 2의 값**

`scripts/path-cost-sim.ts` — 고정 시드, 고정 타임스텝 1/120초, 헤드리스. 렌더 없이 봇을 돌린다. 폐기 기준은 가수·게이지·막 없이 이 스크립트만으로 1~2일차에 판정한다.

**지배 전략 봇 3종을 붙여 "경로가 비용"이 실재하는지 수치로 증명한다.**

| 봇 | 전략 | 통과 조건 | 증명하는 것 |
|---|---|---|---|
| `DIRECT` | 항상 가수를 향해 직선. 우회 없음 | 클리어율 **< 35%** | 뚫는 것만으로는 안 된다 |
| `SAFE` | 아무도 스치지 않는 경로만 사용. 정리도 안 한다 | 클리어율 **< 35%** | 돌아가는 것만으로도 안 된다 |
| `BUDGET` | 어둠 예산 8.3초를 배분한다. 잔여 예산으로 우회와 인사시키기를 고른다 | 클리어율 **> 70%** | **읽을 수 있는 것이 있고, 읽으면 이긴다** |

둘 중 하나가 70%를 넘으면 한쪽 극단이 지배 전략이라는 뜻이고, 그때는 파라미터가 아니라 규칙을 고쳐야 한다. `SAFE`가 35%를 넘으면 `DIM_RATE`와 `CLING_DRAG`부터 의심한다 — 우회가 너무 싸다는 뜻이다.

같은 시드 · 같은 입력 로그 → 같은 무대. 영상 촬영도 입력 로그 재생으로 뽑는다. 매 테이크가 같은 곳에서 웃겨야 한다.

## 범위 밖

| 안 만드는 것 | 왜 |
|---|---|
| 빛으로 사람을 없애기·떨어뜨리기·기절시키기 | 웃음의 대상이 피해자로 읽히는 순간 감점이다. 각성한 사람은 신이 나 있고 손해는 나만 본다 |
| 스텔스·발각 게이지·시야 원뿔 | **빛이 탐지로 오독되는 순간 이 게임은 남의 것이 된다.** 규칙 차원에서 아예 없앤다 |
| 조명 색 변경 | `Enter Stage Light`가 이미 갖고 있다. 우리가 파는 것은 색이 아니라 경로다 |
| 점수·콤보·배수 | 배우 수에 감점이 걸리는 순간 웃긴 플레이가 곧 못하는 플레이가 된다 |
| 클릭·키보드·메뉴 | 입력이 늘면 손이 쉬는 순간이 생기고, 손이 쉬면 무대가 안 망가진다 |
| 래그돌·창발 물리 | "a certain percentage of the time"만 웃기다. 결정론 영상과 양립하지 않는다 |
| 카메라 이동·줌 | 한 화면 안에서 전부. 이동하면 마지막 정지 컷이 성립하지 않는다 |
| 화면을 덮는 파티클 | 어두운 화면에서 실루엣을 가리면 재미의 전부가 무효가 된다. 파티클은 빛 원 안쪽에만 |
| 사람 종류 추가, 조명 업그레이드 | 체류 0.15초와 끌림 0.45가 이 게임의 전부다. 부품을 늘리면 그게 흐려진다 |
| 세이브, 랭킹, 절차 생성, 네트워크, 3D, 외부 이미지·오디오 | 2분짜리 게임에 붙일 자리가 없다. 외부 에셋 0개 |
