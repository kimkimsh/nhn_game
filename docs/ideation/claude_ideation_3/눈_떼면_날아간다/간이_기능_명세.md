# 눈 떼면 날아간다 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 카메라 이동 없음. 씬 전환은 타이틀 / 플레이 / 최종 화면 셋뿐이다.

```
┌───────────────────────────────────────────────────────────────┐
│ 천장 조명 ▬▬ ▬▬ ▬▬ ▬▬ ▬▬  ← 한 줄씩 꺼진다 = 남은 시간          │
│ ▨    ▨     ▨     ▨      ▨      ▨     ▨    ▨     ▨    ▨        │ ← 벽면 작품
│               ╲╲  ← 고무줄 2가닥 (보는 사람 2명)                │
│         ✋─────╲╲                                    ┌─────┐  │
│         손      ▨ ← 장전 중 (제자리에서 안 움직임)     │ ▨▨  │  │
│                    ▨ ← 비행 중 (0.9초, 회전)          │ ▨▨▨ │  │ ← 반출구
│                                                      └─────┘  │
│      ◤◥          ◤◥            ◤◥           ◤◥                │ ← 시선 원뿔
│      ♟           ♟             ♟            ♟                 │ ← 관람객
│═══════════════════════════════════════════════════════════════│ ← 바닥
│ ┄┄┄┄┄┄┄┄  ← 고무줄이 늘어졌던 흔적선 (페이드 없이 남는다)         │
└───────────────────────────────────────────────────────────────┘
```

전부 도형·단색·절차 생성이다. 외부 에셋 0개.

| 요소 | 어떻게 그리는가 |
|---|---|
| 작품 / 손 | 사각형·삼각형·원 + 액자 테두리, 12종은 색과 비율만 다르다 / 원 + 손가락 선분 3개, 당기는 방향 반대로 기울어진다 |
| 고무줄 | Verlet 점 8개 사슬. 팽팽하면 직선, 풀리면 1.2초간 출렁인다. **보는 사람 수만큼 가닥이 늘어난다** |
| 관람객 | 원(머리) + 사다리꼴(몸). 팔 없음. **머리 회전각이 전부다** |
| 시선 원뿔 / 지루함 | 반투명 부채꼴(`GAZE_CONE_DEG` × `GAZE_RANGE`) / 머리 기울기 각도 0도 → `TILT_MAX`. **게이지 바 없음** |
| 반출구 / 벽 착탄 | 굵은 사각 테두리 안에 작품이 겹쳐 쌓인다 / 빗나간 작품은 벽에 45도로 꽂힌다 |
| 천장 조명 · 흔적선 | 가로 막대 6개가 한 줄씩 꺼진다 / 고무줄이 최대로 늘어났던 궤적을 바닥에 점선으로 남기고 지우지 않는다 |

**HUD 없음.** 점수 없음, 타이머 숫자 없음, 남은 작품 표시 없음. 남은 시간은 켜진 조명 수이고, 남은 작품은 벽을 세면 된다. 장전량은 고무줄 길이고, 시선 수는 가닥 수다. **무음으로 이해 가능해야 한다는 제약이 HUD를 지운다.**

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 손 위치. **이것이 전부다** |
| (자동) 부착·분리 | 반경 `GRAB_R` 안에 들어오면 붙고, 다른 작품에 닿으면 옮겨 붙는다. 떠난 작품의 장전은 **유지된 채** 남는다 |
| 아무 키 / 클릭 | 결과 화면에서 즉시 재시작 |

**버튼이 없다.** 잡기 버튼도, 조준도, 발사도 없다. 발사는 손이 아니라 **관람객의 고개**가 한다.

OS 커서는 `cursor: none`으로 숨긴다. 화면 속 손은 스무딩과 반동을 거친 별개 좌표다.

## 핵심 시스템

물리 엔진 없음. 아래 7계층 전부 합쳐 120줄 안쪽이다.

```
[0] 고정 타임스텝 누산기 (1/120초)
[1] 입력층    raw 마우스 → 지수감쇠 스무딩 → 발사 반동 임펄스
[2] 부착층    손 ↔ 최근접 작품. 버튼 없음
[3] 시선층    관람객 FSM + 고개 2차 시스템 ← 판정의 전부가 여기 있다
[4] 장전층    고무줄 벡터 = (손 − 작품) × 시선 가닥 배율. 누출·끊김
[5] 발사·비행 스크립트 0.9초 회전 비행 → 반출구 / 벽 착탄. 창발 아님
[6] 히트스톱  충돌한 두 오브젝트만
[7] 고무줄 렌더 Verlet + 거리제약
```

### [1] 입력 미화 — 지수감쇠 1줄

```
sx += (mx - sx) * (1 - Math.exp(-dt / INPUT_SMOOTH_TAU));
```

발사 프레임에 손 좌표로 반동 임펄스를 더한다. 방향은 **작품 쪽**, 크기는 장전량에 비례. 손이 앞으로 훅 튀었다가 스무딩으로 되돌아온다. ("making every janky line into a slick curved swoosh")

**미화는 반드시 물리 앞에 온다.** 고무줄에 먹이는 것은 `sx`이지 `mx`가 아니다. raw를 먹이면 손 떨림이 선 길이에 그대로 나타나 장전량이 초당 수십 번 요동친다.

**[2] 부착**은 손 반경 `GRAB_R` 안의 최근접 작품. 이미 붙어 있으면 `GRAB_R * 0.7` 안에 더 가까운 작품이 들어와야 옮겨 붙는다 — 밀집 스테이지에서 부착이 깜빡이는 것을 막는 히스테리시스다.

### [3] 시선 — 관람객 FSM

**랜덤 없음.** 관람객마다 `BORED_MS`가 고정값으로 배정된다. 같은 시드면 같은 시선 지도가 나온다.

| 상태 | 행동 |
|---|---|
| `WATCH` | 한 작품을 본다. 지루함이 `BORED_MS`에 도달할 때까지 |
| `TILT` | 회전 `TILT_TELEGRAPH_MS`(0.8초) 전부터 머리가 기울기 시작한다. **아직 시선은 붙어 있다** |
| `TURN` | 다음 작품으로 머리 회전. 2차 시스템(z<1)이라 목표 각도를 지나쳤다 돌아온다. **회전 중과 오버슛 구간에는 어느 작품도 안 본다** |
| `PULLED` | 비행 중인 작품이 있으면 `AGGRO_MS` 동안 강제로 그쪽을 본다. 우선순위 최상 |
| `NOD` | 목표 작품이 사라진 벽을 보면 4초간 끄덕인다. 시선은 빈 벽에 고정 |

다음 작품은 현재 시선 방향에서 각도가 가장 가까운 것을 고른다. 없으면 빈 벽을 보고 `NOD`로 간다. **`TURN`의 오버슛이 미세 판정을 만든다.** 고개가 목표를 지나쳐 돌아오는 사이 시선이 잠깐 벗어나므로, **회전 목적지가 원래 그 작품이었더라도 중간에 한 번 발사된다.**

### [4] 장전 — 고무줄

```
charge = clamp(len(hand - art), 0, MAX_STRETCH) * VIEWER_MULT[gazeCount]
```

- **`gazeCount == 0`이면 장전이 아니다** — 작품이 손을 `FOLLOW_TAU`로 따라온다. **1 이상이면 작품은 완전히 고정**이고 손만 멀어지며 선이 길어진다
- 손을 뗀 작품의 장전량은 초당 `LEAK_RATE`만큼 줄어든다. 0이 되면 선이 사라진다
- 길이가 `SNAP_STRETCH`를 넘으면 **끊어진다.** 작품이 제자리에서 1.0초 진동, 장전 0, 손은 반대로 크게 튕긴다 (실패 연출 0.8초 이상 규칙)

**장전 방향은 발사 방향 그대로다.** 새총이 아니다. 선이 가리키는 쪽으로 날아간다 — 무음 가독성이 이 결정의 이유다.

### [5] 발사와 비행

`gazeCount`가 1 이상에서 0으로 떨어지는 프레임에 `speed = STRETCH_TO_SPEED * (charge / MAX_STRETCH)`로 발사한다.

비행은 물리가 아니라 **스크립트**다. `FLIGHT_MS`(900ms) 고정, 얕은 포물선, `FLIGHT_SPIN`(1.5회전) 등속. 착탄점은 발사 순간에 이미 정해진다 — 속도가 반출구에 닿을 만큼이면 반출구, 아니면 그 방향의 벽이다. **0.9초는 관객이 결과를 먼저 알고 기다리는 시간이고, 즉사가 없는 이유다.**

래그돌은 "a certain percentage of the time"만 웃기고, 30초 결정론 영상은 확률에 걸 수 없다. 그리고 **작품은 관람객을 절대 맞히지 않는다** — 비행 경로가 관람객 히트박스와 겹치면 포물선 정점을 올려 머리 위로 넘긴다. 가학성 안전핀이다.

### [6] 히트스톱

60fps 기준 **약 3프레임(고무줄 끊김) / 중 6(반출구 진입) / 대 10(벽 착탄)**. 정지 대상은 **충돌한 두 오브젝트만**이다. 화면 전체를 멈추면 관람객 고개가 같이 멈춰서 "저 사람은 아무것도 모른다"는 태그가 죽는다.

### [7] 고무줄 렌더 — Verlet + 거리제약 6줄

```
for (const p of pts) { const vx = p.x - p.px, vy = p.y - p.py;
  p.px = p.x; p.py = p.y; p.x += vx * DRAG; p.y += vy * DRAG + G * dt * dt; }
for (let k = 0; k < 3; k++) for (let i = 1; i < pts.length; i++) {
  const a = pts[i-1], b = pts[i], dx = b.x-a.x, dy = b.y-a.y;
  const d = Math.hypot(dx,dy) || 1, f = (d - REST) / d * 0.5;
  if (i > 1) { a.x += dx*f; a.y += dy*f; } b.x -= dx*f; b.y -= dy*f; }
```

양 끝은 손과 작품에 고정. `REST`를 실제 거리보다 짧게 잡으면 팽팽할수록 직선이 되고, 발사 순간 고정을 풀면 1.2초간 출렁이다 사라진다. 게임플레이에 영향 없다 — 장력을 눈에 보이게 만드는 용도다.

## 판정 규칙

| 사건 | 조건 | 결과 |
|---|---|---|
| 부착 | 손과 작품 거리 < `GRAB_R` | 자동으로 붙는다 |
| 무시선 견인 | `gazeCount == 0` · 붙어 있음 | 작품이 손을 `FOLLOW_TAU`로 따라온다. **장전 0** |
| 장전 | `gazeCount >= 1` · 붙어 있음 | 작품 고정. 고무줄 길이 × `VIEWER_MULT[gazeCount]` = 장전량 |
| 누출 | 손이 떨어진 장전 상태 | 초당 `LEAK_RATE`만큼 감소 |
| 끊김 | 길이 > `SNAP_STRETCH` | 장전 0 + 작품 1.0초 진동 + 손 반동 |
| **발사** | `gazeCount`가 1 이상 → 0 | 장전 벡터 방향으로 `speed`로 발사. 0.9초 비행 |
| 반출 성공 | 착탄점이 반출구 내부 | 남은 작품 −1. 반출구에 겹쳐 쌓인다 |
| 벽 착탄 | 그 외 | 작품이 벽에 꽂힌다. **새 시선 정박점이 된다** — 관람객이 거기를 보러 온다 |
| 어그로 | 비행 중인 작품 존재 | 모든 관람객이 `AGGRO_MS` 동안 그쪽을 본다 → 다른 작품들의 시선이 동시에 떨어진다 |
| 시간 경과 | 항상 | `LIGHT_ROW_MS`마다 천장 조명이 한 줄 꺼진다 |
| **승리 / 패배** | 남은 작품 0 / 조명 전부 꺼짐 | 다음 스테이지 / 재시작 |

**어그로가 이 명세에서 가장 중요한 한 줄이다.** 하나를 날리면 모든 시선이 그쪽으로 끌리고, 그 순간 걸어둔 나머지가 전부 풀린다. 사고 하나가 연쇄가 되는 것도 자폭형 선택이 성립하는 것도 전부 이 규칙에서 나온다. 그리고 **벽 착탄은 벌점이 아니라 상태 변화다** — 빗나간 작품은 사라지지 않고 벽에 꽂혀 관람객을 그쪽으로 끌어온다. 실수가 다음 판의 지형이 된다.

점수 없다. 감점 없다. 의심 게이지 없다. 유일한 자원은 천장 조명 여섯 줄이다.

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 무엇을 정하는가 |
|---|---|---|
| `GAZE_CONE_DEG` / `GAZE_RANGE` | 34° / 화면폭의 55% | 시선 원뿔. 넓으면 발사가 안 일어난다 |
| `BORED_MS` | 2600~4200 ms (관람객별 고정값) | 시선 주기. **랜덤 아님** |
| `TILT_TELEGRAPH_MS` / `TILT_MAX` | 800 ms / 22° | 고개 기울기 예고. 붕괴 연출 하한과 같은 값 |
| `HEAD_F / Z / R` | 2.0 Hz / 0.45 / 1.8 | 고개 회전 2차 시스템. **z<1이라 오버슛한다** |
| `GRAB_R` / `FOLLOW_TAU` | 화면폭의 4% / 120 ms | 자동 부착 반경 / 무시선 견인 지연 |
| `MAX_STRETCH` | 화면폭의 28% | 장전량 상한 |
| `SNAP_STRETCH` / `SNAP_SHAKE_MS` | 화면폭의 34% / 1000 ms | 끊어지는 길이 / 끊김 연출 (0.8초 이상 규칙) |
| `LEAK_RATE` | 초당 12% | 뗀 고무줄이 새는 속도. **`HOLD` 봇을 죽이는 파라미터** |
| `VIEWER_MULT` | 1.0 / 1.6 / 2.2 / 2.8 | 시선 가닥 수 배율. **선형이 아니다** — 4명 모아도 4배는 안 된다 |
| `STRETCH_TO_SPEED` | 화면폭의 3.2배/초 | 최대 장전 시 발사 속도 |
| `FLIGHT_MS` / `FLIGHT_SPIN` | 900 ms / 1.5 회전 | 비행 길이. 즉사 금지 규칙의 직접 대상 |
| `AGGRO_MS` | 700 ms | 비행 작품이 시선을 붙잡는 시간. **연쇄의 폭을 정한다** |
| `NOD_MS` | 4000 ms | 빈 벽 앞 끄덕임 길이. 셋째 웃음의 지연 |
| `HITSTOP_S / M / L` | 3 / 6 / 10 프레임 | 손맛 3단 |
| `LIGHT_ROW_MS` | 3000 ms | 조명 한 줄이 꺼지는 간격 = 스테이지 18초 |
| `INPUT_SMOOTH_TAU` | 60~90 ms | 입력 미화 강도. 크면 조작이 무뎌진다 |

## 콘텐츠 분량

스테이지 **6개** + 명시적 최종 화면(텅 빈 전시장 정지 컷). 1스테이지 15~20초, 전체 완주 100~120초 — 1회 플레이 2분 이내. 무한 아케이드 없음. **레벨 셀렉트 필수** — 심사자가 최종 화면에 도달하지 못하면 만든 것의 절반이 평가에서 사라진다.

| 스테이지 | 새로 들어오는 것 | 작품 / 관람객 |
|---|---|---|
| 1 | 보고 있으면 안 움직이고 선만 길어진다. **첫 4초에 규칙 전부** | 3 / 1 |
| 2 | 시선이 겹치면 선이 두 가닥, 배율이 붙는다 | 4 / 2 |
| 3 | 반출구가 반대편으로 이동. **방향을 미리 걸어둬야 한다** | 5 / 2 |
| 4 | 동시 장전. 왕복하지 않으면 고무줄이 샌다 | 6 / 3 |
| 5 | 어그로. **하나를 먼저 날려 시선을 모으는 자폭형 선택** | 8 / 4 |
| 6 | 관람객 전원이 같은 주기로 회전. 전시장 전체가 한 번에 풀린다 | 12 / 6 |

## 오디오 (Web Audio 절차 생성, 외부 파일 0개)

| 사건 | 소리 |
|---|---|
| 고무줄 장력 | 지속 사인. **길이에 비례해 음정이 올라간다.** 가닥이 늘면 옥타브가 겹친다 |
| 고개 기울기 시작 | 아주 작은 저역 틱 하나. 예고의 청각판 |
| 발사 · 비행 | 밴드패스 노이즈 스윕(장전량에 비례해 밝아진다) → 저역 사인이 0.9초간 하강 |
| 연쇄 발사 | 발사음이 100ms 간격으로 겹친다. **화음이 아니라 뭉개져야 한다** |
| 반출구 진입 / 벽 착탄 | 상승 사인 2음 / 저역 퍽 + 짧은 화이트노이즈 |
| 고무줄 끊김 / 조명 꺼짐 | 톱니파 글리산도 상승 후 급감쇠 / 짧은 딸깍 + 저역 험 한 겹 제거 |
| 빈 벽 끄덕임 | **아무 소리도 없다.** 4초간 |

**무음으로도 전부 이해된다.** 소리는 화면 정보의 중복이다 — 음정은 선 길이의 중복이고, 옥타브 겹침은 가닥 수의 중복이다. 심사 자료인 30~60초 영상이 무음으로 재생될 것을 전제로 만든다.

## 승패와 흐름

```
  타이틀 ──▶ 스테이지 선택 ──▶ 플레이 ──┬──▶ 승리 ──▶ 다음 스테이지
    ▲              ▲                   │              │
    │              │                   └──▶ 폐관 ──┐  │ (6판 끝)
    │              └──────────────────────────────┘   ▼
    └───────────────────────────────────────────── 최종 화면
                                              (텅 빈 전시장 정지 컷)
```

- **재시작 0.5초 이내.** 패배 연출은 마지막 조명이 꺼지는 것 하나뿐이고, 그 뒤 즉시 초기 배치로 돌아간다
- 최종 화면은 정지 컷 하나 — **텅 빈 흰 벽 앞에서 끄덕이는 관람객 하나, 반대편 구석에 겹쳐 쌓인 12개 더미, 바닥에 남은 고무줄 흔적선.** 조명이 꺼져도 화면은 어두워지지 않는다. 어두워지면 이 그림이 안 보인다

## 검증 훅 (AI 활용 기술 문서 재료)

`window.__game`에 노출한다.

```
{ artLeft, artOut, artStuck, chargedCount, gazeStrands, chargeSum,
  pullRatio, chargeAtFire, fireCount, snapCount, aggroChainMax,
  lightsLeft, elapsed, stage, seed }
```

- **`pullRatio`** — 시선이 붙어 있던 총 프레임 중 장전량이 **증가하고 있던** 프레임의 비율. **폐기 기준 ①** (중앙값 50% 미만이면 폐기)
- **`chargeAtFire`** — 발사 순간 장전량 ÷ `MAX_STRETCH`, 발사마다 기록. **폐기 기준 ②** (중앙값 0.6 미만이면 폐기)
- **`aggroChainMax`** — 한 번의 어그로로 동시에 풀린 작품 수의 최댓값. 2차 웃음이 실제로 일어나는지의 지표다. 스테이지 5에서 3 미만이면 `AGGRO_MS`를 늘린다

`scripts/balance-sim.ts` — 고정 시드, 고정 타임스텝 1/120초, 헤드리스. 렌더 없이 봇을 돌린다. **지배 전략 봇 3종을 붙여 깊이를 수치로 증명한다.**

| 봇 | 전략 | 통과 조건 | 증명하는 것 |
|---|---|---|---|
| `HOLD` | **가장 오래 보이는 작품 하나만 최대로 당겨둔다.** 왕복 없음 | 클리어율 **< 35%** | 시선 지도를 안 읽고도 이기면 이 게임엔 결정이 없다 |
| `SPRAY` | 아무 작품이나 닥치는 대로 왕복하며 얕게 걸어둔다 | 클리어율 **< 40%** | 왕복량만으로도 안 된다 |
| `BAIT` | 하나를 먼저 날려 시선을 모으고, `AGGRO_MS` 동안 나머지를 동시에 푼다 | 클리어율 **> 70%** | **읽을 수 있는 것이 있고, 읽으면 이긴다** |

**수치의 근거**: 스테이지 1·2는 규칙을 가르치는 구간이라 어떤 봇이든 통과하는 게 정상이다. 6판 중 2판 = 33%, 그래서 `HOLD`의 상한이 35%다. `BAIT`의 70%는 6판 중 4.5판 — 읽는 플레이가 안 읽는 플레이의 두 배 이상 나와야 결정이 있다고 말할 자격이 생긴다.

세 봇이 이 순서로 안 갈리면 파라미터가 아니라 규칙을 고친다. `HOLD`가 35%를 넘으면 `LEAK_RATE`와 `VIEWER_MULT`부터 의심한다 — 새지 않으면 왕복할 이유가 없고, 배율이 없으면 시선을 모을 이유가 없다.

같은 시드 · 같은 입력 로그 → 같은 결과. `BORED_MS`가 관람객별 고정값인 이유다. 영상 촬영도 입력 로그 재생으로 뽑는다. 매 테이크가 같은 곳에서 웃겨야 한다.

## 범위 밖

| 안 만드는 것 | 왜 |
|---|---|
| 의심 게이지 · 경비원 · 발각 | 붙는 순간 스텔스로 읽히고 금지 목록에 걸린다. 관람객은 나를 절대 제지하지 않는다 |
| 관람객 피격 · 넉백 · 리액션 | 웃음의 대상이 사람으로 읽히면 감점이다. 작품은 관람객 머리 위로 넘어간다 |
| 점수 · 콤보 · 배수 | 감점이 걸리는 순간 얌전한 플레이가 최적해로 돌아온다 |
| 시선 회피 · 은폐 · 사각지대 | 이 게임은 **보이기를 원하는** 게임이다. 숨을 곳을 만들면 규칙이 반대로 읽힌다 |
| 래그돌 · 창발 물리 | "a certain percentage of the time"만 웃기다. 결정론 영상과 양립하지 않는다 |
| 카메라 이동 · 줌 · 작품별 특수 능력 · 손 업그레이드 | 한 화면 안에서 전부. 고무줄 하나가 이 게임의 전부이고, 부품을 늘리면 그게 흐려진다 |
| 화면을 덮는 파티클 | **고무줄 선과 시선 원뿔을 가리는 순간 재미의 전부가 무효가 된다.** 먼지는 바닥 근처만 |
| 세이브 · 랭킹 · 절차 생성 · 네트워크 · 3D · 외부 이미지·오디오 | 2분짜리 게임에 붙일 자리가 없고, 외부 에셋은 0개다 |
