# 굽혀 인사하기 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 씬 전환 없음. 스테이지가 넘어가도 카메라는 이동하지 않는다.

**θ = 0° (똑바로 섰을 때)**

```
┌──────────────────────────────────────────┐
│ ┃                                      ┃ │  ← 복도 벽 (수직선 2개)
│ ┃                                      ┃ │
│ ┃        ▮                    ▯        ┃ │  ← 머리
│ ┃        ┃                    ┃        ┃ │  ← 어깨~허리
│ ┃        ┃                    ┃        ┃ │
│ ┗━━━━━━━━┻━━━┿━━━┿━━━┿━━━┿━━━┻━━━━━━━━┛ │  ← 바닥 + 눈금
│           나                  상대        │
└──────────────────────────────────────────┘
```

**θ = 60° (숙였을 때 — 화면 전체가 같이 회전한다)**

```
┌──────────────────────────────────────────┐
│                                    ┃      │
│         ▮                    ┿  ┃         │  ← 상대는 모서리 밖으로 나갔다
│        ╱                  ┿             │
│      ┃         ┿      ┿                  │  ← 바닥 눈금만 프레임을 채운다
│    ┃      ┿                              │
│  ┿                                       │
└──────────────────────────────────────────┘
```

| 요소 | 그리는 법 |
|---|---|
| 나 | 3분절 막대. 발 → 허리 → 어깨 → 머리. 단색 진회색. **허리 관절 하나만 접힌다** |
| 상대 | 같은 형태, 밝은 회색. **얼굴·표정·눈 없음.** 인격을 주지 않는다 |
| 바닥 | 수평선 1개 + 등간격 세로 눈금. **회전을 눈에 보이게 하는 유일한 장치** |
| 복도 벽 | 수직선 2개. 회전하면 기울어져 회전량을 증폭한다 |
| 실격 압력 | ① 화면 가장자리 비네트가 짙어진다 ② 내 도형의 목 부분이 붉게 물든다. **숫자·게이지 없음** |
| 제3의 도형 | 붕괴 후 지나가는 통행인. 단색 원 하나. 멈추지 않고 지나간다 |
| 최종 카드 | 빈 복도 + 접힌 도형 하나 + 한 줄 텍스트 |

HUD 없음. 타이머 없음. 파티클은 게임플레이 오브젝트를 절대 가리지 않는다.

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 Y 이동 | **숙인 각도 θ (절대 매핑).** 화면 최상단 = 0°, 최하단 = `THETA_MAX` |
| 마우스 Y 급강하 | 2차 시스템의 오버슛으로 이마가 바닥/상대 머리까지 넘어간다 |
| 마우스 정지 | 그 각도 유지 |
| 아무 키 | 실패 후 즉시 재시작 |

**버튼이 하나도 없다.** 클릭도 쓰지 않는다. 이게 `Super Deference Fighter`의 BOW/GAZE 두 버튼과 갈리는 지점이므로, 편의를 위해서라도 버튼을 추가하지 않는다.

## 핵심 시스템

물리 엔진 없음. 아래 7계층이 전부이고, 실제 물리는 세 덩어리뿐이다.

| 계층 | 하는 일 | 구현 |
|---|---|---|
| L0 입력 미화 | 커서 잡음 제거 | **지수감쇠 1줄** `x += (target - x) * (1 - Math.exp(-k * dt))` + 데드존 |
| L1 자세 | θ 생성. 급강하 시 오버슛 | **t3ssel8r 2차 시스템 4줄** — `f, z, r` → `k1, k2, k3` → 위치·속도 갱신. **r > 1이 오버슛을 만든다.** 별도 오버슛 코드 없음 |
| L2 카메라 | 화면 회전 | `camAngle = θ * CAM_COUPLE` 뒤에 **지수감쇠 1줄**로 한 박자 지연. `ctx.rotate(-camAngle)` 한 번 |
| L3 가시성 | 상대가 보이는가 | **판정 코드 없음.** 회전 변환 후 그냥 그린다. 프레임 밖이면 안 보이는 것이다 |
| L4 상대 | 결정론 스크립트 | 내 최저 θ를 기록 → **τ초 뒤** 그보다 `DEPTH_MARGIN`만큼 깊은 목표로 이동. 구간별 하강 속도·재상승 타이밍은 스테이지 데이터 테이블. **난수 0** |
| L5 압력 | 승패 스칼라 | 부호 있는 값 1개. `θ_나 > θ_상대`면 감소, 아니면 더 빠르게 증가 |
| L6 충돌·붕괴 | 이마 충돌, 0.9초 접힘 | **Verlet + 거리 제약 6줄.** 붕괴 연출 동안에만 활성화. 평시에는 L1이 자세를 지배한다 |
| L7 히트스톱 | 손맛 | 약 3 / 중 6 / 대 10프레임(60fps). **정지 대상은 충돌한 두 오브젝트만.** 카메라와 배경은 계속 돈다 |

**래그돌을 상시로 돌리지 않는 이유**: 창발 슬랩스틱은 확률적으로만 웃기다. 30초 결정론 영상은 확률에 걸 수 없다. 그래서 L6은 **연출 구간 전용**이고, 붕괴 자세는 매번 같은 그림으로 끝난다.

**커브 보정(curve correction)**: 마우스 입력을 그대로 물리에 먹이지 않는다. L0에서 다듬고, L1에서 2차 시스템에 통과시키고, 바닥 접촉 직전 `SNAP_DEG` 안에서는 착지 각도를 스냅한다. 이마가 어중간한 각도로 박히는 그림이 나오지 않는다.

## 판정 규칙

| 조건 | 결과 |
|---|---|
| `θ_나 > θ_상대` | 압력 감소 (`PRESSURE_DOWN`/s) |
| `θ_나 < θ_상대` | 압력 증가 (`PRESSURE_UP`/s). **증가가 감소보다 빠르다** |
| `θ_나 < THETA_SEE` | 상대가 프레임 안에 완전히 들어온다 = 깊이를 읽을 수 있다 |
| `THETA_SEE ≤ θ_나 < THETA_BLIND` | 상대가 모서리에 부분적으로 걸린다 = 부정확하게 읽힌다 |
| `θ_나 ≥ THETA_BLIND` | 상대가 프레임 밖. 아무것도 모른다 |
| 압력 = 0 | **스테이지 클리어.** 상대가 먼저 접힌다 |
| 압력 = 만재 | **실패.** 0.9초 붕괴 연출 → 재시작 |
| 이마 ↔ 바닥 충돌 | 히트스톱 10프레임. 압력에 영향 없음. 순수 연출 |
| 이마 ↔ 상대 머리 충돌 | 히트스톱 6프레임. 두 도형이 튕겨 오른다 |
| 상대가 내 깊이를 추월하는 순간 | 히트스톱 3프레임. **안 보고 있어도 손에 느껴지는 유일한 신호** |
| 최종 스테이지에서 `θ_나 < THETA_SEE` | **클리어.** 상대가 없다는 것을 확인하는 것이 승리 조건 |

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 무엇을 정하는가 |
|---|---|---|
| `THETA_MAX` | 100° | 최대 숙임. 90°를 넘겨야 이마가 바닥에 닿는다 |
| `THETA_SEE` | 35° | 상대가 완전히 보이는 상한 |
| `THETA_BLIND` | 55° | 상대가 완전히 사라지는 각도. **이 안의 핵심 축** |
| `CAM_COUPLE` | 1.0 | 카메라 결합 계수. 1.0 고정. 낮추면 게임이 사라진다 |
| `f / z / r` | 2.2Hz / 0.5 / 2.0 | 2차 시스템. `r`이 오버슛 양을 정한다 |
| `CAM_LAG_K` | 12~18 | 카메라가 머리를 따라오는 지연. 무게감 |
| `FOLLOW_LAG` τ | 0.6~1.2초 | 상대가 내 최저점을 반영하는 지연. **선택이 존재하는 창** |
| `DEPTH_MARGIN` δ | 4~8° | 상대가 나보다 더 내려가는 폭 |
| `PRESSURE_UP` | 0.55/s | 내가 높을 때 압력 증가율 |
| `PRESSURE_DOWN` | 0.35/s | 내가 낮을 때 압력 감소율 |
| `COLLAPSE_MS` | 900 | 붕괴 연출 길이. **0.8초 미만으로 내리지 않는다** |
| `HITSTOP` | 3 / 6 / 10 프레임 | 약 / 중 / 대 |
| `SNAP_DEG` | 6° | 착지 스냅 범위 |

## 콘텐츠 분량

- **스테이지 6개** + 명시적 최종 화면. 무한 아케이드 아님
- 1스테이지 **12~18초**. 웃음 사이클 길이와 같게 맞춘다
- 전체 완주 **1분 40초 내외**. 2분 이내 제약 충족
- 재시작은 스테이지 단위. 전체를 다시 하지 않는다

| 스테이지 | 상대 기준선 | τ (추종 지연) | 무엇이 새로 요구되는가 |
|---:|---|---|---|
| 1 | 얕음 | 길다 (1.2s) | 카메라가 같이 돈다는 사실 하나 |
| 2 | 중간 | 1.0s | 올라와서 확인하는 행동이 처음 필요해진다 |
| 3 | 중간 | 0.8s | 상대의 재상승 타이밍이 불규칙해진다 |
| 4 | 깊음 | 0.8s | 오버슛 관리. 급강하하면 이마가 박힌다 |
| 5 | 매우 깊음 | 0.6s | 확인 창이 좁아진다. 거의 눈을 감고 버틴다 |
| 6 | **바닥에서 시작** | — | 이길 수 없다. **고개를 드는 것이 클리어 입력** |

## 오디오 (Web Audio 절차 생성, 외부 파일 0개)

| 사건 | 소리 |
|---|---|
| 숙이는 중 | 필터 걸린 노이즈. **각속도에 비례**해 커진다. 옷깃 스치는 질감 |
| 각도 유지 | 아주 낮은 드론. 압력이 찰수록 음량과 거칠기가 오른다 |
| 상대가 내 깊이를 추월 | 짧은 클릭 하나. **안 보이는 동안 유일하게 오는 정보** |
| 이마 ↔ 바닥 | 저역 사인 임펄스 + 짧은 노이즈. "쿵" |
| 이마 ↔ 이마 | 중역 임펄스 2개가 1프레임 간격으로 |
| 붕괴 | 노이즈 버스트 + 하강 글리산도, 900ms 동안 |
| 최종 화면 | **무음.** 통행인의 발소리만 지나간다 |

**무음으로도 전부 이해된다.** 각도는 도형의 접힘으로, 시야 상실은 프레임 밖으로, 압력은 비네트와 목 색으로, 붕괴는 실루엣 변화로 화면에 중복 표현된다. 소리는 어느 판정도 단독으로 담당하지 않는다.

## 승패와 흐름

```
타이틀
  │  (아무 키)
  ▼
스테이지 N  ──────────────┐
  │                      │
  ├─ 압력 0 ──→ 클리어 ──┤ 0.5초 뒤 다음 스테이지
  │                      │
  └─ 압력 만재 ──→ 붕괴 (900ms) ──→ 같은 스테이지 재시작
                                     │
                        ┌────────────┘
                        ▼
                   스테이지 6 클리어
                        │
                        ▼
                   최종 화면 (빈 복도)
                   "상대를 본 시간 3.4초 / 1분 47초"
                        │  (아무 키)
                        ▼
                      타이틀
```

- **재시작 0.5초 이내.** 붕괴 연출 900ms는 실패 프레임 안에 포함되고, 그 뒤 배치는 0.5초 안에 끝난다
- 붕괴 연출 중 아무 키를 누르면 즉시 스킵된다. 두 번째 실패부터는 기다리게 하지 않는다
- 판이 끝나면 화면에 남는 것: **접힌 도형 하나와 빈 복도.** 그게 성적표다

## 검증 훅 (AI 활용 기술 문서 재료)

`window.__game` 노출:

```
{ theta, thetaOpp, camAngle, oppVisible, oppVisibleMs,
  pressure, lookUpCount, stage, t, debugAlwaysVisible }
```

`scripts/balance-sim.ts` — 헤드리스로 봇을 돌려 **지배 전략이 없다는 것을 수치로 증명한다.**

| 봇 | 정책 | 증명하려는 것 |
|---|---|---|
| `BURY` | `THETA_MAX`에 붙박이 | 최대 깊이 고정이 죽는다. 상대가 δ만큼 더 깊어 압력이 단조 증가 |
| `PEEK` | `THETA_SEE` 아래를 유지하며 계속 확인 | 계속 확인하는 전략이 죽는다. 확인하는 내내 지고 있다 |
| `ORACLE` | 정보 차단을 무시하고 `thetaOpp`를 직접 읽어 최소 마진 추종 | **클리어율 상한.** 이 게임에서 완전 정보의 가치 |
| `PERIODIC(P)` | 주기 P초마다 `THETA_SEE`까지 올라와 확인, 나머지 시간은 잠수 | **P를 0.5~4.0초로 스윕.** 클리어율이 P에 대해 **단봉(single-peak)이면 "언제 확인할지"가 실제 결정이라는 증명** |

**핵심 지표 — 정보 차단 기여도**

```
Δ = 클리어율(debugAlwaysVisible = ON) − 클리어율(OFF)

Δ ≥ 15%p   →  정보를 끊는 것이 게임을 만들고 있다
Δ < 15%p   →  폐기 (간이 기획의 폐기 기준과 같은 숫자)
```

`ORACLE`과 `PERIODIC(최적 P)`의 클리어율 격차도 같은 것을 잰다. 두 값이 붙으면 시야 차단이 장식이라는 뜻이다.

**결정론**: 난수 0. 상대 스크립트는 스테이지 데이터 테이블. 같은 입력 시퀀스는 같은 프레임에 같은 그림을 만든다. 30초 영상이 매번 같아야 하므로 이건 편의가 아니라 요구사항이다.

## 범위 밖

| 안 만드는 것 | 왜 |
|---|---|
| 상시 래그돌 물리 | 창발 슬랩스틱은 확률적으로만 웃기다. 붕괴 연출만 Verlet로 만든다 |
| 얼굴·표정·비명 | 웃음의 대상이 사람으로 읽히는 순간 한국 심사에서 감점된다 |
| 압력 게이지 UI, 각도 숫자 | UI가 판정을 대신 말해버린다. 비네트와 목 색으로 충분하다 |
| 카메라 컷 전환, 씬 이동 | 카메라는 오직 θ로만 움직인다. 다른 이유로 움직이면 규칙이 흐려진다 |
| 좌우 이동, 점프, 공격 | 입력은 커서 Y 하나다 |
| 멀티플레이, 랭킹, 세이브, 네트워크 | 2분짜리 단일 화면 게임에 필요 없다 |
| 대사·자막 | 무음으로 이해 가능해야 한다. 최종 카드 한 줄만 예외 |
| 스프라이트, 외부 이미지·폰트·오디오 파일 | 도형·단색·절차 생성만. 약관 제4조 2항 리스크를 구조적으로 0으로 만든다 |
