# 후려쳐 내보내기 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 카메라 이동 없음. 씬 전환은 타이틀 / 플레이 / 최종 화면 셋뿐이다.

```
┌──────────────────────────────────────────────────────┐
│                                          ╔══════╗    │  ← 열린 창문
│                                          ║      ║    │    개구부 높이 = 남은 시간
│      ✳ 파리                          ✳   ╚══════╝    │
│                                                      │
│              ●                                       │  ● = 커서 = 자루 끝
│               ╲                                      │  ╲ = 자루 (선분 1개)
│                ▬ ← 채 머리 (자루 끝을 2차 감쇠로 추종)  │
│                                                      │
│   ▭    ○   △    ○    ▭    ○    ▭         ◇          │
│  접시  컵 케이크 컵  접시  컵  접시    밥 먹는 도형     │
│ ════════════════════════════════════════════════     │  ← 식탁 (가로 직선)
│                                                      │
│                    ☻ ← 아바타 (식탁 앞, 고정)          │
└──────────────────────────────────────────────────────┘
```

전부 도형·단색·절차 생성이다. 외부 에셋 0개.

| 요소 | 어떻게 그리는가 |
|---|---|
| 채 머리 | 모서리 둥근 직사각형 1개. 회전각은 진행 방향 |
| 자루 | 커서와 채 머리를 잇는 선분 1개. 굵기 3px |
| 파리 | 검은 점 + 진행 방향으로 늘어나는 잔상 3점. **날개 없음** — 궤적이 캐릭터다 |
| 접시 | 가로로 눌린 타원. 파손 시 3~5조각 다각형 |
| 유리컵 | 반투명 사각형. 넘어지면 회전 + 미끄러짐 |
| 케이크 | 삼각형 + 위에 원 하나. 천장 부착 시 납작하게 눌린 형태로 교체 |
| 아바타 | 원 + 사각형. 케이크를 맞으면 머리 위에 눌린 케이크 도형이 얹힌다 |
| 밥 먹는 도형 | 마름모 + 팔 선분 1개. 팔이 1.4초 주기로 위아래 왕복. **영원히 멈추지 않는다** |
| 창문 | 사각 테두리. 개구부 높이가 줄어드는 것으로 남은 시간을 표현 |
| 커튼 / 식탁보 | Verlet 점 12개 사슬. 채 머리가 지나가면 흔들린다 |

**HUD 없음.** 점수 없음, 타이머 숫자 없음, 남은 파리 표시 없음. 남은 시간은 창문 개구부 크기이고, 남은 파리는 화면의 파리를 세면 된다. 무음으로 이해 가능해야 한다는 제약이 HUD를 지운다.

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 자루 끝(=커서) 위치. **이것이 전부다** |
| 아무 키 / 클릭 | 결과 화면에서 즉시 재시작 |

버튼이 없다. 휘두르기 버튼도, 조준도, 차지도 없다. 스냅은 커서 속도로 자동 판정한다.

## 핵심 시스템

물리 엔진 없음. 아래 6계층 전부 합쳐 100줄 안쪽이다.

```
[0] 고정 타임스텝 누산기 (1/120초)
      │
[1] 입력층    raw 마우스 → 지수감쇠 스무딩 → 스냅 구간 원호 보정
      │       ("making every janky line into a slick curved swoosh")
[2] 도구층    자루 끝 → 채 머리. t3ssel8r 2차 시스템
      │       여기서 지연·오버슛·잔진동이 전부 나온다
[3] 접촉층    채 머리 원 vs 파리 점 / 물건 AABB. 히트스톱
      │
[4] 물건층    상태기계 + 연출 스크립트 (창발 아님)
      │
[5] 천 흔들림  Verlet + 거리제약. 커튼·식탁보
      │
[6] 파리층    결정론 FSM. 랜덤 없음
```

### [1] 입력 미화 — 지수감쇠 1줄

```
sx += (mx - sx) * (1 - Math.exp(-dt / INPUT_SMOOTH_TAU));
```

여기에 스냅 보정을 얹는다. 커서 속도가 `SNAP_MIN_SPEED`를 넘은 프레임부터 `SNAP_ARC_MS` 동안, 스무딩된 궤적을 시작점·현재점·속도 방향으로 만든 원호로 대체한다. 손 떨림이 채 머리에서 증폭되는 것을 막는 유일한 장치다. **미화는 반드시 물리 앞에 온다.** 물리 뒤에 두면 잔진동까지 지워진다.

### [2] 채 머리 — 2차 시스템 4줄

t3ssel8r 형태 그대로. `f`(고유진동수), `z`(감쇠비), `r`(초기 응답) 세 개를 계수 셋으로 바꾼다.

```
k1 = z / (Math.PI * f);
k2 = 1 / ((2 * Math.PI * f) ** 2);
k3 = r * z / (2 * Math.PI * f);
y += dt * yd;  yd += dt * (x + k3 * xd - y - k1 * yd) / k2;
```

- `x` = 스무딩된 자루 끝 위치, `xd` = 그 속도, `y` = 채 머리 위치
- `z < 1`이면 오버슛하고 출렁인다. **이 게임의 전부가 이 값에 걸려 있다** (폐기 기준의 대상)
- `r > 1`이면 스냅 시작 순간 채 머리가 앞으로 튀어나간다. 손맛이 여기서 나온다

x, y 각각 독립으로 돌린다. 채 머리 회전각은 `atan2(yd)`로 따라간다.

### [3] 접촉과 히트스톱

채 머리는 반지름 `HEAD_R` 원 하나. 물건은 AABB, 파리는 점. 프레임당 채 머리 이동량이 클 수 있으므로 이전 위치와 현재 위치 사이를 4등분해 검사한다.

히트스톱은 **충돌한 두 오브젝트만** 멈춘다. 화면 전체를 멈추면 파리가 같이 멈춰서 "파리는 멀쩡하다"는 태그가 죽는다.

| 등급 | 프레임 (60fps) | 언제 |
|---|---|---|
| 약 | 3 | 파리에 닿음 |
| 중 | 6 | 접시·유리컵 파손 |
| 대 | 10 | 케이크 정타 |

### [4] 물건 — 상태기계 + 연출

`온전 → 밀림 → 날아감 → 착지/파손`. 날아간 뒤의 궤적은 물리가 아니라 **스크립트**다. 케이크는 맞은 방향과 무관하게 천장에 붙고, 0.9초 뒤 아바타 머리 좌표로 떨어진다. 유리컵은 맞은 컵을 기준으로 1.2초에 걸쳐 순서대로 넘어간다.

창발 슬랩스틱을 쓰지 않는 이유는 하나다. 래그돌은 "a certain percentage of the time"만 웃기고, 30초 결정론 영상은 확률에 걸 수 없다.

### [5] 천 — Verlet + 거리제약 6줄

커튼과 식탁보에만 쓴다. 점 12개 사슬, 위쪽 끝 고정.

```
for (const p of pts) { const vx = p.x - p.px, vy = p.y - p.py;
  p.px = p.x; p.py = p.y; p.x += vx * DRAG; p.y += vy * DRAG + G * dt * dt; }
for (let k = 0; k < 3; k++) for (let i = 1; i < pts.length; i++) {
  const a = pts[i-1], b = pts[i], dx = b.x-a.x, dy = b.y-a.y;
  const d = Math.hypot(dx,dy) || 1, f = (d - REST) / d * 0.5;
  if (i > 1) { a.x += dx*f; a.y += dy*f; } b.x -= dx*f; b.y -= dy*f; }
```

게임플레이에 영향 없다. 채 머리가 지나간 자리를 눈에 보이게 만드는 용도다.

### [6] 파리 — 결정론 FSM

랜덤 없음. 같은 입력이면 같은 궤적이 나온다.

| 상태 | 행동 |
|---|---|
| `PERCH` | 착석. 착석지 점수 = (근처 파손 가능 물건 수 × 2) + (채 머리 접근 난이도). **가장 높은 자리를 고른다** |
| `DODGE` | 커서 속도가 `SNAP_MIN_SPEED`를 넘는 순간 `FLY_DODGE_LEAD`(0.2초)만큼 **선행해서** 이탈. 채 머리가 도착하기 전에 이미 떠 있다 |
| `TAUNT` | `FLY_TAUNT_PERIOD`(15~18초)마다 열린 창문 앞을 유유히 지나갔다가 **일부러 되돌아온다**. 이 상태에서는 절대 나가지 않는다 |
| `LURE` | 3막 전용. 마지막으로 멀쩡한 물건 위로 이동해 앉는다 |
| `EVICTED` | 창 개구부 통과. 화면에서 사라진다 |

`DODGE`의 선행 이탈은 채 머리 속도가 아니라 **커서 속도**를 본다. 채 머리는 늦게 오기 때문에, 채 머리를 보고 피하면 플레이어 입장에서 회피가 안 보인다.

## 판정 규칙

| 사건 | 조건 | 결과 |
|---|---|---|
| 파리 퇴출 | 파리가 창 개구부를 통과 | 남은 파리 −1 |
| 파리 밀어내기 | 채 머리가 파리에 닿음 · 속도 ≥ `V_EVICT` | 채 머리 진행 방향으로 강하게 밀린다. **죽지 않는다** |
| 헛침 | 채 머리가 파리에 닿음 · 속도 < `V_EVICT` | 파리가 흩어졌다가 **더 나쁜 자리에** 다시 앉는다 |
| 물건 파손 | 채 머리가 물건에 닿음 · 속도 ≥ `V_BREAK` | 파손 연출 + **창문 개구부가 `WINDOW_CLOSE_PER_BREAK`만큼 닫힌다** |
| 물건 밀림 | 채 머리가 물건에 닿음 · 속도 < `V_BREAK` | 밀리기만 한다. 위치가 바뀌어 다음 궤도가 달라진다 |
| 시간 경과 | 항상 | 창문이 초당 `WINDOW_CLOSE_RATE`만큼 스스로 닫힌다 |
| **승리** | 남은 파리 0 | 다음 스테이지 |
| **패배** | 개구부 높이 < 파리 몸통 | 재시작 |

**`V_BREAK < V_EVICT`가 이 명세에서 가장 중요한 한 줄이다.** 파리를 내보낼 수 있는 속도는 전부 물건을 부술 수 있는 속도다. 살살 치는 플레이는 파리를 못 내보내고, 창문이 먼저 닫힌다. 이것이 fun 렌즈가 지목한 "극도로 얌전한 봇"을 규칙 차원에서 지운다.

점수는 없다. 감점도 없다. 유일한 자원은 창문 개구부 하나다.

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 무엇을 정하는가 |
|---|---|---|
| `SWAT_F` | 1.6~2.4 Hz | 채 머리가 자루 끝을 따라오는 빠르기 |
| `SWAT_Z` | 0.25~0.40 | 잔진동이 몇 번 출렁이는가. **폐기 기준의 직접 대상** |
| `SWAT_R` | 1.5~2.5 | 스냅 시작 순간 앞으로 튀어나가는 정도 |
| `INPUT_SMOOTH_TAU` | 60~90 ms | 입력 미화 강도. 너무 크면 조작이 무뎌진다 |
| `SNAP_MIN_SPEED` | 화면폭의 1.2배/초 | 스냅으로 인정하는 커서 속도. 파리 회피 트리거를 겸한다 |
| `SNAP_ARC_MS` | 120 ms | 원호 보정 구간 길이 |
| `V_EVICT` | 화면폭의 2.0배/초 | 파리를 창까지 밀어내는 최소 채 머리 속도 |
| `V_BREAK` | `V_EVICT`의 0.6배 | 물건이 부서지는 속도. **반드시 `V_EVICT`보다 작다** |
| `WINDOW_CLOSE_RATE` | 개구부의 초당 1.5% | 가만히 있으면 지는 속도 |
| `WINDOW_CLOSE_PER_BREAK` | 개구부의 6% | 한 번 부술 때의 비용 |
| `HITSTOP_S / M / L` | 3 / 6 / 10 프레임 | 손맛 3단 |
| `CAKE_CEILING_HOLD` | 0.9초 | 첫 웃음의 지연 길이 |
| `GLASS_DOMINO_MS` | 1200 ms | 둘째 웃음의 붕괴 길이 (0.8초 이상 규칙) |
| `FLY_DODGE_LEAD` | 0.2초 | 파리가 스냅보다 얼마나 먼저 뜨는가 |
| `FLY_TAUNT_PERIOD` | 15~18초 | 창문 앞 U턴 주기 = 웃음 사이클 주기 |
| `HEAD_R` | 화면폭의 3.5% | 채 머리 크기. 명중률과 파손률을 동시에 움직인다 |

## 콘텐츠 분량

- 스테이지 **6개** + 명시적 최종 화면 (폐허가 된 식탁 정지 컷)
- 1스테이지 **15~20초**, 전체 완주 **100~120초** — 1회 플레이 2분 이내
- 무한 아케이드 없음. 6판을 끝내면 확실히 끝난다
- 레벨 셀렉트 필수. 심사자가 최종 화면에 도달하지 못하면 만든 것의 절반이 평가에서 사라진다

| 스테이지 | 새로 들어오는 것 |
|---|---|
| 1 | 파리 1마리, 물건 3개. 채 머리 지연을 손에 익힌다 |
| 2 | 물건 7개로 밀집. **귀환 궤도가 처음으로 위협이 된다** |
| 3 | 파리 2마리. 하나를 노리면 다른 하나가 최악의 자리로 간다 |
| 4 | 케이크 등장. 첫 천장 부착이 여기서 나온다 |
| 5 | 파리가 `TAUNT`를 쓴다. 창문 앞 U턴 |
| 6 | `LURE`. 마지막 멀쩡한 물건 위에 앉는다. **파리가 나를 조종한다** |

## 오디오 (Web Audio 절차 생성, 외부 파일 0개)

| 사건 | 소리 |
|---|---|
| 스냅 | 짧은 밴드패스 노이즈. 채 머리 속도에 비례해 밝아진다 |
| 채 머리 잔진동 | 아주 작은 저역 사인, 진폭에 비례. **속도가 죽으면 소리도 죽는다** |
| 파리에 명중 | 톡. 사각파 2ms + 즉시 감쇠 |
| 접시 파손 | 화이트노이즈 버스트 + 하이패스 |
| 유리컵 도미노 | 짧은 사인 5개, 반음씩 내려간다 |
| 케이크 천장 부착 | 저역 퍽. 그리고 0.9초 동안 **아무 소리도 없다** |
| 케이크 낙하 | 퍽 + 저역 노이즈 |
| 창문 닫힘 | 삐걱 — 톱니파 글리산도 하강 |
| 파리 퇴출 | 상승 사인 2음 |
| 밥 먹는 도형 | 1.4초 주기의 아주 작은 딸깍. 끝까지 변하지 않는다 |

**무음으로도 전부 이해된다.** 소리는 전부 화면 정보의 중복이다. 심사 자료인 30~60초 영상이 무음으로 재생될 것을 전제로 만든다.

## 승패와 흐름

```
  타이틀 ──▶ 스테이지 선택 ──▶ 플레이 ──┬──▶ 승리 ──▶ 다음 스테이지
    ▲              ▲                   │              │
    │              │                   └──▶ 패배 ──┐  │ (6판 끝)
    │              └───────────────────────────────┘  ▼
    └──────────────────────────────────────────── 최종 화면
                                                (폐허 정지 컷)
```

- **재시작 0.5초 이내.** 패배 연출은 창문이 닫히는 것 하나뿐이고, 그 뒤 즉시 초기 배치로 돌아간다
- 최종 화면은 정지 컷 하나. 케이크 쓴 아바타, 뒤집힌 접시, 여전히 먹고 있는 도형
- 실패해도 화면이 어두워지지 않는다. 어두워지면 마지막 그림이 안 보인다

## 검증 훅 (AI 활용 기술 문서 재료)

`window.__game`에 노출한다.

```
{ fliesLeft, fliesOut, windowOpenRatio, breakCount, swingCount,
  headSpeed, headResidualAmp, elapsed, grazeRate, stage, seed }
```

`grazeRate`가 폐기 기준의 측정값이다 — **귀환 궤도(스냅 종료 후 채 머리가 반대편으로 되돌아오는 구간)에서 표적이 아닌 물건에 닿은 스윙의 비율.**

`scripts/balance-sim.ts` — 고정 시드, 고정 타임스텝 1/120초, 헤드리스. 렌더 없이 봇을 돌린다.

**지배 전략 봇 3종을 붙여 깊이를 수치로 증명한다.**

| 봇 | 전략 | 통과 조건 | 증명하는 것 |
|---|---|---|---|
| `CALM` | 채 머리 속도가 ε 이하일 때만 짧게 스냅. **fun 렌즈가 지목한 바로 그 봇** | 클리어율 **< 30%** | 얌전한 플레이가 최적해가 아니다 |
| `WILD` | 항상 최대 속도로 스냅. 궤도 고려 없음 | 클리어율 **< 40%** | 막 휘두르는 것도 최적해가 아니다 |
| `PHASE` | 채 머리 잔진동 위상을 읽어, 귀환 궤도가 물건을 피하는 각도에서만 스냅 | 클리어율 **> 70%** | **읽을 수 있는 것이 있고, 읽으면 이긴다** |

세 봇이 이 순서로 갈리지 않으면 게임에 깊이가 없다는 뜻이고, 그때는 파라미터가 아니라 규칙을 고쳐야 한다. `CALM`이 30%를 넘으면 `V_EVICT`와 `WINDOW_CLOSE_RATE`부터 의심한다.

같은 시드 · 같은 입력 로그 → 같은 결과. 영상 촬영도 입력 로그 재생으로 뽑는다. 매 테이크가 같은 곳에서 웃겨야 한다.

## 범위 밖

| 안 만드는 것 | 왜 |
|---|---|
| 파리 죽이기 | 죽으면 화면에서 사라지고, 가학성 안전핀도 같이 사라진다 |
| 점수·콤보·배수 | 파손에 감점이 걸리는 순간 얌전한 플레이가 최적해로 돌아온다 |
| 래그돌·창발 물리 | "a certain percentage of the time"만 웃기다. 결정론 영상과 양립하지 않는다 |
| 카메라 이동·줌 | 한 화면 안에서 전부. 이동하면 마지막 정지 컷이 성립하지 않는다 |
| 파리 종류 추가, 무기 업그레이드 | 채 머리 하나의 감쇠 계수가 이 게임의 전부다. 부품을 늘리면 그게 흐려진다 |
| 화면을 덮는 파티클 | 파리와 채 머리를 가리는 순간 재미의 절반이 무효가 된다. 파편은 아래로만 튄다 |
| 세이브, 랭킹, 절차 생성, 네트워크 | 2분 안에 끝나는 게임에 붙일 자리가 없다 |
| 3D, 스프라이트, 외부 이미지·오디오 | 외부 에셋 0개 |
