# 쥐면 뭉개진다 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.
> **소재는 젓가락+두부가 아니라 집게+말랑한 덩어리(물풍선·젤리)다.** 사유는 기획 문서의 필수 수정 (2) 참조.

## 화면 구성

한 화면 고정.

```
┌──────────────────────────────────────────┐
│                                          │
│      ╲╱ ← 집게 (커서 위치)                │
│      ◍  ← 쥐고 있는 덩어리. 힘만큼 찌그러짐 │
│                                          │
│   ◯ ◯ ◯ ◯ ◯   ← 남은 덩어리 (크기 다름)   │
│   ═══════════                            │
│   ~~~  ← 부서진 자국 (미끄러운 지형)       │
│                        ▭ ← 목적지         │
└──────────────────────────────────────────┘
```

- **덩어리**: 원. **쥐는 힘만큼 실시간으로 눌린 타원이 된다.** 이게 힘 게이지를 대신한다
- **금**: 덩어리 위의 선. 누적될수록 늘어난다
- **밴드 표시**: 덩어리 테두리에 두 겹 링. 안쪽 링 = 유지 임계, 바깥 링 = 손상 임계. **금이 갈 때마다 두 링이 서로에게 다가온다**
- **자국**: 부서진 자리에 남는 반투명 얼룩. 그 위에서는 유지 임계가 오른다
- HUD 없음. 숫자·게이지·타이머 전부 없음

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 집게 위치 |
| 버튼 누르고 있기 | **쥐는 힘 상승** |
| 버튼 떼기 | 쥐는 힘 하강 |
| 아무 키 | 실패 후 즉시 재시작 |

버튼이 온/오프가 아니라 **적분기**다. 누른 시간이 힘이 된다.

## 상태와 판정

덩어리 하나의 상태.

| 변수 | 의미 |
|---|---|
| `grip` | 현재 쥐는 힘 (연속량). 버튼 누름/뗌으로 오르내림 |
| `holdMin` | 유지 임계. 이 아래면 미끄러진다 |
| `dmgMax` | 손상 임계. 이 위면 금이 쌓인다 |
| `cracks` | 누적 금 개수 |
| `state` | `ON_PLATE` / `HELD` / `SLIPPING` / `BROKEN` / `DELIVERED` |

**핵심 규칙 — 임계가 상수가 아니라 내 실패의 함수다**

```
금이 한 줄 갈 때마다:
    holdMin  +=  Δ_up      (갈라진 면이 미끄러워 더 세게 쥐어야 붙는다)
    dmgMax   -=  Δ_down    (이미 상한 것은 덜한 힘에도 부서진다)

밴드 폭 = dmgMax - holdMin
밴드 폭 ≤ 0  →  무슨 짓을 해도 부서진다  →  포기 판단이 여기서 생긴다
```

**전이**

```
grip < holdMin                 →  SLIPPING (예고 표시 먼저)
SLIPPING 중 회수 창 안에 grip 회복  →  HELD
SLIPPING 중 창 만료             →  ON_PLATE (떨어짐, 금 +1)
grip > dmgMax 인 시간 누적       →  cracks++
cracks ≥ CRACK_LIMIT           →  BROKEN (자국 생성)
목적지 도달 + HELD              →  DELIVERED
```

**회수 창**: "미끄러진 뒤 6프레임"이 아니라 **"미끄러질 조짐 표시가 먼저 뜨고, 그때부터 열린다."** 사람의 단순 시각 반응 시간이 200~250ms라 예고 없는 100ms 창은 실력이 아니라 확률이다.

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 의미 |
|---|---|---|
| `GRIP_RISE` / `GRIP_FALL` | — | 힘의 상승/하강 속도. 두드림 주파수를 정한다 |
| `holdMin` 초기 | 덩어리마다 다름 | 첫 접촉에서만 실측 가능 |
| `dmgMax` 초기 | 덩어리마다 다름 | 같음 |
| `Δ_up` / `Δ_down` | — | **밴드 좁아짐 속도. 이 안의 핵심 축** |
| `CRACK_LIMIT` | 3~4 | 부서지기까지의 금 |
| `SLIP_WARN_MS` | 150~200 | 조짐 예고 시간 |
| `RECOVER_MS` | 200~250 | 회수 창 |

## 콘텐츠 분량

- 스테이지 **6개**. 덩어리 임계 분포와 목적지 거리만 다르다
- 1판 30~45초, 전체 완주 3~4분
- 진행: 임계 편차 작음 → 큼 → 자국이 깔린 판 → 밴드 좁아짐 강함 → 목적지 멀어짐 → 종합
- 클리어 조건은 **여섯 중 넷** — 포기 판단이 규칙에 내장된다

레벨 셀렉트 필수.

## 오디오 (Web Audio 절차 생성)

| 사건 | 소리 |
|---|---|
| 쥐는 힘 | **연속 사인파. 힘이 그대로 음정.** 화면을 안 봐도 어느 쪽으로 죽는 중인지 귀로 안다 |
| 유지 임계 근접 | 저역으로 미끄러지며 흔들림 |
| 손상 임계 근접 | 배음이 거칠어짐 (약간의 왜곡) |
| 금 | 짧은 크랙 노이즈 |
| 미끄러짐 조짐 | 음이 아래로 흐르기 시작 |
| 부서짐 | 노이즈 버스트 + 음 소멸 |

**무음으로도 이해된다.** 힘은 찌그러짐으로, 임계는 두 겹 링으로, 금은 선으로 화면에 중복 표현된다.

## 승패와 흐름

```
타이틀 → 스테이지 선택 → 플레이 → (승리 | 패배) → 즉시 재시작
                                        ↓
                                  0.3초 만에 재배치
```

- 승리: 여섯 중 넷 이상 목적지 도달
- 패배: 남은 덩어리로 넷을 채울 수 없게 된 시점 (즉시 종료, 기다리게 하지 않는다)
- 판이 끝나면 화면에 남는 것: **자국의 개수와 위치.** 그게 성적표다

## 검증 훅 (AI 활용 기술 문서 재료)

- `window.__game`에 `{ grip, holdMin, dmgMax, cracks, band, tapRate, delivered }` 노출
- `scripts/balance-sim.ts`
  - **고정힘 봇** (두드리지 않고 임계 바로 위 한 값만 유지) 성공 개수 → **폐기 기준의 대상**
  - **두드림 봇** (초당 3~4회 톡톡) 성공 개수
  - 두 봇의 차이가 없으면 이 게임이 파는 손이 존재하지 않는다
  - 밴드 폭이 0에 도달하는 평균 시점 → 포기 판단이 실제로 발생하는지
- 결정론: 난수 0. 임계값은 스테이지 데이터에 고정
