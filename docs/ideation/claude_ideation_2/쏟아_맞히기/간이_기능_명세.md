# 쏟아 맞히기 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 카메라 이동 없음.

```
┌──────────────────────────────────────────┐
│                                          │
│         ● ← 커서(손). 화면 어디든         │
│         │   줄 (렌더는 가는 선 1개)       │
│         ╰─▽ ← 그릇. 커서를 지연 추종      │
│            ~~~ 안에 물 입자                │
│                                          │
│   ▲불   ▲불          ♦새싹  ♦새싹        │
│                                          │
│  [물 잔량 바 — 화면 하단 가로 한 줄]      │
└──────────────────────────────────────────┘
```

- **불**: 위로 뻗은 삼각형. 시간이 지나면 이웃 칸으로 번진다
- **새싹**: 작은 마름모. 성장 단계마다 형태가 커진다 (싹 → 잎 → 꽃)
- HUD는 물 잔량 바 하나뿐. 숫자·아이콘·타이머 없음

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 커서(=손) 위치. **이것이 전부다** |
| 아무 키 | 실패 후 즉시 재시작 |

버튼이 없다. 기울이기·붓기·조준 버튼이 전부 없고, **손을 움직이는 것 하나로 전부 표현된다.**

## 물리 — 3계층 지연

```
커서 위치  →  그릇 (감쇠 진자, 지연 1겹)  →  물 입자 (그릇 로컬 좌표계에서 다시 출렁임, 지연 2겹)
```

1. **그릇**: 커서에 매달린 감쇠 진자. 줄 길이 L 고정. 각도 θ는 커서 가속도에 반응
2. **물**: 입자 120~200개. 그릇 내벽과 충돌. 그릇이 기울면 관성으로 한쪽 벽을 탄다
3. **잔량 되먹임**: 물이 줄면 그릇 총질량이 줄어 진자 고유주기가 짧아진다 → 같은 손동작이 다른 결과를 준다

물 입자가 그릇 상단 테두리를 넘으면 자유 낙하로 전환. 이때부터는 표적 판정 대상이 된다.

## 판정 — 2축

물 입자가 표적 콜라이더에 닿으면 그 프레임에 카운트한다. **0.3초 창** 안에 누적된 입자 수로 판정한다.

| 표적 | 입자 < 하한 | 하한 ≤ 입자 ≤ 상한 | 입자 > 상한 |
|---|---|---|---|
| 불 | 아무 일 없음 | — | **꺼짐** |
| 새싹 | 아무 일 없음 | **한 단계 성장** | **즉시 시듦 (패배 조건)** |

새싹은 "가는 물줄기로 2초 연속"을 요구한다. 즉 판정 창을 연속으로 여러 번 통과해야 한 단계 오른다.

**새싹마다 자체 시들기 시계**를 둔다. 이것이 "서서 출렁임을 재우는" 지배 전략을 막는 유일한 부품이다.

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 무엇을 정하는가 |
|---|---|---|
| `ROPE_LENGTH` | 화면 높이의 15% | 진자 주기 |
| `BOWL_DAMPING` | — | 출렁임이 잦아드는 속도. **폐기 기준 1의 대상** |
| `PARTICLE_COUNT` | 120~200 | 물의 시각적 밀도 |
| `FIRE_THRESHOLD` | 입자 25개 / 0.3초 | 왈칵의 하한 |
| `SPROUT_MIN` / `SPROUT_MAX` | 3 / 10 | 졸졸의 허용 폭 |
| `SPROUT_WILT_SEC` | 6~10초 | 정지의 비용 |
| `WATER_PER_ROUND` | — | 판당 고정 지급 (우물 없음) |

## 콘텐츠 분량

- 스테이지 **6개** + 명시적 최종 화면
- 1스테이지 20~30초, 전체 완주 3~4분
- 난이도 진행: 불만 → 새싹만 → 섞임 → 불이 번짐 → 물 부족 → 종합

레벨 셀렉트 필수. 심사자가 엔딩에 도달하지 못하면 만든 것의 절반이 평가 대상에서 사라진다.

## 오디오 (Web Audio 절차 생성, 외부 파일 0개)

| 사건 | 소리 |
|---|---|
| 물이 그릇 벽을 침 | 저역 노이즈 버스트, 세기에 비례 |
| 물이 그릇 밖으로 나감 | 화이트노이즈 짧게 |
| 불 꺼짐 | 치익 (노이즈 감쇠) + 반음 상승 |
| 새싹 성장 | 사인파 짧게, 단계마다 반음 위 |
| 새싹 시듦 | 반음 아래로 미끄러짐 |

**무음으로도 전부 이해된다.** 소리는 전부 화면 정보의 중복이다.

## 승패와 흐름

```
타이틀 → 스테이지 선택 → 플레이 → (승리 | 패배) → 즉시 재시작 or 다음
                                        ↓
                                  0.3초 안에 재시작
```

- **승리**: 불 전부 꺼짐 + 새싹 전부 생존
- **패배**: 새싹 하나라도 시듦 / 물 소진 후 불 잔존
- 실패 연출 없음. 0.3초 재배치

## 검증 훅 (AI 활용 기술 문서 재료)

- `window.__game`에 `{ waterLeft, firesOut, sproutStages[], spillEvents[] }` 노출
- `scripts/balance-sim.ts` — 고정 타임스텝 헤드리스로 봇 플레이. 다음 두 가지를 수치로 증명한다
  - **정지 봇**(가만히 서서 출렁임 재우고 조준) 클리어율이 40%를 넘으면 실패
  - 잔량 100% / 40%의 착탄 분산이 그릇 지름보다 큰지
- 결정론: 고정 시드 + 고정 타임스텝. 같은 입력 → 같은 결과

## 범위 밖

- 우물 왕복 이동 (지루한 구간 + 출렁임 리셋 구멍을 동시에 만든다)
- 물 종류 추가, 그릇 업그레이드, 콤보 배수
- 세이브, 랭킹, 절차 생성, 네트워크
- 3D, 스프라이트, 외부 이미지·오디오 파일
