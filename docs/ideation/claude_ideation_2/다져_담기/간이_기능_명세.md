# 다져 담기 — 간이 기능 명세

> 고도화 전 단계의 골격만. 수치는 전부 튜닝 대상이다.

## 화면 구성

한 화면 고정. 상자가 화면 중앙 부근에서 커서를 따라 움직인다.

```
┌──────────────────────────────────────────┐
│   ◆ ← 다음 조각 (큰 도형으로 예고)        │
│                                          │
│              ▽ ← 낙하 중인 조각           │
│                                          │
│   ┌─────────────┐                        │
│  ╌│╌╌╌╌╌╌╌╌╌╌╌╌│╌ ← 넘으면 지는 선        │
│   │   ◣ ▲ ◆    │  ← 큰 조각(채도 높음)    │
│   │ ▪▫▪▫▪▫▪▫▪▫ │  ← 알갱이 층             │
│   └─────────────┘                        │
│         ↑ 상자 = 커서                     │
└──────────────────────────────────────────┘
```

- **상자**: 뚜껑 없는 U자. 세 변만 콜라이더
- **선**: 상자 상단을 가로지르는 점선. 더미의 어느 꼭짓점이라도 넘으면 패배
- **큰 조각**: 단색 채도를 확 올려 더미 안에서도 실루엣으로 읽힌다
- **알갱이 층**: 작은 원 200~400개. 상시 깔려 있다. **이게 이 게임의 물리 전제다**
- HUD는 남은 조각 수 하나뿐. 타이머 없음

## 입력

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 상자 위치. **이것이 전부다** |

**회전 키 없음. 좌우 이동 키 없음. 드롭 키 없음.** 코드에 존재하지 않는다.

세 가지 움직임은 별도 입력이 아니라 **마우스 이동의 크기와 주파수**로 구분된다.

| 이름 | 판별 | 물리 결과 |
|---|---|---|
| 툭툭 | 진폭 1~2px, 고주파 | 알갱이 층에 미세 진동 → 다짐 + 브라질너트 |
| 밀기 | 진폭 20~40px, 수평 | 관성으로 더미가 한쪽 벽에 쏠림 |
| 쾅 | 진폭 100px+, 하강 | 더미 전체 부양 → 큰 조각 침강 + 가장자리 튐 |

## 물리

```
알갱이 층 (원 200~400개)  ←  이 층 안에서 큰 조각이 뜨고 가라앉는다
       +
낙하 조각 (다각형 8~10개, 크기 편차 큼)
       +
상자 (U자 콜라이더, 커서 추종. 커서 속도가 그대로 상자 속도)
```

**핵심 현상**: 반복 진동 → 작은 알갱이가 큰 조각 아래 틈으로 파고듦 → 큰 조각이 상대적으로 상승. 이것이 브라질너트 효과이고, **이 게임의 유일한 지배 전략 방어**다.

이 현상이 실제로 나오는지가 아래 폐기 기준의 전부다.

## 판정

| 조건 | 결과 |
|---|---|
| 남은 조각 0 + 모든 꼭짓점이 선 아래 | **승리** |
| 어느 꼭짓점이든 선을 넘고 0.3초 유지 | **패배** |
| 조각·알갱이가 상자 밖으로 이탈 | **즉시 패배** |

## 파라미터 (튜닝 대상)

| 이름 | 초기값 후보 | 의미 |
|---|---|---|
| `GRAIN_COUNT` | 200~400 | 알갱이 수. **문헌 조건의 하한** |
| `PIECE_COUNT` | 8~10 | 한 판의 조각 수 |
| `RUN_SEC` | 15~20 | 판 길이 |
| `SIZE_RATIO` | 큰 조각 / 알갱이 ≥ 5 | 브라질너트 성립 조건 |
| `LINE_HEIGHT` | 상자 높이의 80% | 여유 폭 |
| `ESCAPE_MARGIN` | — | 튐 판정 관용 |

## 콘텐츠 분량

- 스테이지 **6개**. 조각 크기 분포와 선 높이만 다르다
- 1판 15~20초, 전체 완주 2~3분
- **조각 순서는 매 판 다시 뽑는다.** 고정 순서는 죽을 때마다 이미 잘하는 구간을 복습시킨다
- 진행: 알갱이만 → 작은 조각 → 큰 조각 등장 → 선이 낮아짐 → 크기 편차 큼 → 종합

레벨 셀렉트 필수.

## 오디오 (Web Audio 절차 생성)

| 사건 | 소리 |
|---|---|
| 툭툭 | 짧은 저역 클릭. 알갱이 접촉 수에 비례한 노이즈 |
| 다짐 성공(표면 하강) | 사각사각 (필터 노이즈), 하강량만큼 |
| 쾅 | 큰 저역 임팩트 + 0.1초 정적 |
| 큰 조각 부상 | 저역 사인이 서서히 올라감 (경고) |
| 이탈 | 높은 톤 하나, 즉시 컷 |

**무음으로도 전부 이해된다.** 다짐량은 표면 높이로, 큰 조각 위치는 채도로 보인다.

## 승패와 흐름

```
타이틀 → 스테이지 선택 → 플레이 → (승리 | 패배) → 즉시 재시작
                                        ↓
                                  0.3초 만에 재배치
```

- 이탈 순간 화면이 붉어지며 즉시 종료. 이탈한 조각의 궤적을 0.4초 남긴다 (실패 귀속)
- 승리 시 더미 전체가 한 번 주저앉으며 정착 (보상 연출)

## 검증 훅 (AI 활용 기술 문서 재료)

- `window.__game`에 `{ tapCount, largestPieceY, surfaceHeight, escapeEvents, grainContacts }` 노출
- `scripts/brazil-nut-check.ts` — **폐기 기준 전용 스크립트. 게임 코드 없이 물리만 돌린다**
  - 고정 타임스텝으로 1만 판
  - 탭 횟수 대비 `largestPieceY` 회귀 → 기울기 + 산점도 PNG 출력
  - 기울기 ≤ 0 이면 CI 실패
- `scripts/balance-sim.ts` — 봇 정책 비교
  - **툭툭 봇** (약하게만 무한 반복) 클리어율
  - **혼합 봇** (툭툭 + 주기적 쾅) 클리어율
  - 두 봇 차이가 0에 가까우면 3단 상충이 존재하지 않는다는 뜻
- 결정론: 고정 시드. 알갱이 초기 배치까지 시드에서 나온다
