# [주제 5] 에코 드리프트 (Echo Drift)
> **비트 동기화 바운스 & 반사 보스 러시 (Beat-Synced Reflect Bullet Hell)**

---

## 1. 게임 개요 및 하이 콘셉트 (High Concept)

- **핵심 한 줄 콘셉트**: 절차적 음원 비트(BPM)에 맞춰 폭풍처럼 쏟아지는 탄막을 박자에 맞춰 튕겨내거나(Parry) 회피하여 보스를 타격하는 리듬 센싱 바운스 액션.
- **타겟 플레이어**: 'Just Shapes & Beats', 'Cuphead', 'Crypt of the NecroDancer' 등 음악과 탄막 액션의 조화를 좋아하는 플레이어.
- **비주얼 스타일**: 화려한 형광 오디오 비주얼라이저 스타일 (Neon Reactive Spectrum) — 비트에 맞춰 화면 전체가 박동하고 진동하는 시각적 쾌감.

---

## 2. 핵심 게임플레이 루프 (Core Gameplay Loop)

```
[음악 BPM 박자 감지] ➔ [비트 패턴 탄막 생성 (보스 공격)]
         ↑                                        │
         │                                [퍼펙트 패링/대쉬 회피]
         │                                        │
[다음 음악 트랙/보스 해금] ◄────────────── [반사 탄막으로 보스 체력 0]
```

1. **비트 분석 탄막**: 내장된 절차적 Web Audio 음악의 킥/스네어 비트에 맞춰 보스가 정교한 탄막 패턴을 생성합니다.
2. **리듬 타이밍 패링**: 박자에 맞춰 클릭/스페이스바를 누르면 반사 쉴드가 발동하여 적의 탄막을 보스에게 반사(Reflect)시켜 데미지를 줍니다.
3. **드리프트 대쉬**: 비트가 몰아치는 드롭(Drop) 구간에서는 무적 대쉬로 공간을 가르며 아이템을 획득합니다.

---

## 3. AI 에이전트 기반 1주일 제작 전략

### (1) 코드 구조 및 AI 에이전트 프롬프팅 포인트
- **Web Audio Synth & Beat Analyzer**: Synth 음원 생성 및 FFT / Peak Detection으로 BPM 타임스탬프 계산 (AI 코드가 Canvas2D/Web Audio API 조합으로 깔끔히 작성).
- **Bullet Pool Manager**: 메모리 과부하 없는 오브젝트 풀링(Object Pooling) 기반 탄막 엔진.
- **Parry Window Logic**: 비트 타임스탬프와 입력 타임스탬프 차이를 계산하는 Perfect / Great / Miss 판정 엔진.

### (2) 개발 분량 및 1주일 스케줄 (7-Day Sprint)
- **Day 1**: Web Audio API 비트 동기화 엔진 및 2D 탄막 오브젝트 풀링 AI 개발.
- **Day 2**: 패링(Reflect) 타이밍 판정 및 보스 HP 데미지 반사 시스템 구현.
- **Day 3**: 보스 패턴 3종(원형 탄막, 비트 레이저, 분선 추적 탄막) 구현.
- **Day 4**: 오디오 비주얼라이저 (비트에 반응하여 펄스치는 배경 파티클 및 그리드 연출).
- **Day 5**: 3가지 난이도 트랙 사운드 완성, 쥬시한 효과음, 랭킹 스코어 화면 추가.
- **Day 6**: 오디오-입력 동기화 딜레이 튜닝 및 하이라이트 영상 촬영.
- **Day 7**: 최종 패키징 제출 및 AI 기술 서류 완성.

## 4. 간이 기능 명세서 (MVP Specs)

| 카테고리 | 주요 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **비트 감지** | Web Audio Peak Detector | 음원의 BPM 및 킥/스네어 주파수 이벤트를 실시간 캡처 |
| **탄막 반사** | Rhythm Parry System | 비트에 맞춰 패링 성공 시 탄막이 보스를 향해 유도 탄환으로 반사 |
| **시각 연출** | Dynamic Audio Visualizer | 오디오 주파수에 따라 반응하는 네온 스펙트럼 라인 및 사운드 웨이브 |
| **보스 패턴** | Beat Pattern Machine | 비트 스템(Stem) 데이터에 따라 탄막의 속도, 각도, 색상이 다이나믹하게 변함 |
| **조작성** | Rhythm Dash & Shield | 8방향 이동 + 비트 반사 쉴드 + 비트 무적 대쉬 3버튼 간결 조작 |

## 5. NAN 2026 해커톤 검증 및 우수성

1. **시각적/청각적 압도**: 음악의 비트에 맞춰 화려한 네온 탄막과 파티클이 폭발하고 패링 이펙트가 터지는 시연 영상은 최고 점수를 받기에 매우 유리함.
2. **AI 제작 최적성**: Web Audio API 기반 오디오 합성 및 수학적 탄막 공수 계산은 에이전트 AI가 오차 없이 정밀하게 짜냄.
3. **독자적 오프라인 구동**: 외부 음원 파일 의존 없이 Web Audio Synth로 음악을 자가 생성하므로 저작권 문제 및 네트워크 소스 문제가 0%.
