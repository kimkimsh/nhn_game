# [주제 1] 크로노스 에코 (Chronos Echo)
> **시간 역전 분신 협동 액션 퍼즐 (Time-Loop Shadow Co-op Puzzle)**

---

## 1. 게임 개요 및 하이 콘셉트 (High Concept)

- **핵심 한 줄 콘셉트**: 10초 단위 시간 루프 속에서 과거의 '나(분신)'들과 시차 협동을 펼쳐 던전을 돌파하는 싱글 플레이 액션 퍼즐 게임.
- **타겟 플레이어**: 신선한 메커니즘, 뇌지컬과 피지컬이 조합된 퍼즐 액션 및 깔끔한 그래픽을 선호하는 게이머.
- **비주얼 스타일**: 네온 사이버펑크 2D 미니멀리즘 (Neon Vector Art) — 연산 부담이 적고 AI 에이전트가 Canvas2D/WebGL 파티클로 고품질 연출 구현 가능.

---

## 2. 핵심 게임플레이 루프 (Core Gameplay Loop)

```
[스테이지 진입] ➔ [10초간 행동 수행 (버튼 작동/적 유인)] ➔ [시간 역전 (루프)]
       ↑                                                            │
       └─────── [과거 잔상(분신) 생성 + 현 회차 플레이어 동시에 수행] ──────┘
                                  │
                          [결승점 도달시 클리어]
```

1. **녹화 및 실행**: 각 루프(10초) 동안 플레이어의 위치, 이동, 공격, 스위치 조작이 자동 기록됩니다.
2. **분신(Echo) 생성**: 루프가 종료되거나 리셋 버튼을 누르면 시간이 0초로 돌아가며, 이전 루프의 플레이어 잔상(Echo)이 똑같이 행동합니다.
3. **복합 협동**: 최대 4~5개의 분신과 함께 스위치 누르기, 발판 유지, 적의 총알 막아주기, 동시에 보스 협공하기 등을 수행합니다.

---

## 3. AI 에이전트 기반 1주일 제작 전략

### (1) 코드 구조 및 AI 에이전트 프롬프팅 포인트
- **State Recording System**: 프레임 단위 `InputState { x, y, action, timestamp }` 배열 기록 및 재생 컴포넌트 (AI가 100줄 이내로 완벽히 구현 가능한 단순 구조).
- **Collision & Physics**: Grid 기반 또는 AABB 2D 사각형 충돌 처리.
- **Stage Data**: JSON 형태의 스테이지 레이아웃 (`{ wall: [], switch: [], door: [], spawn: [] }`).

### (2) 개발 분량 및 1주일 스케줄 (7-Day Sprint)
- **Day 1**: 2D Canvas 기본 플레이어 이동 + 프레임 단위 행동 레코더/플레이백 엔진 AI 구현.
- **Day 2**: 스위치, 문, 이동 플랫폼, 레이저 트랩 등 퍼즐 상호작용 레이어 완성.
- **Day 3**: 보스 패턴 및 전투 분신 상호작용 (분신이 적의 공격을 탱크해주거나 동시 타격).
- **Day 4**: 10개 핵심 스테이지 기획 및 JSON 맵 배치 + UI/UX (시간 타이머, 루프 수 표시).
- **Day 5**: 네온 잔상 효과, 시간 역전 쉐이더/파티클, 사운드 이펙트 쥬시(Juicy) 폴리싱.
- **Day 6**: QA, 난이도 튜닝, 사전 제출용 시연 영상 촬영 (클리어 장면 컷집).
- **Day 7**: 빌드 패키징 + 사전 제출 서류 (게임 소개서 & AI 활용 기술 문서) 최종 점검.

## 4. 간이 기능 명세서 (MVP Specs)

| 카테고리 | 주요 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **코어 시스템** | Time Recorder & Player | 플레이어 입력 벡터 저장 및 `EchoAgent` 인스턴스 재생 |
| **퍼즐 요소** | Multi-Pressure Switch | N개의 스위치를 동시에 누르거나 순서대로 눌러야 열리는 문 |
| **퍼즐 요소** | Kinetic Shield Shadow | 이전 분신이 쉴드를 켜서 현재 플레이어를 레이저로부터 보호 |
| **전투 요소** | Combo Strike Boss | 보스의 쉴드를 3방향에서 동시에 때려야 파괴되는 기믹 |
| **시각 연출** | Time Rewind Effect | 시간 역전 시 화면 반전, 잔상 파티클 및 틱톡 글리치 이펙트 |

## 5. NAN 2026 해커톤 검증 및 우수성

1. **직관적인 시연 영상 파급력**: 영상으로 보았을 때 분신 4개가 동시에 움직여 난관을 해결하는 모습이 시각적으로 매우 화려하고 독창적임.
2. **AI 에이전트 개발 최적성**: 단순 배열 구조의 Input Recording 시스템이라 AI 코딩 에이전트가 버그 없이 100% 코드를 생성해낼 수 있음.
3. **오프라인 싱글 완성도**: 네트워크 의존성 전혀 없이 100% 로컬 프레임 버퍼로 작동하여 제출 빌드의 안정성이 보장됨.
