# [주제 2] 엘리멘탈 알케미스트 (Elemental Alchemist)
> **물리·화학 연쇄 반응 실시간 카드 디펜스 (Chain-Reaction Element Defense)**

---

## 1. 게임 개요 및 하이 콘셉트 (High Concept)

- **핵심 한 줄 콘셉트**: 5가지 원소 카드(불, 물, 번개, 바람, 기름)를 타일 필드에 조합·투척하여 폭발적 연쇄반응으로 몰려드는 적을 퇴치하는 실시간 캐주얼 전략 디펜스.
- **타겟 플레이어**: '전염병 주식회사'나 '알케미 솔로'류의 조합 반응의 재미, 뱀파이어 서바이버 방식의 쾌감 및 덱빌딩 전략을 즐기는 플레이어.
- **비주얼 스타일**: 셀 애니메이션 느낌의 풍부한 원소 파티클 2D 캐주얼 스타일 — CSS/Canvas 그래디언트와 파티클 효과로 AI가 손쉽게 화려한 연출 완성.

---

## 2. 핵심 게임플레이 루프 (Core Gameplay Loop)

```
[원소 드로우 (마나 소비)] ➔ [필드/적에게 원소 카드 드래그 투척]
           ↑                                        │
           │                                 [원소 상극/합성 연쇄 반응]
           │                                        │
[카드 덱 보상 & 원소 도감 해금] ◄────── [웨이브 방어 및 보스 처치]
```

1. **상소 반응 시스템**:
   - **기름(Oil) + 불(Fire)** = 대폭발 & 화염지대 형성 (지속 데미지)
   - **물(Water) + 번개(Lightning)** = 넓은 범위 감전 및 기절 (AoE Stun)
   - **바람(Wind) + 화염지대** = 화염 소용돌이 확산 (범위 3배 증가)
   - **물(Water) + 불(Fire)** = 증기 폭발 (적 둔화 및 시야 차단)
2. **덱 빌딩 & 실시간 투척**: 마나 차오르는 속도에 따라 카드를 적절한 타일이나 적 무리에 드래그 앤 드롭.

## 3. AI 에이전트 기반 1주일 제작 전략

### (1) 코드 구조 및 AI 에이전트 프롬프팅 포인트
- **Element Interaction Matrix**: 2차원 해시 테이블 기반 원소 반응 규칙 엔진 (`ReactionTable[ElemA][ElemB] => Multiplier, EffectType, SpawnEntity`).
- **Entity Component Particle System**: 파티클 및 몬스터 상태 이상(Poison, Burn, Wet, Stun) 관리자.
- **Card Deck Logic**: 손패(Hand), 덱(Deck), 버린 카드(Discard Pile) 단순 상태 머신.

### (2) 개발 분량 및 1주일 스케줄 (7-Day Sprint)
- **Day 1**: 5대 원소 카드 드래그 앤 드롭 UI 및 반응 마트릭스 코어 로직 AI 구현.
- **Day 2**: 몬스터 이동 경로(Pathfinding/Grid Movement) 및 웨이브 생성 스폰 시스템 구축.
- **Day 3**: 연쇄 폭발(Chain Reaction) 및 파티클 연출, 원소 조합 콤보 텍스트 이펙트 추가.
- **Day 4**: 3가지 스테이지 테마(숲, 장막의 동굴, 화산) & 보스 몬스터 패시브/패턴 기획.
- **Day 5**: 사운드 효과(폭발음, 감전음, 바람 소리) 및 덱 편집 / 유물(Relic) 시스템 추가.
- **Day 6**: 밸런스 조정(원소 데미지 계수 튜닝) 및 하이라이트 영상 촬영.
- **Day 7**: 최종 패키징 및 사전 제출 서류 문서화 작성.

## 4. 간이 기능 명세서 (MVP Specs)

| 카테고리 | 주요 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **원소 반응 엔진** | 2D Reaction Matrix | 불, 물, 번개, 바람, 기름 5개 원소 간 10가지 조합 반응 구현 |
| **덱 관리** | Dynamic Deck System | 전투 중 승리 시 새로운 원소 카드/강화 카드 선택 및 덱 구성 |
| **필드 환경** | Interactive Terrain | 풀밭(불에 타버림), 웅덩이(전기 전도), 기름통(폭발 위험) 등 환경 요소 |
| **전투 요소** | Wave & Elite Boss | 일반 몬스터 웨이브 + 특수 면역 상태를 가진 엘리트 보스 3종 |
| **시각 연출** | Dynamic Chain VFX | 연쇄 반응 시 화면 흔들림(Screen Shake) 및 콤보 스코어 연출 |

## 5. NAN 2026 해커톤 검증 및 우수성

1. **중독성 넘치는 쾌감**: 연쇄 폭발이 터질 때 몬스터들이 일제히 소멸하는 장면은 영상 및 심사에서 압도적인 재미를 전달함.
2. **AI 제작 효율성**: 룰 기반의 연소/합성 테이블은 에이전트 AI가 모듈식으로 순수 JS/TS로 아주 빠르게 작성 가능.
3. **독창적 장르 융합**: 디펜스 + 덱빌딩 + 물리화학 반응 3가지 요소를 오프라인 싱글 규격에 맞춰 완벽히 다듬음.
