# [주제 4] 던전 프로그래머 (Dungeon Programmer)
> **비주얼 블록 노드 프로그래밍 자동 탐사 로그라이크 (Visual Logic Automation Rogue)**

---

## 1. 게임 개요 및 하이 콘셉트 (High Concept)

- **핵심 한 줄 콘셉트**: 직접 조작 대신 '조건-행동(IF-THEN)' 비주얼 로직 블록을 조립하여 용사의 AI 행동 알고리즘을 짜준 뒤 던전에 투입해 전투를 관전하고 튜닝하는 전략 자동 탐사 게임.
- **타겟 플레이어**: 'Autonauts', 'Despot's Game', '코딩 게임' 및 퍼즐/자동화 전략 장르를 선호하는 유저 및 해커톤 심사위원.
- **비주얼 스타일**: 레트로 8비트 픽셀 또는 네온 회로보드 아키텍처 — 회로판과 기계 던전 느낌을 가미한 직관적 2D 뷰.

---

## 2. 핵심 게임플레이 루프 (Core Gameplay Loop)

```
[로직 편집기에서 블록 조립] ➔ [던전 투입 (자동 전투 관전)]
           ↑                                    │
           │                            [전투 데이터/로그 분석]
           │                                    │
[새 로직 블록 & 아이템 해금] ◄────────── [실패 원인 수정 & 파밍]
```

1. **로직 블록 조합**:
   - `IF (적과의 거리 < 2m) THEN [화염베기]`
   - `IF (체력 < 30%) THEN [포션 마시기]`
   - `IF (적군 타입 == 힐러) THEN [우선 타겟 지정]`
2. **던전 오토 크롤링**: 플레이 버튼을 누르면 용사가 작성된 알고리즘대로 이동하고 전투를 수행합니다.
3. **디버깅 & 최적화**: 몬스터에게 패배하면 전투 로그(Combat Log)를 분석하여 어떤 조건문이 잘못되었는지 수정합니다.

---

## 3. AI 에이전트 기반 1주일 제작 전략

### (1) 코드 구조 및 AI 에이전트 프롬프팅 포인트
- **Behavior Tree / AST Evaluator**: 프레임마다 블록 노드 순서대로 조건 평가 (`evalNode(node, context)`). AI 에이전트가 인터프리터 패턴으로 깔끔하게 구현 가능.
- **Visual Block Drag&Drop Framework**: HTML5 Canvas / DOM 기반 드래그 앤 드롭 블록 UI.
- **Procedural Dungeon Rooms**: 룸 단위 자동 생성기 (Room-based Grid Dungeon).

### (2) 개발 분량 및 1주일 스케줄 (7-Day Sprint)
- **Day 1**: 비주얼 로직 블록(IF, THEN, target, skill) 드래그 앤 드롭 UI 및 AST 인터프리터 개발.
- **Day 2**: 용사 몬스터 자동 전투 2D 필드 엔진 및 애니메이션/이펙트 연결.
- **Day 3**: 전투 데이터 분석기 (데미지 그래프, 실패 시점 타임라인 디버그 로그) 추가.
- **Day 4**: 20여 종의 신규 조건/행동 블록(예: 방어 태세, 텔레포트, 독 구름) 및 던전 층수 설계.
- **Day 5**: 픽셀 아트/파티클 연출, 사운드 이펙트 및 UI 디자인 연동.
- **Day 6**: 다양한 던전 환경(기계 던전, 독성 늪지대) 균형 튜닝 및 소개 영상 촬영.
- **Day 7**: 빌드 패키징 및 NHN 제출용 AI 기술서(개발 과정에 사용한 AI 프롬프트) 완료.

## 4. 간이 기능 명세서 (MVP Specs)

| 카테고리 | 주요 기능 | 상세 설명 |
| :--- | :--- | :--- |
| **블록 에디터** | Block Logic Compiler | 드래그 앤 드롭으로 조건(Condition)과 행동(Action) 노드를 결합 |
| **전투 인터프리터** | Real-time AST Runner | 0.1초 마다 용사의 주변 환경을 스캔하여 로직 트리 실행 |
| **디버그 타임라인** | Combat Log Analyzer | 용사 사망 시 몇 번째 조건문에서 병목이 생겼는지 시각적 리플레이 제공 |
| **몬스터 패턴** | Tactical Enemy AI | 플레이어의 로직을 파회하는 다양한 특성(격파, 스턴, 보호막)의 적 |
| **로그라이크 요소** | Relic & Block Shop | 층을 클리어할 때마다 새로운 고성능 조건 블록이나 스탯 유물 구매 |

## 5. NAN 2026 해커톤 검증 및 우수성

1. **NHN AI 해커톤 주제와 최고의 상징적 부합**: "AI를 활용해 만든 게임"인 동시에 게임 플레이 자체가 "나만의 AI 용사를 프로그래밍하는 게임"이라 심사 위원의 눈길을 사로잡음.
2. **AI 에이전트 코딩 용이성**: 인터프리터 패턴과 블록 데이터 구조(`JSON tree`)는 LLM AI가 가장 정밀하고 잘 짜는 영역임.
3. **독창적 시연 영상**: 블록을 수정하자마자 고전하던 보스를 완벽하게 공략해내는 리플레이 장면이 강렬함.
