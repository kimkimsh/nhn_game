# 흘리며 간다 — 간이 기능 명세

> 이전 이름 「먹칠하기」. 서예 껍데기(붓·먹·종이·낙관)를 전부 벗기고 재료를 교체한 뒤 개명했다.

## 목표

매 순간 나를 향한 삼각형의 수를 최대로 유지한다. 그 수가 바닥나면 진다.

## 화면

한 화면. 계측 도면 톤(격자 + 치수 보조선 + 단색 3개).

```
┌──────────────────────────────────────────────┐
│  ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲  ← 삼각형 40 (각도만)    │
│ ▲                        ▲                   │
│ ▲   ═══════╲             ▲  ← 내 띠            │
│ ▲      ●    ╲___         ▲     ● 자루          │
│ ▲          ▪▪ ← 무더기(지형) ▲                 │
│ ▲   [경쟁 자루 3개가 각자 그린다]  ▲            │
│  ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲ ▲                        │
└──────────────────────────────────────────────┘
```

## 입력

마우스 이동만. 클릭·키보드·휠 없음. pointer lock 없음.

| 손동작 | 결과 |
|---|---|
| 크고 이어진 **열린 곡선**을 그린다 | 굵은 띠가 남는다. 시선 견인력이 오른다 |
| **닫힌 원**을 그린다 | 시작점과 끝점의 모래가 겹쳐 번져 **손해** |
| 0.6초 이상 멈춘다 | 그 자리에 모래 무더기가 쌓인다 → **지형이 된다** |
| 고주파로 떤다 | 자루가 지수감쇠로 따라오므로 **스무딩에서 소멸. 아무 효과 없음** |

**판정에 쓰는 값**: 300ms 시간창의 꺾임각 합 + 궤적 길이. 절대 픽셀·속도 임계값 없음. 정규화가 필요하면 세션 첫 3초의 자기 최대 궤적으로만 한다.
**곡률의 부호가 뒤집힐 때마다 띠에 마디가 생긴다** — 부호는 OS 가속·DPI·마우스 각도 스내핑에 완전 불변이다.

## 코어 루프 (1.0~1.3초)

```
크게 긋는다 → 삼각형이 하나씩 이쪽으로 돈다 → 경쟁 자루가 더 크게 긋는다
   → 한꺼번에 도로 돈다 → 더 크게 그을 것인가 / 잠깐 멈춰 함정을 놓을 것인가
```

## 시스템 5개

### 1. 삼각형 40 — 점수판이자 심판 (씨앗 2 · 9 · 24)
- 자리 고정. **각도만** 회전: `angle → lerp(angle, atan2(target.y - y, target.x - x), k)`
- **대상은 삼각형마다 다르다.** 각 삼각형은 네 자루의 띠 각각에 대해 아래 견인력을 계산하고 **자기에게 가장 센 것**을 본다:

  ```
  견인력 = (띠 굵기) × (끊기지 않은 연속 길이) ÷ (그 띠까지의 거리 + 1)
      굵기       = 자루의 이동 속도에 비례
      연속 길이  = 마디·끊김 없이 이어진 구간의 길이
  ```

- 그래서 점수가 **0 아니면 40인 이진값이 아니라 0~40의 분포**가 된다. 화면 한쪽 삼각형들은 나를 보고 반대쪽은 남을 보는 상태가 정상이고, 띠가 끊기면 **그 근처 서너 개만** 돌아선다.
- 스태거 40~80ms, 회전 420~580ms.
- **나를 향한 개수가 곧 점수.** 게이지·숫자판 없음.
- 눈도 점 두 개도 안 그린다. 각도가 전부다.

### 2. 모래 — 물성 압박 (지침 9)
- 자루에서 계속 샌다. 이동 속도가 빠를수록 띠가 굵다.
- **0.6초 이상 정지 → 그 자리에 무더기.** 무더기는 사라지지 않는다.
- 무더기 위를 지나는 자루(나 포함)는 튀어 올라 **띠가 끊긴다.** 끊긴 띠는 시선을 못 끈다.
- 시계도 게이지도 없는데 멈춰도 손해, 계속해도 손해라 손이 50초 내내 못 쉰다.

### 3. 경쟁 자루 3 — 자율 행위자
- 각자 자기 리듬으로 판 위를 달린다. 내가 조종하지 않는다.
- **하나는 명백히 더 짧은 길을 두고 굳이 판 바깥을 크게 돌아 들어온다**(비효율적 경로 = 무료 캐릭터성). 얘가 시선을 제일 많이 뺏는다.
- 내 무더기를 밟으면 튀어 오르며 띠가 끊긴다 → **내 실패가 남의 지형이 된다**(씨앗 11).

### 4. 판 밖 흙 — 나갈 수는 있지만 아무도 안 보는 곳
- 삼각형 40개는 판 둘레에 앉아 **판 안쪽만** 본다. 판 밖으로 나간 띠는 견인력 계산에서 거리가 급격히 멀어져 사실상 0이 된다.
- 그런데 판 밖은 **넓고 아무도 안 지나가서 띠가 안 끊긴다.** 가장 굵고 가장 긴 띠를 그을 수 있는데 아무도 안 본다.
- 0:12의 웃음이 여기 있다 — 한꺼번에 시선을 뺏긴 자루가 **판 밖으로 나가면서까지 띠를 이어 긋는다.**

> 이전 판본에 있던 "심판 막대"는 삭제했다. 화면에 안 보이는 채점 규칙(등진 구역은 계산 안 함)이라 "삼각형의 방향이 유일한 표시 장치"와 정면으로 충돌했다.

### 5. 판 간 지속 (초기화 없음)
- 무더기와 띠는 **다음 판 시작 지형**이다. 바닥을 고르지 않는다.
- **내가 지난 판에 놓은 무더기에 내가 걸린다.**
- 판을 거듭할수록 내 바닥만 더러워지고 옆자리 셋은 여전히 깨끗하다 — **이 게임의 웃음이 세션 규모로 커진다.**

## 놀람 3회 — 서로 다른 축

| 시각 | 이름표 | 축 |
|---|---|---|
| 0:06 | 옆 자루 | 갑작스러운 등장 (경쟁 자루가 판 바깥에서 크게 돌아 들어온다) |
| 0:30 | 바닥 갈라짐 | 판 변형 (이미 그은 띠가 두 조각으로 갈리고 갈라진 자리는 못 넘는다) |
| 0:45 | 네 번째 자루 | 갑작스러운 등장 + 판 전체 횡단 (마흔 개가 견인력 규칙 그대로 그쪽으로 정렬) |

## 실패 2층

- **1층** — 손이 멈춰 무더기가 생기고 다음 띠가 그 위에서 튀어 끊긴다. 끊기는 순간 **그 근처 삼각형 서너 개만** 다른 자루 쪽으로 돈다(견인력이 거리로 나뉘므로 국소적이다). 판당 14회 이상, 1.0~1.3초, 손해 0, 다시 그으면 시선이 돌아온다. 무더기 100% 보존.
  - **0:12**이 그 첫 큰 사례다. 옆 자루가 더 굵은 띠를 긋자 다수가 한꺼번에 돌아서고, 남겨진 내 자루가 판 밖 흙까지 띠를 이어 긋는다.
- **2층** — **0:45에 최종 점수가 확정된다.** 그 직후 새 자루가 판을 통째로 가로지르는 거대한 띠를 남기고, 마흔 개가 30ms 스태거로 순차 회전해 전부 그쪽을 본다. 마지막 0.5초는 정지 화면.

## 승패

- 매 순간 나를 향한 삼각형 수를 시간에 대해 **누적 적분**한 값이 점수. **0:45에 확정된다.**
- 순간값이 0이 되어도 지지 않는다 — 다시 그으면 돌아온다. **2층의 전원 이탈은 점수 확정 후이므로 점수를 0으로 만들지 않는다.**
- 화면에 숫자·시계·게이지 없음. **삼각형의 방향이 유일한 표시 장치.**

## 소리

무음으로 100% 성립. Web Audio 예산은 **마흔 개가 한꺼번에 도는 순간의 임팩트 1종**에 전량 투입.

## 안전 가드 (구현 시 하드 룰)

- 삼각형에 눈·표정선·손가락 없음. **각도만.**
- 아무도 다치지 않고 아무것도 부서지지 않는다.
- "잘 쓴 글씨" 같은 정답을 만들지 않는다 — 사전지식 의존 감점 차단.
- 붓·먹·종이·낙관·서예 어휘를 기획서와 화면 어디에도 쓰지 않는다.
