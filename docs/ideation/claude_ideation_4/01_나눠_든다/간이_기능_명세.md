# 나눠 든다 — 간이 기능 명세

## 목표

회색 덩어리를 최대한 남긴 채 널빤지를 검사대까지 끌고 간다. 도착 시 널빤지 위에 남은 부피가 곧 점수다.

## 화면

한 화면. 스크롤 없음. 관심 영역 3개 상한.

```
┌──────────────────────────────────────────────┐
│  격자 · 치수 보조선 (계측 도면 톤, 단색 3개)   │
│                                              │
│      ╭───────────╮                    ▮ 검사대│
│      │ 회색 덩어리 │  ← 널빤지            ▮ 심판3│
│      ╰───────────╯                          │
│    ○ ○  ← 도우미(조각 이고 따라 걷는 중)      │
│                                     ◔ 큰 도형 │
└──────────────────────────────────────────────┘
```

## 입력

마우스 이동만. 클릭·키보드·휠 없음. pointer lock 없음.

| 손동작 | 결과 |
|---|---|
| 커서를 진행 방향으로 끈다 | 널빤지가 2차 감쇠로 따라온다. 커서가 항상 앞서야 한다 |
| 진행 방향에서 **옆으로 크게 꺾는다** | 꺾은 쪽 모서리가 내려간다. 도우미가 그쪽에 손을 못 넣는다 |
| 멈춘다 | 덩어리가 퍼진다. 널빤지 밖으로 흐른다 |

**기울기가 생기는 방식(꺾기의 정의)**: 널빤지는 커서를 2차 감쇠로 따라오므로 항상 커서 뒤에 처져 있다. **커서 속도 벡터와 널빤지 진행 벡터의 외적 부호**가 곧 기울기 부호이고, 두 벡터의 사잇각이 클수록 기울기가 크다. 즉 급히 꺾을수록 그쪽 모서리가 깊이 내려간다. 별도 버튼이 없다.

**판정에 쓰는 값 3개뿐**: 커서-널빤지 거리, 널빤지 기울기 부호, 300ms 창의 정지 프레임 수.
절대 픽셀·속도 임계값을 쓰지 않는다. 속도가 필요하면 세션 첫 3초의 자기 최고속도로 정규화한다.

## 코어 루프 (1.0~1.5초)

```
커서가 앞선다 → 널빤지가 따라온다 → 도우미가 모서리를 든다
   → 기운 쪽으로 덩어리가 샌다 → 도우미가 샌 것을 떼어 제 몸에 얹는다
   → 제각기 다른 각도에서 따라붙는다 → (12초 뒤) 아무 데나 도로 얹는다
```

## 시스템 5개

### 1. 덩어리 — 비뉴턴 유체
- 널빤지 속도가 임계 이상이면 **굳는다**(형태 유지).
- 임계 이하 0.4초 지속 시 **퍼진다**(면적 증가, 가장자리부터 유출).
- 유출량은 널빤지 기울기 방향으로만 흐른다.

### 2. 도우미 — 자율 행위자 (동시 최대 6)
- **0:03 · 0:05 · 0:07에 연달아 셋** 진입, 그 뒤로는 3~6초 간격. **경로가 명백히 비효율적이다**(더 짧은 길을 두고 돌아온다 = 무료 캐릭터성).
- 도착하면 가장 가까운 모서리를 든다. 그 모서리가 내려가 있으면 **못 든다**(플레이어의 방어 수단).
- 샌 조각을 떼어 제 머리에 이고 따라온다. **줄을 서지 않는다** — 각자 다른 각도에서 따라붙는다(대열을 이루면 그림이 Pikmin 계열이 된다).
- **12초 뒤** 그 조각을 널빤지 위에 되돌려 놓는다 — 자리는 "지금 가장 비어 보이는 곳"이라 대개 최악.

### 3. 심판 3 — 검사대
- 검사대 옆에 고정. **각도만** 회전한다(`angle → lerp(atan2(target - pos))`).
- 널빤지가 접근하면 긴 축이 그쪽을 향한다. 도착 시 남은 부피의 실루엣만 보고 등급을 낸다.
- 얼굴·표정선·손가락 없음.

### 4. 흔적
- 샌 자국은 바닥에 100% 영구히 남는다. 판 끝에는 바닥이 내 경로의 지도가 된다.
- 다음 판의 시작 지형이 된다(루프).

### 5. 판 간 지속 (초기화 없음)
- 바닥의 유출 자국은 **다음 판에도 유지**되어 통로를 좁힌다.
- 조각을 떼어 간 도우미는 **그 조각을 계속 이고 있다** → 다음 판 0:00의 첫 프레임이 규칙에서 나온다.
- 판마다 도우미 진입 빈도가 오르지 않는다. **난이도는 지형 누적으로만 오른다**(N1 회피).

## 놀람 3회 — 서로 다른 축

| 시각 | 이름표 | 축 |
|---|---|---|
| 0:03 | 첫 손길 | 갑작스러운 등장 (새 물체 클래스: 조각을 인 채 따라오는 운반자) |
| 0:22 | 바닥 들기 | 판 변형 (통로 바닥이 경사로가 된다 — 원인이 호의다) |
| 0:40 | 큰 손 | looming (0초부터 보이던 가장 큰 도형이 `radius` 증가로 화면 절반을 먹는다) |

## 실패 2층

- **1층** — 도우미가 모서리를 들 때마다 샌다. 판당 12회 이상, 1.0~1.5초, 손해 0, 즉시 복구 가능, 흔적 100% 보존.
- **2층** — 0:40에 널빤지가 통째로 들리며 **굳지 않은 것 전부**가 1.2초에 걸쳐 쏟아진다. **속도를 유지해 굳혀 둔 덩어리는 널빤지에 붙어 남는다** — 그래서 2층이 점수를 0으로 만들지 않는다. 화면 위 물체가 가장 많고 가장 큰 순간. 마지막 0.5초는 정지한 잔해.
- 0:48 검사대 도착 → 채점.

## 승패

- **0:48 검사대 도착 시점**의 널빤지 위 잔여 부피가 점수. 0이면 패배.
- 시계 없음, 게이지 없음, 숫자 없음. 남은 덩어리의 크기가 그대로 점수판이다.
- 한 판 50초 × **2회** = 100초 ("1회 플레이 2분 이내" 준수).

## 소리

무음으로 100% 성립. Web Audio 절차 생성 예산은 **임팩트 1종**(널빤지가 들릴 때의 묵직한 타격)에 전량 투입.

## 안전 가드 (구현 시 하드 룰)

- 도형은 부서지지 않는다. 눌리고 튕기고 굴러갈 뿐이다.
- 넘어진 도형은 0.8초 뒤 몸을 펴고 일어난다.
- 덩어리에 눈·입·팔다리를 그리지 않는다(절단 연상 차단).
- 손가락을 그리지 않는다.
- 도우미는 대열·줄·행렬을 이루지 않는다.
