# 끌면 돈다 — 간이 기능 명세

## 목표

검인대 원 안에 원하는 도형을 밀어 넣어 심판이 집게 하도록 한다. 헛집으면 관중이 등을 돌린다.

## 화면

한 화면. 제도실 톤(격자 + 치수 보조선 + 단색 3개).

```
┌──────────────────────────────────────────────┐
│  ▪▪▪▪▪▪▪▪ ← 관중 40 (난간, 각도만)      ◦ 큰 것│
│                                    (계속 커짐)│
│      ╱──────────────╲                        │
│     ╱   ●    ○ ⊙     ╲  ← 판 (귀퉁이만 잡힘)  │
│    ╱      ╭───╮  ○    ╲                      │
│   ○───────│검인│────────                      │
│           ╰───╯   ↑ 눌어붙은 자국              │
│    ↑ 고리(잡는 점)   ┃ 심판 팔 (2.5초 주기)    │
└──────────────────────────────────────────────┘
```

## 입력

마우스 이동 + 드래그. 키보드·휠 없음. pointer lock 없음.

| 손동작 | 결과 |
|---|---|
| 판 귀퉁이의 고리를 잡고 끈다 | **잡은 점을 축으로 판이 돈다.** 커서와 판이 같은 방향으로 가는 순간이 없다 |
| 화면 3분의 2를 가로지르는 크고 느린 호 | 판 위 도형 다섯이 기울기 쪽으로 굴러다닌다 |
| 0:10 이후 반대쪽 고리로 갈아 잡는다 | **판이 도는 방향이 통째로 뒤집힌다.** 입력 문법은 그대로 |
| 멈춘다 | 판 위 도형이 1.2초 뒤 판에 눌어붙어 굳는다 |

**판정에 쓰는 값 2개뿐**: (a) 검인대 원 안의 **포함관계** (b) 도형이 한자리에 멈춰 있던 **프레임 수**.
**판의 회전각은 채점하지 않는다**(N10 회피). 픽셀도 속도도 쓰지 않는다.

## 코어 루프 (2.5초 — 심판 주기)

```
고리를 끈다 → 판이 축을 벗어나 돈다 → 도형들이 쓸려 이동
   → 심판 팔이 내려온다 → 원 안에 있는 것을 집어 1.0초에 걸쳐 눈높이로 들어 올림
   → 관중 40이 40~80ms 스태거로 그쪽으로 회전 (헛집으면 반대편으로)
```

## 시스템 5개

### 1. 판 — 오프센터 회전 (이 게임의 심장)
- **검인대는 화면 좌표에 고정된 원이고, 판은 그 위를 미끄러진다.** 판을 돌려도 검인대는 그 자리다. (ASCII에서 검인대는 판 윤곽 위에 겹쳐 그린 별도 레이어다 — 판에 붙어 있지 않다.)
- 잡은 점을 축으로 회전한다. 커서 변위가 각변위로 변환된다.
- **판은 절대 스스로 흐르지 않는다. 오직 내가 끄는 것만 움직인다**(N7 회피).
- **커서 궤적을 화면에 흰 실선으로 0.6초간 남긴다**(하드 룰). 커서 움직임의 작음과 판 회전의 큼이 한 프레임에 같이 보여야 이 게임의 웃음이 성립한다.
- 0:10에 두 번째 고리 추가 → 잡는 점 선택이 새 결정축이 된다.
- 0:32에 한 귀퉁이 탈락 → 질량 감소 → **같은 손동작에 두 배로 돈다.**

### 2. 판 위 도형 5 — 그중 셋은 의지가 있다
| 종류 | 행동 |
|---|---|
| 물렁한 도형 2 | 기울기 쪽으로 굴러다니고 서로 부딪히면 튕긴다 |
| **의지 있는 도형 3** | **기울기를 거스르며 검인대 원 바깥으로 기어 나간다**(검사받기 싫어한다). 판을 아무리 기울여도 그쪽으로 안 간다. 눌어붙은 자국을 밟으면 멈춘다 |

- **보충 규칙**: 판 밖으로 떨어진 도형은 **3초 뒤 판 가장자리로 다시 굴러 들어온다.** 판 위 개체 수는 항상 5로 유지된다 — 그래야 1층 실패가 판당 12회 이상 나온다(5개로는 산술적으로 불가능하다).

### 3. 눌어붙음 — 물성 압박 (지침 9)
- 도형은 따뜻하고 물렁하다. 판이 안 움직여 **한자리에 1.2초 이상** 머물면 판에 눌어붙어 굳는다.
- 굳은 것은 아무리 기울여도 다시는 안 움직이고, 다른 도형이 부딪히면 **튕겨 나가는 벽**이 된다.
- **손이 쉰 만큼 판이 좁아진다.** 시계도 게이지도 없다.

### 4. 심판 + 관중 40 — 채점 장치
- 심판은 2.5초마다 팔을 뻗어 검인대 원 안의 것을 집어 **눈높이까지 1.0초에 걸쳐 들어 올린다.** 내가 조종할 수 없고 기다려 주지도 않는다.
- 그 1.0초 동안 관중 40이 40~80ms 스태거로 일제히 그쪽으로 몸을 튼다.
- **헛집으면 같은 속도로 반대편으로 돌아선다.**
- 얼굴도 눈동자도 없고 **오직 방향만** 바뀐다. 점수판 없음 — 그 회전이 판정의 전부.

### 5. 판 간 지속 (초기화 없음)
- 눌어붙은 자국은 **판에 영구히 박힌다.** 다음 판은 이미 자국이 있는 판으로 시작한다.
- **"영구"의 유일한 예외**: 0:32 귀퉁이 탈락 때 그 귀퉁이에 붙어 있던 자국은 판 조각째 떨어져 나간다. 자국이 지워지는 게 아니라 **자국이 붙은 판이 없어지는 것**이다.
- 자국은 벽이므로 판을 거듭할수록 **쓸 수 있는 판이 좁아진다** — 내가 손을 쉰 자리가 나를 가둔다.
- 머니샷(별자리처럼 박힌 자국)이 판마다 진해진다. **세 번째 판의 머니샷이 가장 세다.**

## 놀람 3회 — 서로 다른 축

| 시각 | 이름표 | 축 |
|---|---|---|
| 0:10 | 고리 하나 더 | **새 도구** (손이 쥐는 것이 바뀐다. 입력 문법은 불변) |
| 0:32 | 귀퉁이 탈락 | **판 변형** (판이 작아지고 관성이 절반이 된다) |
| 0:46 | 접힌다 | **looming** (0초부터 다가오던 접는 자국이 도달해 판을 반으로 접는다) |

## 실패 2층

- **1층** — 판을 돌릴 때마다 도형 하나가 가장자리 밖으로 밀려 떨어지거나 제자리에 눌어붙는다. 판당 12회 이상, 1.2초, 손해 0. 떨어진 도형은 3초 뒤 복귀. **눌어붙은 자국은 전부 영구 보존.**
- **2층** — 0:46. 판이 한가운데를 축으로 **책처럼 반으로 접힌다.** 양쪽 면의 자국이 맞물려 대칭 무늬가 되고, 붙지 않은 도형은 접히는 틈으로 1.1초에 걸쳐 밀려 나온다. 마지막 0.5초는 반으로 접힌 채 선 판.
- **0:44에 점수가 확정된다** — 접힘은 그 뒤에 온다.

## 승패

- **0:44까지** 심판이 성공적으로 집어 올린 횟수 = 점수. 헛집기가 연속되면 관중이 전부 등을 돌려 패배. 2층 접힘은 점수 확정 후이므로 점수를 0으로 만들지 않는다.
- 화면에 숫자·시계·게이지 없음.

## 소리

무음으로 100% 성립. Web Audio 예산은 **판이 접히며 맞물리는 순간의 묵직한 임팩트 1종**에 전량 투입.

## 안전 가드 (구현 시 하드 룰)

- 도형은 부서지지 않는다. 눌어붙거나 쏟아질 뿐이다.
- 쏟아진 도형은 0.8초 뒤 몸을 펴고 일어난다.
- 심판의 팔 끝은 갈고리가 아니라 **평평한 두 판**으로 그린다(인형뽑기 연상 차단).
- 손가락·표정선·성별 실루엣 없음.
- 미술 톤은 공장이 아니라 제도실 — 실존 직군이 읽히지 않게 한다.
