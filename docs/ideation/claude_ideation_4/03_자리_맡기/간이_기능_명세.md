# 자리 맡기 — 간이 기능 명세

## 목표

일행 여섯이 도착했을 때 최대한 많이 앉힌다. 앉은 수가 곧 점수다.

## 화면

한 화면. 스크롤 없음.

```
┌──────────────────────────────────────────────┐
│  측량 격자 · 확보 면적 표기 (0.0㎡)             │
│                          ▲▲▲ ← 일행 6         │
│                        (0:00부터 계속 커진다)   │
│   ╭─────────────╮                            │
│   │   흰 천      │  ← 주름선이 누적된다         │
│   │  ╰ 접힌 모서리                    ▓ 옆팀 천│
│   ╰──●──────────╯                            │
│      ↑ 사람 도형 (천에 끌려간다)               │
└──────────────────────────────────────────────┘
```

## 입력

마우스 이동 + 드래그. 키보드·휠 없음. pointer lock 없음.

| 손동작 | 결과 |
|---|---|
| 천 가장자리 한 점을 잡고 길게 끌어당긴다 | 그 방향으로 펴진다. **반대쪽 모서리가 접혀 올라온다** |
| 획이 중간에 끊긴다 | 끊긴 지점에 **접힌 자국이 인쇄된다**(영구) |
| 무게추를 접힌 모서리 위로 끈다 | 그 모서리가 영구 고정. **무게추는 시작 3개 + 0:08 가방 1개 = 총 4개뿐** |
| 손을 놓는다 | 바람이 가장 가벼운 모서리부터 0.8초 상수로 접어 올린다 |

**판정에 쓰는 값 3개뿐**: (a) 한 획 안의 정지 프레임 수 (b) 속도 분산계수(표준편차÷평균 — **스케일 불변**이라 OS 가속·DPI 오염을 통과한다) (c) 획이 끊겼는가의 이진값.
**좌표 정확도는 절대 채점하지 않는다.** 절대 픽셀·속도 임계값 없음.

## 코어 루프 (1.0~1.5초)

```
가장자리를 잡고 길게 당긴다 → 펴진다 → 반대쪽 셋이 접힌다
   → 건너가서 다시 당길 것인가 / 무게추를 써서 영구 고정할 것인가
   → (무게추는 유한) → 남은 천을 펼 여력이 줄어든다
```

## 시스템 5개

### 1. 천 — 질량-스프링 격자 (12×12 상한 고정)
- 한 점을 당기면 장력이 전파되어 무게 없는 모서리가 들린다.
- **천이 사람보다 무겁다.** 당기는 힘이 크면 사람 도형이 천 쪽으로 끌려간다(첫 3초의 정체성).
- 접힌 자국 = 흰 주름선. 100% 영구 보존. **주름선은 다음 바람에 더 잘 접힌다.**

### 2. 바람 — 물성 압박 (지침 9)
- 화면 위 풀이 눕는 방향으로만 표시된다. 숫자도 게이지도 없다.
- 무게가 실리지 않은 모서리를 **스스로 찾아** 0.8초 상수로 접어 올린다.
- 손이 멈추면 즉시 시작된다.

### 3. 자율 행위자 4종
| 누구 | 무엇을 하나 |
|---|---|
| 바람 | 가벼운 모서리를 접어 올린다 |
| 옆 팀의 천 3~4장 | 스스로 펼쳐지며 내 영역 경계를 밀어온다 |
| 지나가는 사람들 | 모서리를 밟는다. 밟는 동안 고정, 발을 떼면 튕겨 올라온다 |
| 비둘기 1마리 | 천 위에 내려앉았다 날아오르며 천을 들춘다 |

### 4. 일행 여섯 — 결과물의 사용자이자 심판 (씨앗 3)
- **0:00부터 화면 안쪽 산책로에 서 있고 50초 내내 `radius`가 커진다**(looming + 가시형 지연).
- 0:44 도착. 천 위로 올라와 앉을 자리를 **스스로** 찾는다.
- **착석 규칙(화면에서 읽혀야 한다)**: 주름 없고 무게추가 눌러 놓은 면적이 자기 몸보다 크면 앉는다. 아니면 안 앉는다. **못 앉은 이유가 프레임에 보인다** — 이 한 줄이 "내 탓"을 지키는 유일한 장치다.
- 앉은 도형 = 무게추가 되어 바람을 막는다. 못 앉은 도형 = 천 밖에서 80~140ms 안에 나를 향해 회전(±15°, 스태거 40~80ms).
- **몇 명이 앉았는가가 곧 점수이고, 앉는 순간 확정된다.**
- 여섯 중 하나는 항상 **0.3초 늦게** 돌아보고 0.3초 늦게 앉는다 (다섯 안 중 이 안에만 있는 부품).

### 5. 판 간 지속 (초기화 없음)
- 흰 주름선은 **다음 판 천에 그대로** 남는다. 주름선은 다음 바람에 더 잘 접힌다.
- 두 번째 판은 **이미 접힌 천**으로 시작 → 같은 손동작인데 더 빨리 무너진다.
- 말린 두루마리 표면에 지난 판의 주름선이 보인다 → 루프가 규칙에서 나온다.

## 놀람 3회 — 서로 다른 축

| 시각 | 이름표 | 축 |
|---|---|---|
| 0:04 | 옆자리 | 갑작스러운 등장 (한 프레임에 화면 1/3이 남의 것이 된다) |
| 0:08 | 가방 착지 | 새 도구 (무게추가 3 → 4. 입력 문법은 그대로, 대상만 추가) |
| 0:44 | 일행 도착 | looming (0초부터 커지던 여섯이 화면 아래 절반을 채운다) |

(0:06의 부분 말림은 놀람이 아니라 1층 실패의 첫 사례다. 무음 문장의 펀치라인이 여기 있다.)

## 실패 2층

- **1층** — 모서리가 바람에 접혀 올라온다. 판당 12~16회, 1.0~1.5초, 손해 0, 즉시 재당김 가능. 접힌 자국 100% 영구 보존. 첫 사례는 **0:06**, 처음 편 자리가 도로 말려 내 도형의 발을 덮는다.
- **2층** — 0:44에 여섯이 앉는다(**점수 확정**). **그 직후** 마지막 무게추가 미끄러져 빠지고, **누적된 주름선을 따라** 천 전체가 1.2초에 걸쳐 두루마리로 말린다 — **앉아 있던 여섯을 천째로 감는다.** 마지막 0.5초는 정지한 두루마리와 양 끝으로 삐져나온 발들.

## 승패

- **0:44 착석 시점**의 앉은 일행 수 = 점수. 0명이면 패배. **2층 붕괴는 점수 확정 후에 온다.**
- 확보 면적은 배경 측량 격자에 작게만 표시(N2 회피 — 큰 숫자 금지).
- 시계 없음.

## 소리

무음으로 100% 성립. Web Audio 예산은 **천이 한 번에 말리는 순간의 임팩트 1종**에 전량 투입.

## 안전 가드 (구현 시 하드 룰)

- 아무도 다치지 않고 아무것도 부서지지 않는다.
- 사람 도형은 걷고 앉고 회전만 한다.
- 손가락·표정선·성별 실루엣 없음.
- 격자 스프링 12×12 상한 고정 (프레임 드랍 = '자잘한 버그' 감점 차단).
- 좌표 정확도 채점 금지 (정밀 추적 = 조작 감점 차단).
