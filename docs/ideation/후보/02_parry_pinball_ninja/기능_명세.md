# [기능 명세] 핀볼 닌자: 영점 패리 (Parry Pinball Ninja)

> **구현 기술 스택**: HTML5 Canvas 2D / WebGL 셰이더 + Phaser 3 / Arcade & Physics + Web Audio API  
> **실행 환경**: 오프라인 웹 브라우저 (GitHub Pages 싱글플레이)

---

## 1. 주요 기능 명세

### 1.1 핀볼 물리 & 영점 패리 시스템
* **핀볼 튕김 물리 (Pinball Elastic Reflection)**:
  * 충돌 판정 윈도우: 캐릭터 중심 35px 이내에 볼 진입 시 패리 가능.
  * 퍼펙트 타이밍 (Distance < 10px): 속도 2.5배 가속 + 궤적 조준 반사.
  * 일반 타이밍 (Distance 10~35px): 속도 1.2배 가속 + 랜덤 반사.
* **프리즈 프레임 효과 (Hit-Stop Freeze)**: 퍼펙트 패리 순간 전체 물리 및 애니메이션 6프레임(0.1초) 완전 정지.

### 1.2 시각 연출 (Visual Juiciness)
* **컬러 반전 & 플래시**: 패리 순간 0.05초간 화면의 모든 색상이 흑백 음화로 반전된 뒤 네온 파란색/분홍색 파티클 섬광 연출.
* **슬래시 궤적 셰이더**: 잔영 카타나 궤적 이펙트가 핀볼 반사 각도에 따라 생성.

### 1.3 청각 연출 (Web Audio)
* **패리 음 (Parry SFX)**: 고주파 금속 검격음 (Metallic Slash + Glass Shatter FX).
* **핀볼 범퍼음**: 클래식 80년대 아케이드 핀볼 띵-띵- 콤보 사운드.

---

## 2. 조작 방식 & UI/UX

| 입력 방식 | 조작 행동 |
|---|---|
| **W, A, S, D** | 닌자 이동 및 벽 타고 오르기 |
| **마우스 좌클릭 / J / Space** | 카타나 휘두르기 (패리 타이밍 발동, 쿨타임 0.2초) |
| **마우스 우클릭 / K** | 방향성 공중 닌자 대시 (Dash Evade) |

* **HUD 메인 UI**: 핀볼 테이블 점수판 (High Score multiplier), 닌자 체력 하트 3개, 퍼펙트 패리 연속 콤보 게이지.
