## 하나만 만든다면

> **받침. 단, 1일차 오전 종이 프로토타입 검증을 통과한 경우에만.**

이 조건절이 추천의 일부다. "받침으로 착수하라"가 아니라 **"1일차 오전에 세로 2글자 가독성부터 실측하고, 통과하면 받침으로 착수하라"**가 추천 문장 전체다.

### 왜 받침인가

1. **규칙 문장과 화면과 제목이 완전히 같은 것을 가리키는 유일한 안이다.** `받침`의 어원이 `받치다`다. 심사위원 3인이 규칙 명료성에 10/10/10을 준 유일한 후보.
2. **뒤집은 것이 시스템이 아니라 판정 축 하나다.** 쌓기 게임에서 붕괴를 결정하는 값은 예외 없이 무게중심인데, 그 값 하나를 "아래 글자에 종성이 있는가"라는 정수 판정으로 갈아끼웠다. 더한 게 아니라 바꿨다.
3. **"AI가 낸 안 중 무엇을 왜 버렸는가"에 답할 재료가 원칙 단위로 정리된다.** 획수=무게를 버린 이유("읽히지 않는 규칙은 노이즈다"), 좌우 흔들림을 버린 이유("실수 각도로 하중을 배분하면 정수 판정이 깨진다"), 무한 아케이드를 버린 이유("엔딩이 없으면 데모로 보인다") — 셋 다 근거가 취향이 아니라 검증 가능한 기준이다.
4. **재미 여부를 숫자로 판정할 수 있다.** 하중이 정수 누적이라 상태공간이 작고, 스테이지 목표 높이가 도달 가능한지를 근사가 아니라 **탐색으로 증명**할 수 있다. (2픽 「칸 긋기」의 패킹 가능성은 NP-hard라 "내 솔버는 풀었다"까지만 간다.)

### 이 추천이 서 있는 미검증 전제 — 숨기지 않는다

받침의 중독 구조 전부가 "세로 단어를 노리는 도박"에 걸려 있고, 그 도박은 **플레이어가 낙하 압박 속에서 세로 두 글자를 읽는다**는 전제 위에 있다. 이 전제는 검증된 적이 없다. 사람은 글자를 가로로 읽도록 훈련되어 있고, 낙하 게임에서 시선은 떨어지는 조각과 착지 지점에 고정된다.

## 폴백 플랜

**전환 대상: 받침 → 칸 긋기.** 판정 시점은 두 번이고, 두 번째가 마지막이다.

### 판정 1 — 1일차 오전 (손실 0)

종이 프로토타입 5분. 카드 두 장을 세로로 놓고 3초 안에 단어로 읽히는지를 본인 포함 4명에게 확인.
**3명 중 2명이 못 읽으면 즉시 칸 긋기로 착수.** 코드가 없으므로 버려지는 것도 없다.

### 판정 2 — 2일차 종료 (실제 갈림길)

판정 기준을 미리 숫자로 못 박는다:

> 테스터 3명이 각각 5판씩 플레이했을 때, **받침 없는 글자를 일부러 받는 선택을 한 번도 하지 않은 사람이 2명 이상이면** 도박이 죽은 것으로 보고 전환한다.

"재미없다"는 감상이 아니라 **이 관찰 하나로** 판정한다. 감상으로 판정하면 3일차, 4일차로 미뤄지고 그때는 전환이 불가능하다.

### 전환 시 코드 회계

| 버려짐 (받침 고유, 코어의 약 60%) | 재사용 (공통 기반, 약 70%) |
|---|---|
| 하중 전파 알고리즘, 붕괴 연쇄 큐 | 고정 timestep 결정론 루프 |
| 낙하 트윈, 착지 스냅 | 정수 격자 ↔ 화면 좌표 변환기 |
| 한글 음절 분해(0xAC00 종성 추출) | Canvas 2D 렌더 레이어, 카메라, 화면 흔들림 |
| 세로 2글자 사전과 큐레이션 산출물 | 게임 상태 머신(타이틀/플레이/승리/패배/재시작) |
| 폰트 메트릭 기반 글자 정렬 | 스테이지 데이터 로더 |
| 좌우 이동 + 즉시 낙하 입력 | Web Audio 합성 SFX 모듈 |
| | 포인터 입력 정규화 |
| | **헤드리스 시뮬 하네스** ← 가장 큰 자산 |

**컷 로그는 코드를 버려도 버리지 않는다.** 최종 문서의 방법론 증거로 살려 쓴다.

**전환은 한 번뿐이다.** 칸 긋기도 4일차에 5~10초 사건이 안 만들어지면 남은 3일로 새 컨셉에 착수할 수 없다.

## 심사위원 3인이 갈린 지점 — 평균으로 뭉개면 정보가 사라진다

### 1) 판 던지기 — 12점 격차 (76 / 74 / 64)

영상 전달력은 8개 중 최고인데 심사위원3만 12점 낮다. 축이 다르기 때문이다. 심사위원3의 기준은 "재미 여부를 사람 감각이 아니라 숫자로 판정할 수 있는가"이고, **판 던지기는 재미가 전부 손맛에 있어서 헤드리스 자동 플레이가 아무것도 알려주지 않는다.**

> 판 던지기는 **영상은 최고이고 제작 과정은 최악인** 후보다. 평균 71점짜리 무난한 안이 아니라, 한 축에서 1위이고 다른 축에서 꼴찌인 극단값이다.

### 2) 받침 대 칸 긋기 — 1점 차

심사위원2만 칸 긋기를 1위로 놨다(80 대 79). 완성 가능성에서 3점을 벌고 한국 문화 코드에서 3점을 잃어 정확히 상쇄된다. 심사위원2가 자기 반론에서 스스로 짚었다:

> 한국 회사가 한국 심사위원으로 한국 사례집에 실을 물건을 뽑는데 내 1픽은 한국적 요소가 규칙에 하나도 없다. 총점 차이는 1점이다. 채점표를 한 칸만 다르게 봤으면 순위가 뒤집힌다.

배점표가 비공개라는 확정 사실을 감안하면 **1점 차 우위는 우위가 아니다.** 그래서 둘 중 하나를 버리지 않고 순서만 정했다.

### 3) 소리보다 빠르게 — 심사위원3만 낮음 (75 / 76 / 67)

심사위원3의 지적이 날카롭다:

> 경비원 시스템을 잘라낸 판단은 방법론에서 나온 게 아니라 **선행작 리서치 결과**에서 나왔다. "내가 지휘해서 잘랐다"가 아니라 "겹쳐서 잘랐다"는 이야기는 사례집에서 약하다.

**이 지적은 최종 문서 작성 전체에 적용된다.** 폐기 사유가 *원칙*인 것과 *검색 결과*인 것을 구분해서 쓰지 않으면, 후자가 전자인 척하다가 들킨다.

## 5개 전부에 공통으로 적용되는 것

리서치에서 확정된 제약이다. 상세는 [`00_제약_조건표_종합.md`](../../research/claude_research/00_제약_조건표_종합.md).

- **스택**: TypeScript(strict) + HTML5 Canvas 2D + Web Audio API + Vite + GitHub Actions → Pages. **프레임워크·물리엔진 없음**
- **외부 에셋 0개.** AI 생성 이미지는 한국 저작권법상 저작물이 아니고(문체부·저작권위 안내서 2025.6), 약관 제4조 2항은 "본인의 순수 창작물"을 요구한다. 도형·단색·절차 생성으로 가면 이 리스크가 구조적으로 0이 된다
- **1회 플레이 2분 이내**, 스테이지 5~8개 + 명시적 최종 화면. 무한 아케이드 금지
- **한 화면 안에서 전부**. 카메라 이동·씬 전환 최소
- **무음으로 이해 가능**해야 한다
- **1일차에 배포 파이프라인부터.** `base: '/<REPO>/'` 누락이 가장 흔한 실수
- **8/08~8/09는 기능 추가 금지**, 링크 검증 전용 예비일
- 영상에서 **AI를 한 번도 언급하지 않는다.** AI 활용 기술 문서에서는 **게임을 자랑하지 않는다.** 매체를 분리한다
