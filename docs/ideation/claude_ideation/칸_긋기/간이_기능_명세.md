# 칸 긋기 — 간이 기능 명세

스택: TypeScript(strict) + HTML5 Canvas 2D + Web Audio API. 프레임워크·물리엔진 없음.

---

## 1. 데이터 모델

```ts
interface Stall {           // 그어진 주차칸
  x: number; y: number;     // 격자 단위 (16px 스냅)
  w: number; h: number;
  occupiedBy: number | null; // 차 id
  fee: number;               // 확정 요금
  dead: boolean;             // 어떤 차도 못 들어가는 자투리
}

interface Car {
  id: number;
  reqW: number; reqH: number; // 최소 요구 크기 (격자 단위)
  color: string;
  state: 'waiting' | 'entering' | 'parked' | 'leaving';
}

interface Lot {
  cols: number; rows: number;
  aisle: { x: number; w: number };  // 침범 불가 통로 (고정)
  stalls: Stall[];
}
```

**모든 좌표가 격자 정수다.** 자유 드래그 좌표는 입력 순간 즉시 스냅되어 정수가 된다.

## 2. 핵심 알고리즘

### 2-1. 드래그 → 정규화된 사각형

```
pointerdown  → 시작점을 격자로 스냅
pointermove  → 현재점 스냅, 두 점으로 사각형 정규화 (좌상단·크기)
               반투명 면으로 프리뷰 렌더 (선이 아니라 면)
pointerup    → 검증 후 확정
```

### 2-2. 작도 검증 (확정 조건)

세 가지를 순서대로 본다. 하나라도 실패하면 작도 취소 + 거부 피드백.

```
1. 통로 침범?           aisle 사각형과 교차하면 거부
2. 기존 칸과 겹침?       모든 stall과 AABB 교차 검사
3. 최소 크기 미만?       w,h >= 1
```

그을 수 없는 칸은 드래그 전부터 색칠해 보여준다.

### 2-3. 차 수용 판정

```
canFit(car, stall) = stall.w >= car.reqW && stall.h >= car.reqH
```

**정확 일치가 아니라 ≥.** 이것이 Shikaku와 갈라서는 지점이다.

### 2-4. 요금 계산

```
요구면적 = car.reqW * car.reqH
실제면적 = stall.w * stall.h
요금 = BASE_FEE * (요구면적 / 실제면적)   // 1.0에 가까울수록 만점
```

칸 안에 상시 인쇄한다. 딱 맞으면 큰 숫자, 헐렁하면 작은 숫자.

### 2-5. 죽은 땅 판정 (매 차량 확정 후 1회)

```
남은 시퀀스의 모든 차에 대해 canFit이 false인 stall → dead = true
dead 칸은 붉게 변하고 사선이 그어진다
```

이 판정이 "남은 수명"의 시각화이자 패배 예고다.

## 3. 진입 애니메이션 (경로 탐색 없음)

주차장 형태를 **가운데 세로 통로 + 좌우 구역** 한 가지로 고정한다.

```
입구 → 통로를 따라 목표 칸의 y까지 직진 → 좌 또는 우로 직진해 칸 진입
```

고정 트윈 2구간. 시뮬레이션도 경로 탐색도 아니다. 이것으로 7일 안에 들어온다.

## 4. 입력

| 입력 | 동작 |
|---|---|
| 드래그 | 사각형 작도 |
| 우클릭 / Esc | 작도 중 취소 |
| R | 재시작 |

터치: 그대로 동작(pointer 이벤트 통일).

## 6. 게임 상태 머신

```
타이틀 → 플레이 → (고정 시퀀스 20대 전부 수용) → 승리 화면
                → (현재 차를 넣을 칸을 만들 수 없음) → 패배
        재시작 / 종료
```

승리 조건이 고정 시퀀스 소진이라 1회 플레이가 2분 안에 반드시 끝난다.

## 7. 오디오 (Web Audio 절차 생성)

| 사건 | 합성 |
|---|---|
| 작도 확정 | 짧은 클릭 + 스톨 라인 인쇄음 |
| 차 진입 완료 | 부드러운 2음 하강 |
| 딱 맞음(요금 만점) | 도장 찍는 저역 타격음 + 상승 3음 |
| 거부(겹침/통로) | 짧은 부저 |
| 자투리 사망 | 저역 감쇠음 |
| 대기줄 누적 | 경적 |

무음으로도 전부 이해 가능(요금 숫자·색·사선이 정보를 독점하지 않고 중복 전달).

## 8. 검증 하네스

```
scripts/balance-sim.ts
  고정 시퀀스 20대에 대해 탐욕 패킹 정책으로 자동 플레이
  출력: 클리어 가능 여부, 남은 면적 곡선, 죽은 땅 발생 시점
  시퀀스가 클리어 불가능하면 exit 1
```

주의: 패킹 가능성은 NP-hard라 "내 솔버는 풀었다"까지만 증명된다. 「받침」의 하중 탐색처럼 완전 증명은 안 된다. 이 한계를 AI 활용 기술 문서에 그대로 적는다.

## 9. 7일 일정

| 일차 | 작업 |
|---|---|
| D1 | 배포 파이프라인, 고정 타임스텝 루프, **격자 스냅 작도 + 반투명 면 프리뷰** |
| D2 | 겹침·통로 검증, 진입 트윈, 요금 계산, 죽은 땅 판정 — 코어 완성 |
| D3 | 고정 차량 시퀀스 20대 손으로 설계, `balance-sim.ts` 로 클리어 가능성 증명 |
| D4 | **5~10초 사건 3종**(대기줄 누적 / 자투리 사망 연출 / 요금 도장), 콘텐츠 동결 |
| D5~D6 | 폴리시 — 이징, 스크린셰이크, 진입 트윈 감각, 오디오 |
| D7 | 영상(6~8대째부터 촬영), PDF 3종, 링크 검증 |

## 10. 명시적 비목표
