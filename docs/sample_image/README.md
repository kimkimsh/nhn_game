# 인게임 화면 15장 — 「환도(還刀)」

`index.html`을 브라우저로 열면 전체 목록이 나온다. 각 폴더는 인게임 **한 프레임 한 화면**이다.

```
docs/sample_image/
  index.html          전체 목록
  _shared/            공통 소스 (tokens.css · screen.css · engine.js)
  00_title/ …         화면별 폴더: index.html · scene.js · README.md
```

## 어떻게 그렸나

캡처 이미지가 아니라 **스펙을 실행해서 그린 그림**이다. `_shared/engine.js`가
`docs/spec/기능_명세서.md`의 수치를 그대로 들고 있고(패리 반경 70u, 등급 밴드
28/48/70u, 반사 공식 `v' = v − 2(v·n)n`, 탄종 12개, 적 9종), 각 `scene.js`는
적 배치와 발사 스케줄만 적는다. 시뮬레이션을 1/60초 간격으로 돌린 뒤 한 프레임을
그려서 멈춘다. 애니메이션은 없다.

즉 화면에 보이는 GREAT는 실제로 거리 28u 안에서 성립한 GREAT이고,
반사탄이 향하는 방향도 손으로 찍은 게 아니라 반사 공식이 낸 값이다.

주소 뒤에 `?at=6.5` 를 붙이면 같은 장면의 다른 순간을 볼 수 있다.

## 색 규칙 — 색 하나에 규칙 하나

| 색 | 뜻 |
|---|---|
| 적 `#E23C2E` | 적 탄환 · 적 본체. 닿으면 라이프 −1 |
| 황 `#F5B324` + 적색 링 | 반사탄. 내 데미지지만 나에게도 유효하다(HR-07) |
| 청 `#35B7E0` | 플레이어 · 패리. 피격 판정 10u 코어는 항상 보인다 |
| 백 `#EDE6D8` 점선 | 예고 표시. 착탄 원 · 관통선 · 돌진선 3종뿐(HR-05) |
| 탁적 + 대각 해칭 | 패리 불가. 색이 아니라 **형태**로 구분한다(§17) |
