# 기능 명세서 — 「환도(還刀)」

**제목**: 환도(還刀). 조선의 검 환도(環刀)와 소리가 같고, 글자는 '돌려주는 칼'이다. 적이 쏜 것을 그대로 돌려보내는 것이 이 게임의 유일한 공격 수단이라는 규칙을 제목이 그대로 말한다.
**장르**: 종스크롤 비행 슈팅 × 뱀파이어 서바이벌형 빌드 성장 × 패리 액션
**한 줄 규칙**: 플레이어는 공격 수단이 없다. 적이 쏜 탄환을 패리로 튕겨낸 반사탄만이 유일한 데미지원이다.
**배경**: 임진왜란 (1592~1598), 조선 검사
**플랫폼**: PC 브라우저 (§16.6)

---

## 0. 이 문서의 범위

### 0.1 포함하는 것

- 게임이 만족해야 할 **기능 요구사항**과 그에 딸린 **수치**
- 시스템 간 인과 관계 (어떤 입력이 어떤 상태 변화를 일으키는가)
- 스테이지·적·보스·카드의 전체 목록과 파라미터 표
- 판정 규칙, 우선순위, 예외 처리

### 0.2 포함하지 않는 것

- 기술 스택, 엔진, 라이브러리, 파일 구조, 클래스 설계, 알고리즘 최적화
- 아트 스타일 가이드, 사운드 제작 지침, 스토리·대사·연출 각본
- 마케팅, 심사 전략, 팀 역할 분담

**구현 방법은 이 문서에서 일절 다루지 않는다.** 반사 각도 공식처럼 수식이 등장하는 곳은 "이런 결과가 나와야 한다"는 동작 정의이지 코드 지시가 아니다.

### 0.3 수치의 지위

이 문서의 모든 수치는 **초기값**이며 실측 플레이로 조정될 대상이다. 조정 시 §14의 튜닝 규칙을 따른다. 다만 §2의 하드 규칙(HR-01~HR-09)은 수치가 아니라 제약이므로 조정 대상이 아니다.

시간은 **전부 초(s) 단위로 표기한다**(HR-06). 0.15초처럼 소수로 적으며 밀리초 표기는 쓰지 않는다.

## 1. 용어 정의

| 용어 | 정의 |
|---|---|
| **논리 단위(u)** | 화면 해상도와 무관한 게임 내 좌표 단위. 플레이필드는 1080u × 1920u. |
| **패리** | 플레이어가 패리 입력을 넣어 주변 원형 판정 영역을 활성화하는 행위. |
| **패리 원** | 플레이어 중심을 원점으로 하는 반경 R의 원. 이 안에 들어온 적 탄환이 패리 대상이 된다. |
| **패리 등급** | 패리 성립 순간 탄환과 플레이어 중심 사이 거리로 결정되는 3단계 판정. NOT BAD / GOOD / GREAT. |
| **적 탄환** | 적이 발사한 발사체. 플레이어에게 피해를 준다. |
| **반사탄** | 패리로 소유권이 뒤집힌 발사체. 적에게 피해를 주며, **플레이어에게도 그대로 피해를 준다**. |
| **재패리** | 반사탄을 다시 패리하는 행위. 데미지와 속도가 누적된다(§7.4). |
| **자해 유예** | 반사가 성립한 직후 그 반사탄이 플레이어를 맞히지도, 패리 대상이 되지도 않는 구간. 0.15초. |
| **반사기본위력(BRP)** | 탄환 종류마다 고정된 값. 반사탄 데미지 계산의 기준값. |
| **웨이브** | 스테이지를 구성하는 시간 구획. 정해진 시각에 정해진 적 편성이 등장한다. |
| **소강 구간** | 마지막 웨이브 종료와 보스 등장 사이의 3초. 신규 적 탄환이 발생하지 않을 뿐이며 **플레이어가 무적이 되는 구간이 아니다.** 잔존 반사탄은 그대로 남아 유효하다(§9.1). |
| **런(run)** | 스테이지 1 시작부터 게임오버 또는 스테이지 5 클리어까지의 1회 플레이. |
| **발사 예비동작** | 적이 발사 직전 취하는 자세 변화·발광·총구 점화. **궤적선이나 착탄 원을 그리지 않는다.** 어디로 날아올지는 알려주지 않고 언제 나올지만 알려준다. |
| **예고 표시** | 공격이 닿을 지점을 도형으로 미리 그리는 것. 착탄 예고 원·관통 예고선·돌진 방향선 세 가지뿐이며, 사용 조건은 HR-05가 정한다. |
| **착탄 예고 원** | 곡사 공격이 떨어질 지점을 미리 표시하는 원. |
| **장판** | 지속 시간 동안 특정 영역에 머무는 피해 영역. 패리 불가. |

## 2. 하드 규칙

시스템 전체가 항상 만족해야 하는 제약. 밸런싱으로 완화할 수 없다.

| ID | 규칙 |
|---|---|
| **HR-01** | 플레이어는 직접 공격 수단을 가지지 않는다. 반사탄 외의 데미지 소스는 존재하지 않는다. |
| **HR-02** | 모든 웨이브 편성에는 **원거리 공격 적이 최소 1기 이상** 포함되어야 한다. 근접·돌격 전용 편성은 금지된다. 플레이어의 탄약 공급이 끊기기 때문이다. |
| **HR-03** | 게임 플레이 중 **적 탄환이 화면에 하나도 없는 상태가 2.0초를 초과할 수 없다.** 보스 페이즈 전환 연출 구간도 이 상한에 포함된다. |
| **HR-04** | 패리 불가 공격(장판, 관통 대창, 본체 접촉)은 **반드시 회피 가능한 안전 지대**를 남겨야 한다. 화면 전체를 덮는 패리 불가 공격은 금지된다. |
| **HR-05** | **예고 표시는 패리로 해결할 수 없는 공격에만 붙인다.** 대상은 곡사 착탄(P7), 관통 대창(P12), 본체 돌진 세 가지뿐이다. 일반 탄환 발사에는 조준선·궤적선·착탄 원을 **표시하지 않는다.** 일반 탄환은 발사 예비동작만 두고, 날아오는 탄환 자체를 보고 반응하는 것이 정상 플레이다. |
| **HR-06** | 게임 내 모든 시간 파라미터는 **초(s)** 로 정의한다. 프레임 수나 밀리초로 정의하지 않으며, 프레임률이 변해도 동일한 실시간이 유지되어야 한다. |
| **HR-07** | 반사탄은 적과 **플레이어 양쪽 모두에게** 피해를 준다. 적 탄환은 다른 적에게 피해를 주지 않는다. |
| **HR-08** | 보스는 항상 플레이필드 상단 영역에 머문다. 반사탄이 위로 향했을 때 보스에 도달할 수 있어야 한다. (하단으로 밀고 내려오는 돌진 패턴은 예외이며, 이 구간에는 별도 안전 지대를 둔다.) |
| **HR-09** | 예고 표시가 없는 탄환은 **발사 시점부터 플레이어 위치까지의 비행 시간이 0.45초 이상**이어야 한다. 이 조건을 만족하지 못하는 근거리에서는 적이 발사하지 않고 다음 주기로 미룬다. HR-05로 궤적 예고가 사라진 만큼, 탄환을 눈으로 보고 반응할 시간은 규칙으로 보장한다. |

## 3. 전역 사양

### 3.1 플레이필드

| 항목 | 값 |
|---|---|
| 논리 해상도 | 1080u × 1920u (9:16 세로) |
| 원점 | 좌상단 (0, 0), x는 오른쪽, y는 아래 방향 증가 |
| 플레이어 이동 가능 영역 | x ∈ [70, 1010], y ∈ [620, 1830] |
| 적 활동 영역 | y ∈ [-200, 1000] (돌격형 적은 y=1920까지 진입 가능) |
| 보스 정위치 영역 | x ∈ [240, 840], y ∈ [180, 520] |
| 탄환 소멸 경계 | 플레이필드 외곽 +150u 를 벗어난 시점 |

### 3.2 전역 상한

| 항목 | 값 |
|---|---|
| 동시 적 탄환 상한 | 스테이지별 (§14 표 참조), 최대 280 |
| 동시 반사탄 상한 | **240** |
| 동시 잡몹 상한 | **20기** |
| 히트스톱 동시 적용 | 불가. 동일 프레임 다중 패리 시 **최고 등급 1회만** 적용. |
| 히트스톱 누적 상한 | 1초당 총 0.32초 |

**상한 도달 시 처리**

| 대상 | 처리 |
|---|---|
| 적 탄환 | 신규 발사를 **억제**한다. 이미 화면에 있는 탄환을 지우지 않는다. 억제된 발사는 취소되며 다음 발사 주기를 기다린다. |
| 반사탄 | 가장 오래된 반사탄부터 소멸시킨다. 패리는 언제나 성립해야 하므로 신규 반사탄을 버리지 않는다. |
| 잡몹 | 신규 스폰을 상한 아래로 내려갈 때까지 **지연**한다(§9.1). 스폰 예정 편성은 취소되지 않는다. |

- 잡몹 상한 20기는 화면을 적으로 채워 **반사탄 한 발이 여러 기를 정리하는 장면**을 만들기 위한 값이다. §11의 관통(R02)·분열(R01·E01)·파편(R08) 카드가 이 상한과 함께 작동한다.

## 4. 플레이어 사양

### 4.1 기본 파라미터

| 항목 | 값 | 비고 |
|---|---|---|
| 이동 속도 | 520 u/s | 8방향, 대각선 정규화(대각선이 빠르지 않음) |
| 가속/감속 | 없음 (즉시 최고속) | 입력 지연 0 |
| 피격 판정 반경 | 10u | 캐릭터 스프라이트 중심. 화면에 코어 점으로 상시 표시 |
| 시각적 크기 | 약 90u | 판정과 무관 |
| 초기 라이프 | 3 | 전 스테이지 공유 |
| 최대 라이프 | 5 | 카드로만 증가 |

### 4.2 피격 처리

플레이어 코어(반경 10u)와 적 탄환·적 본체·**반사탄**이 겹치면 피격(HR-07).

| 단계 | 동작 |
|---|---|
| 1 | 라이프 -1 |
| 2 | 플레이어 중심 반경 **280u** 내의 모든 적 탄환 즉시 소멸 (반사탄 아님, 점수 없음) |
| 3 | 무적 **1.5초** 부여 |
| 4 | 콤보 0으로 초기화 |
| 5 | 히트스톱 0.14초 |
| 6 | 라이프가 0이면 게임오버 처리(§13.3) |

- 2단계의 소멸 대상은 **적 탄환뿐이다.** 반사탄은 플레이어의 자산이므로 지우지 않는다. 다만 **피격을 일으킨 반사탄 자신은 소멸한다** — 적에게 명중했을 때와 같은 처리이며, 무적이 끝난 직후 같은 탄에 다시 맞는 상황을 막는다.
- 무적 중에는 적 탄환·적 본체·반사탄·장판 모두 무해하며, 무적 중에도 패리는 정상 동작한다.
- 무적 상태는 플레이어 표시로 구분 가능해야 한다(§17).

### 4.3 장판 피해

- 장판 영역 안에 플레이어 코어가 들어가면 **0.5초 간격**으로 피격 판정.
- 진입 즉시 1회 판정, 이후 0.5초마다 반복.
- 피격 시 §4.2와 동일하게 처리되므로 무적 1.5초 동안은 추가 피해가 없다.

## 5. 패리 시스템

### 5.1 입력과 상태

패리는 **방향 입력이 없다.** 한 개의 버튼으로 플레이어 주변 전 범위를 판정한다.

| 항목 | 값 |
|---|---|
| 패리 반경 R | **70u** (플레이어 중심 기준) |
| 활성 시간 | **0.15초** |
| 쿨다운 | **0.24초** (활성 시작 시점 기준) |
| 재입력 불가 구간 | 활성 종료 후 **0.09초** |
| 선입력 버퍼 | 쿨다운 종료 **0.12초 전**부터 입력 접수, 종료 즉시 발동 |
| 무적 | **패리가 성립했을 때만** 부여. 성립 시점부터 **0.14초** |
| 최대 입력 빈도 | 초당 **4.16회** (= 1 / 0.24초) |

- 입력은 눌림(press) 순간에만 접수한다. 누르고 있어도 활성이 연장되지 않는다.
- 쿨다운 중 입력은 선입력 버퍼 구간이 아니면 무시된다.

**무적은 패리 성공의 대가다.** 활성 구간에 들어갔다는 사실만으로는 아무 보호도 없다. 패리 유효 범위 안에 실제로 탄환이 있어서 패리가 성립한 그 순간부터 0.14초 동안만 무적이다. 따라서 **탄환이 없는 곳에서 패리를 난사해 버티는 행동은 성립하지 않는다.** 난사는 탄막 한가운데에서만 이득이 된다.

- 무적 중 다시 패리가 성립하면 남은 시간에 더하지 않고 **0.14초로 다시 설정**한다.
- 한 활성 구간에서 여러 탄환이 동시에 패리되어도 무적은 1회분만 부여한다. 등급에 따라 무적 길이가 달라지지 않는다.
- **같은 프레임에서 패리 판정을 피격 판정보다 먼저 처리한다.** 이 순서가 없으면 §5.3의 대형 탄환 GREAT가 성립하는 즉시 피격으로 처리된다.

**불변 조건** — 카드로 파라미터가 변해도 아래 두 가지는 항상 성립해야 한다.

| ID | 조건 | 이유 |
|---|---|---|
| **INV-1** | `쿨다운 ≥ 활성 시간 + 0.05초` (= 재입력 불가 구간 ≥ 0.05초) | 활성 구간이 빈틈없이 이어지면 패리 버튼을 계속 누르고 있는 것과 같아져 입력 행위 자체가 무의미해진다. 최소 간극을 남긴다 |
| **INV-2** | `패리 유래 무적 총 지속 ≤ 쿨다운 × 0.75` | 탄환이 계속 공급되는 구간에서 무적이 100% 이어지는 것을 막는다. 무적만 잘리며 **패리 판정 자체는 활성 시간 전체에서 정상 동작한다** |

두 조건은 카드 효과를 모두 합산한 **뒤에** 검사하며, 위반 시 각각 쿨다운을 늘리고 무적을 자르는 방향으로 보정한다.

INV-1의 마진이 0.05초로 좁은 것은 무적이 성공 조건부가 됐기 때문이다. 빈 패리에 무적이 없으므로 "연타로 영구 무적"이라는 위반 경로가 사라졌고, 남은 것은 입력의 의미를 지키는 최소 간극뿐이다.

### 5.2 패리 성립 조건

활성 구간의 매 프레임, 아래 조건을 **모두** 만족하는 발사체가 패리된다. 대상은 적 탄환과 **반사탄** 양쪽이다(§7.4).

| 조건 | 내용 |
|---|---|
| C1 | 발사체 중심과 플레이어 중심 사이 거리 `d ≤ R` |
| C2 | 발사체가 플레이어에게 **접근 중**일 것 — 속도 벡터 `v`와 법선 `n`에 대해 `v · n < 0` |
| C3 | 발사체의 패리 가능 플래그가 참일 것 (§6 표의 "패리" 열) |
| C4 | 해당 발사체가 이번 활성 구간에서 아직 패리되지 않았을 것 |
| C5 | 반사탄인 경우: 반사 직후 **자해 유예 0.15초**가 지났을 것 (§7.4) |

`n = normalize(발사체위치 − 플레이어위치)`

- C2가 있으므로 이미 스쳐 지나간 발사체는 패리되지 않는다. **반사탄은 구조상 플레이어에게서 멀어지므로 보통 이 조건에서 걸러진다.** 재패리가 성립하는 경우는 유도 반사탄(R03)이 되돌아왔거나, 플레이어가 반사탄보다 빠르게 이동해 앞질렀을 때뿐이다.
- C4는 같은 활성 구간 안에서 반사 → 즉시 재패리가 무한히 반복되는 것을 막는다.
- 활성 구간 도중 새로 반경 안에 들어온 발사체도 그 진입 프레임에 판정된다. 따라서 **일찍 누르면 탄환이 원의 바깥 가장자리에서 걸려 낮은 등급이 나오고, 늦게 누를수록 탄환이 중심에 가까워져 높은 등급이 나온다.**

### 5.3 등급 판정

패리 성립 프레임의 거리 `d`로 등급을 결정한다.

| 등급 | 거리 조건 | 데미지 배수 | 반사 속도 배수 | 히트스톱 | 점수 |
|---|---|---|---|---|---|
| **NOT BAD** | 48 < d ≤ 70 | ×1.0 | ×1.3 | 0.02초 | 50 |
| **GOOD** | 28 < d ≤ 48 | ×2.0 | ×1.8 | 0.05초 | 150 |
| **GREAT** | d ≤ 28 | ×3.5 | ×2.6 | 0.075초 | 400 |

히트스톱이 원래 값(0.025 / 0.055 / 0.09초)보다 짧은 것은 쿨다운 0.24초 때문이다. 초당 최대 4.16회 패리 × GREAT 0.09초 = 0.375초로, 난사 구간에서 히트스톱이 누적 상한에 걸려 계속 잘려 나간다. GREAT를 0.075초로 내리고 누적 상한을 0.32초로 올려 `4.16 × 0.075 = 0.312초 ≤ 0.32초`를 만족시켰다. 등급 간 차이(0.02 / 0.05 / 0.075)는 체감되도록 남겼다.

쿨다운을 더 줄이는 카드(R10·E07)를 든 빌드는 이 계산을 넘어선다. 그 경우 누적 상한이 초과분을 잘라내며, 이것이 상한의 존재 이유다.

**타이밍이 곧 거리다.** 예를 들어 속도 600u/s 탄환이 정면으로 접근할 때, 반경 70u에서 28u까지 42u를 이동하는 데 0.07초가 걸린다. 즉 GREAT를 노리려면 NOT BAD가 나오는 타이밍보다 0.07초 늦게 눌러야 하고, 그보다 더 늦으면 탄환이 코어(10u)에 닿아 피격된다. 탄환이 빠를수록 이 창이 좁아진다.

**대형 탄환의 GREAT는 "맞기 직전"이 아니라 "이미 겹친 상태"다.** 등급 판정 거리 `d`는 탄환 **중심**과 플레이어 중심 사이 거리이므로, 반경이 큰 탄환일수록 GREAT를 받는 순간 탄환 몸통이 이미 플레이어 코어를 덮고 있다. 참격파(P5, 반경 34u)를 예로 들면 `d = 44` 지점에서 탄환 가장자리가 코어(10u)에 닿는데, GREAT 밴드는 `d ≤ 28`이라 그보다 한참 안쪽이다. 이것을 성립시키는 것은 **패리 성립과 동시에 부여되는 0.14초 무적**과, **같은 프레임에서 패리 판정이 피격 판정보다 먼저 처리된다는 순서 규칙**(§5.1)이다. 활성 구간에 들어간 것만으로는 보호받지 못하므로, 대형 탄환을 몸으로 받는 행동은 반드시 패리가 성립해야만 성립한다.

무적 0.14초는 반사된 대형 탄환이 코어에서 완전히 벗어나기에 충분해야 한다. 최악 조건인 대통 폭탄(P7, 반경 30u, 속도 260u/s)을 `d = 28`에서 GREAT로 받으면 반사 속도는 676u/s이고, 겹침이 풀리는 `d = 40`까지 12u를 가는 데 0.018초가 걸린다. 0.14초는 이 값의 7배 이상이므로 반사한 탄에 자신이 즉시 맞는 상황은 발생하지 않는다.

즉 **대형 저속탄은 "몸으로 받아내는" 감각이 되고, 소형 고속탄은 "스쳐 지나가기 직전에 쳐내는" 감각이 된다.** 의도된 차이이며, §14.2의 난이도 축 1(탄속)과 함께 스테이지별 체감을 만든다.

- 동일 활성 구간에 여러 탄환이 패리되면 **각 탄환이 자기 거리로 개별 등급**을 받는다.
- 히트스톱·점수·콤보는 그중 **최고 등급 기준으로 1회만** 적용한다.
- 등급 밴드 경계는 카드로 변경될 수 있다(§11). 변경 후에도 `GREAT 상한 < GOOD 상한 ≤ R` 순서는 항상 유지된다. 카드 조합으로 순서가 깨지면 상위 밴드를 하위 밴드 상한에 맞춰 자른다.

### 5.4 빈 패리

활성 구간에 패리된 발사체가 0개인 경우.

- **무적이 부여되지 않는다.** 활성 구간 내내 플레이어는 평소와 똑같이 피격된다.
- 콤보는 리셋되지 않는다.
- 점수·히트스톱 없음.
- 카드 N13 보유 시 쿨다운이 단축된다.

빈 패리에 아무 보호가 없다는 것이 이 시스템의 유일한 억제 장치다. 쿨다운이 0.24초까지 내려가 패리를 사실상 난사할 수 있게 됐지만, 난사 자체는 플레이어를 지켜주지 않는다. **탄환이 실제로 오는 자리에서 눌러야만 이득이 있다.**

### 5.5 반사 방향

패리 성립 시 탄환의 속도 벡터를 아래대로 변환한다.

```
n  = normalize(탄환위치 − 플레이어위치)
v' = v − 2 (v · n) n
반사탄 속도 = |v'| × (등급별 반사 속도 배수) × (카드 보정)
반사탄 방향 = normalize(v')
```

동작 결과:

- 탄환을 **정면(중심 가까이)으로 받으면** `n`이 `v`와 거의 반대이므로 `v' ≈ −v`, 즉 쏜 적에게 그대로 되돌아간다.
- 탄환을 **가장자리로 스치게 받으면** `n`이 `v`에 가까워지므로 크게 꺾여 옆으로 튄다.

즉 **몸 위치가 조준이다.** 정확도가 높을수록(=GREAT) 반사탄이 곧게 되돌아가고, 데미지도 높다. 두 보상이 같은 방향을 가리킨다.

반사 공식에는 부수 효과가 하나 있다. `v · n < 0`인 발사체만 패리되므로 반사 후에는 언제나 `v' · n > 0`, 즉 **반사탄은 반드시 플레이어에게서 멀어지는 방향으로 출발한다.** 반사탄이 플레이어에게 유해해졌는데도(HR-07) 반사 즉시 자기 탄에 맞지 않는 이유가 이것이다. 맞으려면 플레이어가 그 탄을 따라가야 한다(§7.1).

| 대상 | 처리 |
|---|---|
| 화염 장판 (P9) | 패리 원 안에 있어도 무시. 무적 중이 아니면 피해. |

### 6.2 예고와 예비동작 규칙 (HR-05)

**궤적을 그려주는 예고는 패리로 해결할 수 없는 공격에만 붙는다.** 일반 탄환은 어디로 날아올지 미리 알려주지 않는다. 날아오는 탄환을 보고 판단하는 것이 이 게임의 기본 행위이며, 조준선을 그려주면 그 판단이 통째로 사라진다.

| 공격 형태 | 표시 | 시간 | 분류 |
|---|---|---|---|
| 단발 직선 (P1~P3) | **궤적 예고 없음.** 발사 예비동작(사격 자세 + 총구·시위 발광)만 | 스테이지별 (§14.1) | 예비동작 |
| 확산·링 | **궤적 예고 없음.** 발사원이 밝아지는 예비동작만 | 0.4초 고정 | 예비동작 |
| 참격파 (P5) | **궤적 예고 없음.** 무기 백스윙 자세만. 궤적 잔상을 미리 그리지 않는다 | 0.7초 고정 | 예비동작 |
| 유도탄 (P11) | **궤적 예고 없음.** 유도 중 궤적선을 그리지 않는다 | — | 예비동작 |
| 곡사 (P7) | **착탄 예고 원** | 1.2초 고정 | 예고 표시 |
| 관통 대창 (P12) | **폭 40u 예고선** | 0.8초 고정 | 예고 표시 |
| 돌진 (본체) | **적 외곽 발광 + 돌진 방향선** | 1.0초 고정 | 예고 표시 |
| 화염 장판 (P9) | 별도 예고 없음 — 생성 원인인 P7의 착탄 예고 원, 또는 눈에 보이는 P8 궤적이 예고를 대신한다 | — | — |

**예고 표시 3종의 공통점**: 전부 패리로 지울 수 없고, 판정이 순간적으로 발생하며, 회피만이 대응책이다(HR-04). 반대로 예비동작만 두는 공격은 전부 패리로 처리 가능하다. **이 대응이 곧 플레이어에게 "예고 도형이 보이면 피해라, 안 보이면 받아쳐라"라는 규칙을 가르친다.**

**발사 억제 거리 (HR-09)**

예고 도형이 없는 탄환은 눈으로 보고 반응할 시간이 필요하므로, 비행 시간 0.45초를 규칙으로 보장한다.

| 항목 | 값 |
|---|---|
| 최소 비행 시간 | 0.45초 |
| 발사 억제 거리 | `실제 탄속 × 0.45초` — 플레이어까지 거리가 이보다 가까우면 발사하지 않는다 |
| 최악 조건 검산 | 조총탄 P2 760u/s × S5 탄속 배율 1.34 = 1018u/s → 억제 거리 **458u** |

- 억제된 발사는 취소되고 다음 발사 주기를 기다린다. 적이 플레이어를 쫓아와 코앞에서 쏘는 상황을 구조적으로 없앤다.
- 근접 위협은 이 규칙에 걸리지 않는 수단(E-C·E-D의 본체 접촉, 보스 돌진)이 담당한다. 이들은 전부 예고 표시 대상이다.

| 속도 | `원래 속도 × 등급 반사 속도 배수 × 카드 보정`, 상한 **2400 u/s** |
| 수명 | 3.0초. 이후 소멸 (재패리 시 재설정) |
| 관통 | 기본 없음. 적 1기 명중 시 소멸 (카드로 변경 가능) |
| 화면 밖 | 경계 +150u 이탈 시 소멸 |
| 재패리 | **가능. 횟수 제한 없음** (§7.4) |
| 유도 | 기본 없음 (카드 R03으로 부여) |

**반사탄은 플레이어에게도 위험하다.** 반사 공식(§5.5)상 반사탄은 언제나 플레이어에게서 멀어지는 방향으로 출발하므로 가만히 있으면 맞지 않는다. 하지만 **플레이어가 반사탄보다 빠르게 이동해 따라잡으면 맞는다.** 이동 속도 520u/s(카드 최대 900u/s)에 비해 저속탄의 반사 속도가 낮기 때문에 실제로 일어난다.

| 탄종 | 최저 반사 속도 (NOT BAD ×1.3) | 기본 이동 속도로 추격 가능 |
|---|---|---|
| 대통 폭탄 P7 | 338 u/s | 가능 |
| 함포탄 P6 | 390 u/s | 가능 |
| 불화살 P8 | 624 u/s | 불가 (카드로 이동 속도를 올리면 가능) |
| 조총탄 P2 | 988 u/s | 불가 |

- 자해 유예 0.15초는 패리 순간 탄환이 코어를 덮고 있는 경우(§5.3 대형 탄환)에 반사 직후 자기 탄에 맞는 것을 막는다. 유예가 끝난 뒤에는 어떤 반사탄도 플레이어에게 유효하다.
- 유예 구간을 지나도 즉시 맞지는 않는다. 최악 조건인 P7을 NOT BAD(`d = 70`)로 반사한 직후 최대 속도로 추격하면, 0.15초 뒤 거리는 `70 + 338×0.15 − 520×0.15 = 42.7u`로 피격 거리(코어 10u + 탄 반경 30u = 40u)를 아직 넘는다. **추격을 계속 선택해야만 맞는다.**

**파생 발사체** — 반사탄에서 갈라져 나온 것은 전부 반사탄과 같은 규칙을 따른다.

| 대상 | 처리 |
|---|---|
| R01 쌍검 / E01 학익진 분열탄 | 반사탄. 플레이어에게 유해, 재패리 가능 |
| R08 파편 | 반사탄. 플레이어에게 유해, 재패리 가능. 자해 유예 0.15초 동일 적용 |
| E02 화전 | 반사탄. 플레이어에게 유해, 재패리 가능 |
| E06 화공 장판 | 반사탄과 동일. **플레이어에게도 유효하다.** 피해는 §4.3의 장판 규칙(0.5초 간격, 라이프 −1)을 따른다 |

E06 장판이 플레이어에게도 유해한데 HR-04(패리 불가 공격은 안전 지대를 남길 것)를 위반하지 않는 이유는 **생성 위치 때문이다.** 장판은 반사탄이 적에게 명중한 지점에 생기고, 적 활동 영역은 `y ∈ [-200, 1000]`인 반면 플레이어 이동 영역은 `y ∈ [620, 1830]`이다. 겹치는 띠는 `y ∈ [620, 1000]`뿐이고, 플레이어는 언제든 아래쪽 830u를 쓸 수 있다. 게다가 지속 시간이 2초로 P9의 절반이다.

### 7.2 데미지 계산 순서

```
1. 기준값        = 탄환 BRP  (재패리여도 직전 데미지가 아니라 언제나 BRP에서 다시 시작)
2. 등급 배수 적용 = 기준값 × (NOT BAD 1.0 / GOOD 2.0 / GREAT 3.5)
3. 가산 보정      = 카드의 "+N%" 효과를 모두 더해 한 번에 곱한다
4. 조건부 배수    = R04(GREAT 시 ×1.5) 등 조건 만족 시 곱한다
5. 분열 감쇠      = R01·E01 등 분열 카드의 개별 계수를 곱한다
6. 최종 데미지    = 소수점 내림
```

1번이 핵심이다. **재패리는 직전 데미지에 배수를 다시 곱하지 않는다.** 그렇게 하면 GREAT를 세 번 이어 붙였을 때 `3.5⁴ = 150배`가 나와 밸런스가 무너진다. 기준값은 언제나 BRP로 되돌아가고, 재패리로 달라지는 것은 **이번에 받은 등급뿐이다.**

예시 1 — 조총탄(BRP 14)을 GREAT로 패리, 카드 N01 3중첩(+45%)과 R04 보유.
`14 × 3.5 × 1.45 × 1.5 = 106.5 → 106`

예시 2 — 함포탄(BRP 55)을 NOT BAD로 급하게 받은 뒤, 추격해 GREAT로 다시 쳐냄. 카드 없음.
```
1회차 (NOT BAD)  55 × 1.0 = 55
재패리   (GREAT)  55 × 3.5 = 192   ← 누적이 아니라 등급 재판정의 결과
```

### 7.3 방패병 상호작용

- 방패병(§8)은 **정면 방향에서 들어오는 반사탄 1회를 무효화**한다.
- 무효화 후 방패는 파괴되어 이후 반사탄은 정상 피해를 준다.
- 측면·후면에서 들어온 반사탄은 방패를 무시한다. 즉 원형 거울 반사로 각도를 틀어 옆에서 때리는 것이 정답 행동이다.

### 7.4 재패리

반사탄을 다시 패리해 **다른 방향으로, 다시 매긴 등급으로** 보내는 행위. 성립 조건은 §5.2의 C1~C5를 그대로 따른다.

| 항목 | 값 |
|---|---|
| 횟수 제한 | **없음** |
| 데미지 | 재패리 전용 보너스는 **없다.** §7.2의 계산을 그대로 다시 돌린다 |
| 등급 | 이번 패리의 거리로 새로 판정한다. 직전 등급을 물려받지 않는다 |
| 속도 | 매 재패리마다 등급 반사 속도 배수를 다시 곱한다. 상한 2400 u/s |
| 수명 | 재패리 시 3.0초로 재설정 |
| 자해 유예 | 재패리마다 0.15초 새로 시작 |
| 콤보 | +1 (일반 패리와 동일) |
| 점수 | 등급 점수의 **50%** (NOT BAD 25 / GOOD 75 / GREAT 200) |

**왜 되는가.** 반사탄이 플레이어에게 유해해졌으므로(HR-07), 반사탄은 이제 "위험한 발사체"라는 점에서 적 탄환과 같은 종류의 물체다. 패리 판정에서만 예외로 두면 규칙이 두 갈래로 갈라진다. **날아오는 위험한 것은 전부 쳐낼 수 있다** — 이 한 문장으로 통일된다.

**재패리로 얻는 것.** 데미지 보너스가 없어도 이유는 셋 남는다.

| 이득 | 내용 |
|---|---|
| **방향 재조정** | 각도가 어긋나 빈 곳으로 날아가던 반사탄을 적 쪽으로 다시 보낸다. 이것이 주된 용도다 |
| **등급 재판정** | NOT BAD(×1.0)로 급하게 받은 탄을 GREAT(×3.5)로 다시 치면 데미지가 3.5배가 된다. 별도 보너스 없이도 증폭 경로가 성립한다 |
| **위험 제거** | 자기에게 돌아온 반사탄(R03 유도 등)을 맞는 대신 쳐낸다 |

**왜 횟수 제한이 없어도 되는가.** 재패리를 반복하려면 매번 반사탄을 **따라잡아야 한다**(C2: 접근 중일 것). 그런데 구조가 이미 이것을 막는다.

| 제약 | 내용 |
|---|---|
| 반사 속도 | 가장 느린 P7조차 NOT BAD 반사에서 338u/s. 기본 이동 속도 520u/s로는 겨우 따라잡는 수준이고, 한 번이라도 GOOD·GREAT가 나오면 468~878u/s로 올라 사실상 놓친다 |
| 소멸 경계 | 반사탄은 플레이필드 경계 +150u를 벗어나면 사라진다. 위로 날아가는 반사탄을 아래에서 쫓는 거리는 애초에 짧다 |
| 수명 | 3.0초 |
| 이동 속도 상한 | 카드를 다 쌓아도 900u/s. 반사 속도를 앞지르는 폭이 크지 않다 |
| 기회비용 | 반사탄을 쫓는 동안 적 탄환은 막지 못한다. 무적도 패리가 성립해야만 나오므로 추격 중에는 보호가 없다 |

즉 재패리는 **"안전한 딜 증폭"이 아니라 "위치를 버리고 사오는 딜 증폭"이며**, 몇 번이나 할 수 있는지는 규칙이 아니라 물리가 정한다. 점수 50% 감액은 그럼에도 남겨 둔 브레이크다.

**실제로 성립하는 경우**

| 상황 | 성립 여부 |
|---|---|
| 저속탄(P6·P7)을 NOT BAD로 반사 후 추격 | 성립. 반사 속도 338~390u/s < 이동 속도 520u/s |
| R03 자석 반사로 유도가 붙은 반사탄이 크게 돌아옴 | 성립. 유도가 플레이어 쪽을 스칠 때 C2 만족 |
| 같은 탄을 3회 이상 연속 재패리 | 이론상 가능하나 위 제약이 겹쳐 거의 나오지 않는다 |
| 고속탄(P2·P3)을 반사 | 사실상 불가. 반사 속도가 이동 속도를 크게 웃돈다 |
| 반사탄이 적에게 명중 | 불가. 명중과 동시에 소멸 |

## 9. 스테이지 구성

### 9.1 공통 구조

```
스테이지 시작
  → 웨이브 1..N (시간 기반 진행)
  → 소강 구간 (3초, 적 탄환 없음 — HR-03의 유일한 예외)
  → 보스 등장
  → 보스 격파
  → 스테이지 클리어
  → 업그레이드 카드 선택 (스테이지 1~4만)
  → 다음 스테이지
```

**웨이브 진행 규칙**

- 웨이브는 **시간 기반**으로 전환된다. 이전 웨이브의 적을 다 잡지 못해도 다음 웨이브가 시작된다.
- 잔존 적은 그대로 유지되며, 동시 잡몹 상한 **20기**에 걸리면 신규 스폰이 상한 아래로 내려갈 때까지 지연된다.
- 마지막 웨이브 종료 시점에 잔존 잡몹이 있으면 **4초간 유예** 후 화면 밖으로 강제 퇴장시킨다. 퇴장한 적은 점수를 주지 않는다.
- 소강 구간 3초 동안 플레이어는 무적이 아니며, **잔존 반사탄은 유지된다. 이 반사탄은 플레이어에게도 유효하므로 소강 구간이 완전한 안전 구간은 아니다.**

| 시작 보유 카드 | **없음.** 스테이지 1은 언제나 카드 0장으로 시작한다 |
| 획득 시점 | 스테이지 1·2·3·4 클리어 직후. **총 4회** |
| 제시 매수 | 3장 |
| 선택 | 반드시 1장 선택. 취소·건너뛰기 불가 |
| 리롤 | **런당 1회** (아래 참조) |
| 시간 제한 | 없음 (선택 중 게임 정지) |
| 중복 제시 | 동일 카드가 같은 화면에 2장 이상 나오지 않는다 |
| 소실 | 게임오버 시 전체 리셋. 리롤 사용 여부도 초기화된다 |

**리롤**

| 항목 | 규칙 |
|---|---|
| 횟수 | 런 전체에서 **1회.** 4번의 선택 화면 중 아무 때나 쓸 수 있다 |
| 입력 | `R` (§16.2) |
| 동작 | 제시된 3장을 버리고 §11.2의 추첨 절차를 처음부터 다시 실행한다. **등급도 다시 뽑는다** |
| 재추첨 범위 | 직전에 나왔던 카드도 다시 나올 수 있다. 같은 화면 안의 중복만 금지된다 |
| 소진 | 사용 즉시 소진. 결과가 더 나빠져도 되돌릴 수 없다 |
| 표시 | 리롤이 남아 있는지 카드 선택 화면에 항상 표시한다 (§15.2) |

등급을 다시 뽑는 것이 핵심이다. 카드 자체만 다시 뽑으면 노말 3장이 나온 화면에서 리롤해도 노말 3장이 다시 나와 리롤이 사실상 무의미해진다. 등급까지 다시 뽑아야 §11.2의 회차별 가중치(4회차 기준 에픽 18%)에 한 번 더 도전하는 의미가 생긴다.

```
0.06초일 때   0.5 × 0.06 + 0.5 × 0.24 = 0.150초  →  6.67회/초  →  성공 3.33회/초  (기준 대비 +60%)
```

레어 카드 한 장이 유효 패리 빈도를 1.6배로 만드는 것은 §14.4의 보스 HP 산출 전제를 통째로 벗어난다. +34%는 강력하되 T-05의 검사 범위 안에 남는다.

### 11.6 효과 합산 규칙

| 항목 | 규칙 |
|---|---|
| 같은 카드 중첩 | 효과 수치를 **가산**한다 (N01 3중첩 = +45%) |
| 다른 카드 간 % 효과 | 같은 대상에 대해 **가산 후 1회 곱연산** (+15%와 +20% → ×1.35) |
| 조건부 배수 (R04 등) | 가산 보정 적용 후 **곱연산** |
| 분열 계수 (R01·E01) | 마지막에 곱연산. 두 카드를 동시 보유하면 분열이 중첩되어 총 6발, 각 계수 `0.65 × 0.55 = 0.3575` |
| 상충 (R09 vs N08·E05) | 밴드 조정은 전부 가산 적용. 결과가 `GREAT 상한 > GOOD 상한`이 되면 GREAT 상한을 GOOD 상한 값으로 자른다 |
| 쿨다운 하한 | 어떤 조합으로도 **0.15초 미만이 될 수 없다.** 다만 실효 하한은 대개 INV-1이 먼저 결정한다 |
| 쿨다운 vs 활성 | **INV-1** — 위 하한을 적용한 뒤에도 `쿨다운 < 활성 시간 + 0.05초`이면 쿨다운을 `활성 시간 + 0.05초`로 올린다. **E07 보유 시에만 이 단계를 건너뛰고 `활성 시간 + 0.04초`를 쓴다** |
| 패리 무적 총합 | **INV-2** — `쿨다운 × 0.75`로 자른다. 무적만 잘리고 패리 판정 창은 유지된다 |
| 반사탄 속도 상한 | 2400 u/s |
| 패리 반경 상한 | 어떤 조합으로도 **150u를 초과할 수 없다** |
| 이동 속도 상한 | 900 u/s |

**보정 순서** — 상충이 생기면 아래 순서로 처리한다.

```
1. 같은 카드 중첩 가산
2. 카드 간 % 효과 가산 → 1회 곱연산
3. 조건부 배수 곱연산
4. 분열 계수 곱연산
5. 개별 상한 적용 (쿨다운 하한, 반경 상한, 이동 속도 상한, 반사탄 속도 상한)
6. 밴드 순서 보정 (GREAT 상한 > GOOD 상한이면 잘라냄)
7. INV-1 적용 (쿨다운 상향, E07 보유 시 예외 규칙 적용)
8. INV-2 적용 (무적 하향)
```

1~4단계는 §7.2의 데미지 계산 순서와 같은 순서다. 두 곳을 대조할 때 어긋난 것처럼 보이지 않게 맞춰 둔 것이다.

**최악 조합 검산 1 — E07 없음.** N04 3중첩(쿨다운 −18%) + N05 3중첩(활성 +0.03초) + N10(무적 +0.03초) + R10

```
쿨다운   0.24 × 0.82 = 0.197초    → 하한 0.15초 통과
활성     0.15 + 0.03 = 0.18초
INV-1    0.197 < 0.18 + 0.05     →  쿨다운 0.23초로 상향
무적     0.14 + 0.03 = 0.17초
INV-2    0.23 × 0.75 = 0.1725초  →  0.17초 통과 (잘리지 않음)
결과     활성 0.18초 / 쿨다운 0.23초 / 무적 0.17초  →  초당 4.35회
         R10 발동 시(패리 성립) 쿨다운 즉시 종료, 최소 간격 0.06초 → 초당 최대 12.5회
```

기본값(0.24초, 초당 4.16회) 대비 쿨다운 단축은 0.01초에 그친다. **쿨다운 축은 이미 포화 상태이며, 카드로 더 빨라지는 길은 R10의 조건부 초기화뿐이다.** N05가 활성을 늘려 INV-1 하한을 밀어올린 것이 원인이고, 이것이 §11.3에 적은 N04·N05 상충의 실제 수치다.

**최악 조합 검산 2 — E07 포함.** E07 + N04 3중첩 + N05 3중첩 + N10 + R10

```
활성     0.15 + 0.03 = 0.18초
쿨다운   E07 예외    →  0.18 + 0.04 = 0.22초   (INV-1의 0.23초를 건너뜀)
무적     0.14 + 0.03 = 0.17초
INV-2    0.22 × 0.75 = 0.165초  →  0.165초로 하향
결과     활성 0.18초 / 쿨다운 0.22초 / 무적 0.165초  →  초당 4.55회
         반사탄 데미지 −20%
         무적 점유율 75% — INV-2 상한에 정확히 걸린 상태
```

무적 점유율 75%는 **탄환이 끊임없이 공급되고 그것을 모두 성공시켰을 때의 이론값**이다. 한 번이라도 빈 패리가 나오면 그 구간은 무방비가 된다. 빈 패리에 무적이 없다는 규칙(§5.4)이 이 점유율을 실전에서 지탱 불가능하게 만든다.

| NOT BAD 패리 | 50 |
| GOOD 패리 | 150 |
| GREAT 패리 | 400 |
| 재패리 | 위 등급 점수의 **50%** (25 / 75 / 200) |
| 잡몹 처치 | §8.1 아키타입별 점수 |
| 보스 페이즈 전환 | 2,000 |
| 보스 격파 | 10,000 |
| 스테이지 클리어 보너스 | 남은 라이프 × 2,000 |

패리 점수와 처치 점수 모두에 콤보 배수가 곱해진다.

### 12.2 콤보

| 항목 | 규칙 |
|---|---|
| 증가 | 패리로 발사체를 1발 처리할 때마다 +1 (다중 패리는 개수만큼 증가) |
| 재패리 | +1. 일반 패리와 동일하게 센다 |
| 유지 시간 | 마지막 패리 성공 후 **3.0초** |
| 리셋 조건 | 유지 시간 경과 **또는** 플레이어 피격 (반사탄에 맞은 경우 포함) |
| 빈 패리 | 콤보에 영향 없음 (증가·리셋 모두 안 함) |
| 배수 | `1.0 + floor(콤보 / 10) × 0.1`, 상한 **3.0** |
| 스테이지 전환 | 콤보는 스테이지를 넘어 유지되지 않는다. 스테이지 시작 시 0 |

- 재패리에 횟수 제한은 없지만(§7.4) 콤보를 무한히 벌 수는 없다. 반사탄은 빠르게 멀어지다 소멸 경계를 넘어 사라지고, 쫓는 동안 적 탄환은 방치되므로 콤보 리셋 위험이 함께 커진다.
- 노히트 클리어에 대한 별도 보상은 없다. 노히트는 남은 라이프 보너스(라이프 × 2,000)로 이미 점수에 반영된다.

### 12.3 최종 결과

런 종료 시(클리어 또는 게임오버) 아래를 표시한다.

- 총점
- 도달 스테이지
- 최대 콤보
- 패리 등급별 횟수 (NOT BAD / GOOD / GREAT)
- 총 패리 시도 대비 성공률
- 재패리 횟수
- 반사탄 자해로 잃은 라이프 수 (T-06 실측 근거)
- 획득 카드 목록
- 치트 모드 사용 여부 — 사용했다면 **오염된 런**임을 명시한다(§18.5)

## 13. 게임 진행·실패·재시작

### 13.1 진행 흐름

```
타이틀
  → 스테이지 1
  → [클리어] → 카드 선택 → 스테이지 2
  → [클리어] → 카드 선택 → 스테이지 3
  → [클리어] → 카드 선택 → 스테이지 4
  → [클리어] → 카드 선택 → 스테이지 5
  → [클리어] → 엔딩 · 결과 화면
```

- **스테이지 5를 클리어하면 런이 끝난다.** 무한 모드나 추가 스테이지로 이어지지 않는다. 이 게임의 완주 길이는 §9.2의 450초 + 카드 선택 4회이며, 그 뒤에 붙는 것은 엔딩과 결과 화면뿐이다.
- 난이도 선택은 없다. 모든 플레이어가 §14.1의 같은 곡선을 지난다.

### 13.2 라이프

- 라이프는 **5스테이지 전체를 관통하여 공유**된다. 스테이지 클리어로 회복되지 않는다.
- 회복 수단은 카드 N14(즉시 +1), R06(최대치 +1 및 즉시 +1), E03(보호막)뿐이다.

### 13.3 게임오버

라이프 0 도달 시.

| 단계 | 동작 |
|---|---|
| 1 | 즉시 게임 정지, 결과 화면 표시 (§12.3) |
| 2 | 재시작 선택 시 **스테이지 1**부터 시작 |
| 3 | **획득한 카드 전부 소실**. 라이프·최대 라이프·점수·콤보 전부 초기값으로 |
| 4 | 다음 런의 카드 추첨은 이전 런과 독립적이다 (기억하지 않는다) |

**중간 진행 저장은 없다.** 스테이지 3에서 죽으면 스테이지 1부터다. 이것이 매 런마다 다른 카드 조합이 나오는 구조를 성립시킨다.

### 13.4 일시정지

- 언제든 일시정지 가능. 모든 타이머·탄환·쿨다운 정지.
- 일시정지 중 재시작(런 포기) 가능.

## 14. 난이도 곡선과 튜닝 규칙

### 14.1 스테이지별 파라미터

| 항목 | S1 | S2 | S3 | S4 | S5 |
|---|---|---|---|---|---|
| 적 HP 배율 | 1.00 | 1.35 | 1.80 | 2.40 | 3.10 |
| 탄속 배율 | 1.00 | 1.08 | 1.16 | 1.24 | 1.34 |
| 발사 예비동작 시간 (단발 직선) | 0.95초 | 0.85초 | 0.75초 | 0.65초 | 0.55초 |
| 동시 적 탄환 상한 | 80 | 120 | 170 | 210 | 280 |
| 동시 잡몹 최대 도달치 | 10 | 12 | 10 | 18 | 20 |
| 웨이브 수 | 3 | 4 | 4 | 4 | 5 |
| 목표 길이 | 70초 | 85초 | 90초 | 95초 | 110초 |
| 보스 HP | 1450 | 2250 | 3200 | 3850 | 5100 |
| 근접·돌격 적 비율 | 20% | 30% | 25% | 30% | 35% |
| 패리 불가 요소 | 없음 | 없음 | 없음 | 화염 장판 | 화염 장판 + 관통 대창 |

- 동시 적 탄환 상한을 이전(60~220)보다 올린 것은 잡몹 상한이 12기 → 20기가 되면서 발사원 자체가 늘었기 때문이다. 상한은 성능 방어선이지 난이도 목표치가 아니며, 실제 밀도는 웨이브 편성이 정한다.
- "동시 잡몹 최대 도달치"는 §9의 편성이 잔존 적을 포함해 실제로 도달하는 값이다. 상한 20기에 닿는 것은 S5의 W5뿐이다.

### 14.2 난이도 상승 축

난이도는 아래 5개 축으로만 올린다. **적 HP를 올리는 것만으로 난이도를 만들지 않는다.**

| 축 | 상승 방식 |
|---|---|
| 1. 탄속 | 빨라질수록 GREAT 판정 창이 좁아지고, 탄환을 보고 반응할 시간도 함께 줄어든다 (§5.3) |
| 2. 발사 예비동작 시간 | 짧아질수록 "언제 나오는지"를 읽을 여유가 준다. 궤적 예고가 없으므로(HR-05) 이 축은 위치가 아니라 타이밍만 압박한다 |
| 3. 동시 탄환 수·적 수 | 쿨다운 0.24초로도 모든 탄을 받을 수 없게 된다. 잡몹 수 증가가 이 축을 함께 민다 |
| 4. 패리 불가 요소 | 패리만으로 해결되지 않는 위협을 섞는다 |
| 5. 위협 종류 전환 속도 | 보스 페이즈가 늘어나며 대응 전환 빈도가 오른다 |

축 2가 이전보다 약해진 것은 HR-05 개정의 직접적 결과다. 조준선이 사라지면서 "어디로 날아올지 미리 아는 상태"가 없어졌고, 예비동작은 발사 시각만 알려준다. 줄어든 압박은 축 1(탄속)과 축 3(밀도)이 나눠 가진다.

### 14.3 튜닝 규칙

| 규칙 | 내용 |
|---|---|
| T-01 | 보스 HP는 **카드 미획득 상태의 추정 DPS × 목표 격파 시간**으로 산출한 뒤 실측으로 조정한다 |
| T-02 | 추정 DPS 계산 기준: 실제 패리 성공률 50%, 평균 등급 GOOD(×2.0), 재패리 0회. 쿨다운 0.24초에서 최대 4.16회/초 → **유효 2.08패리/초** |
| T-03 | 스테이지 1의 **원거리 잡몹(E-A, E-B)** 은 NOT BAD 패리 3발 이내로 죽어야 한다. 초기 학습 구간에서 좌절을 만들지 않기 위함. 근접형(E-C, E-D)은 이 조건에서 제외한다 — 회피가 정답 행동이기 때문 |
| T-04 | 목표 길이 대비 ±15% 이상 벗어나면 웨이브 시간이 아니라 **적 HP 배율**을 먼저 조정한다 |
| T-05 | 카드 4장을 모두 최상급으로 받은 빌드가 스테이지 5 보스를 **20초 미만**에 격파하면 카드 계수를 낮춘다 |
| T-06 | 반사탄 자해(HR-07)로 잃는 라이프가 전체 피격의 **15%를 넘으면** 자해 유예(§7.1, 초기값 0.15초)를 먼저 늘린다. 반사탄 속도나 이동 속도를 건드리지 않는다 — 그 둘은 반사 자체의 손맛을 결정하는 값이다 |
| T-07 | 동시 잡몹 20기 구간에서 프레임률이 목표치 아래로 떨어지면 잡몹 상한이 아니라 **동시 적 탄환 상한**을 먼저 내린다. 화면이 적으로 차 있는 장면이 이 상한을 올린 이유이므로 그것부터 깎지 않는다 |

**"GREAT 패리 1발로 잡몹 최소 1종이 즉사할 것"이라는 규칙은 두지 않는다.** 스테이지마다 등장 탄종과 잡몹 HP 배율이 따로 움직여서, 이 조건을 모든 스테이지에서 강제하면 둘 중 하나를 다른 하나에 맞춰 계속 비틀어야 한다. 스테이지 4가 대표적이었다 — 주력 공급탄인 불화살(P8, BRP 12)의 GREAT는 42인데 그 스테이지의 가장 약한 잡몹 HP가 48이라, 규칙을 지키려면 잡몹 HP를 내리거나 웨이브에 없던 탄종을 억지로 넣어야 했다. 고등급 패리의 보상은 §5.3의 배수(GREAT ×3.5)가 이미 충분히 주고 있으므로, 즉사 여부까지 규칙으로 못 박지 않는다.

### 14.4 초기값 검산

이 문서의 수치가 T-03과 T-01·T-02를 실제로 만족하는지 대조한 결과. 수치를 바꿀 때는 이 표를 다시 채워야 한다.

**T-03 검산 — 스테이지 1 원거리 잡몹**

| 적 | HP (배율 1.00) | NOT BAD 1발 | 필요 발수 | 판정 |
|---|---|---|---|---|
| E-A 조총병 | 30 | 조총탄 14 | 3발 (42) | 통과 |
| E-B 궁병 | 36 | 화살 10 | 4발 (40) | **경계** — 조총탄(14)으로는 3발. 실전에서는 두 탄종이 섞여 공급되므로 통과로 본다 |

**T-01·T-02 검산 — 보스 목표 격파 시간**

추정 기준: 패리 성공률 50%, 평균 등급 GOOD(×2.0), 재패리 0회. **쿨다운 0.24초에서 최대 4.16회/초 → 유효 2.08패리/초.** 카드 보정은 스테이지 1·2에서 0장~1장이므로 S1은 1.0배, 이후 회차당 +15%로 잡는다.

| 보스 | HP | 목표 시간 | 필요 DPS | 주력 탄 BRP | 추정 DPS | 여유 |
|---|---|---|---|---|---|---|
| B1 | 1450 | 24초 | 60.4 | 조총탄 14 → GOOD 28 | 58.2 | −4% (빠듯) |
| B2 | 2250 | 27초 | 83.3 | 참격파 30 / 수리검 12 → 평균 GOOD 42 | 87.4 × 1.15 = 100.5 | +21% |
| B3 | 3200 | 29초 | 110.3 | 함포탄 55 → GOOD 110 | 228.8 × 1.30 = 297 | +169% (포문 각도 제약으로 실효 하락, 실측 필요) |
| B4 | 3850 | 32초 | 120.3 | 혼합 평균 BRP 25 → GOOD 50 | 104 × 1.45 = 150.8 | +25% |
| B5 | 5100 | 37초 | 137.8 | 혼합 평균 BRP 45 → GOOD 90 | 187.2 × 1.60 = 299.5 | +117% |

**HP를 왜 이 값으로 올렸는가.** 쿨다운을 0.38초에서 0.24초로 내리면서 유효 패리 빈도가 1.3회/초 → 2.08회/초, 즉 정확히 **1.6배**가 됐다. 보스 HP를 그대로 두면 B1이 24초가 아니라 15초에 죽는다. 목표 격파 시간을 설계 의도대로 지키기 위해 다섯 보스의 HP를 일괄 1.6배 하고 100 단위로 반올림했다. 그 결과 각 보스의 **여유 비율은 개정 전과 거의 같다**(이전 −3 / +21 / +170 / +25 / +116%). 난이도 곡선의 형태는 건드리지 않고 절대 속도만 올린 것이다.

- **B1의 여유 −4%는 그대로 둔다.** 필요 DPS에 4% 못 미친다는 것은 24초 목표가 실제로는 약 25초가 된다는 뜻이고, 1초 차이는 첫 보스에서 문제가 되지 않는다. 오히려 첫 보스가 약간 버텨 주는 편이 학습 구간에 맞다. HP 1450을 유지한다.
- B3·B5는 추정 여유가 과도하다. 실제로는 반사 각도가 맞지 않아 빗나가는 비율이 크므로 **명중률 축을 실측한 뒤** HP를 재산정한다. 추정치만으로 HP를 올리지 않는다.
- 위 추정에는 재패리(§7.4)가 들어 있지 않다. 재패리에는 전용 데미지 보너스가 없고 반사탄을 쫓느라 위치를 버려야 성립하므로 지속 DPS로 계산하지 않는다. 다만 함포탄·대통 폭탄이 주력인 B3·B4에서 실측 DPS가 추정을 크게 웃돌면, 원인 1순위로 **NOT BAD로 받은 저속탄을 GREAT로 다시 쳐내는 빈도**를 확인한다. 보너스가 없어도 등급 재판정만으로 데미지가 3.5배가 되기 때문이다.
- R10(성공 시 쿨다운 초기화, 최소 간격 0.12초)은 위 표의 2.08패리/초를 2.78패리/초로 끌어올린다(§11.4). E07(재입력 불가 0.04초 고정)도 마찬가지로 전제를 벗어난다. 두 카드를 가진 빌드는 T-05의 검사 대상이다.

| 패리 쿨다운 | **플레이어 주변 링**으로 표시. 쿨다운이 0.24초로 짧으므로 링이 채워지는 것이 시각적 잡음이 되지 않아야 한다 |
| 패리 판정 | 패리 위치에 등급 텍스트(NOT BAD / GOOD / GREAT) 팝업. 등급별 색·크기 구분 |
| 재패리 | 일반 패리와 구분되는 표시. 그 발사체를 몇 번째로 쳐냈는지가 읽혀야 한다 |
| 음소거 상태 | 현재 음소거인지 한눈에 보여야 한다 |
| 플레이어 코어 | 반경 10u 피격 판정을 **상시 시각 표시** |
| 무적 상태 | 플레이어가 무적인지 한눈에 구분 가능해야 한다. 무적이 패리 성공 시에만 붙으므로 **성공 순간과 무적 시작이 같은 신호로 읽혀야 한다** |
| 보스 HP | 화면 상단 바. **페이즈 임계값을 눈금으로 표시** |
| 파괴 가능 부위 | B3 포문처럼 개별 HP를 가진 부위는 개별 게이지 표시 |
| 예고 표시 | 착탄 예고 원·관통 예고선·돌진 방향선 3종만. 배경과 명확히 구분되는 색, 발동 직전 강조. **일반 탄환에는 어떤 예고 도형도 그리지 않는다**(HR-05) |
| 발사 예비동작 | 적이 곧 쏜다는 사실이 적 본체의 상태 변화만으로 읽혀야 한다. 궤적을 암시하는 선·화살표는 쓰지 않는다 |

## 16. 입력·조작키

조작은 **이동과 패리 두 가지뿐이다.** 나머지 키는 전부 화면 전환이나 정보 확인용이며, 전투 중 판단에 개입하지 않는다.

| 일시정지 | Esc | — |
| 치트 모드 열기 | Shift + F9 (§18) | — |

- 치트 모드는 전투 중 직접 진입할 수 없다(§18.2). Shift + F9는 일시정지 화면으로 먼저 보낸다.

### 16.6 플랫폼

**PC 브라우저 전용이다. 터치 입력과 모바일을 지원하지 않는다.**

| 항목 | 규칙 |
|---|---|
| 지원 | 키보드 또는 마우스가 있는 PC 브라우저 |
| 미지원 | 터치 조작 일체. 모바일·태블릿 브라우저 |
| 모바일 접속 시 | 게임을 시작하지 않고 **PC에서 플레이해 달라는 안내를 표시한다** |
| 게임패드 | 미지원 |

**플레이필드가 9:16 세로인 것은 모바일을 겨냥한 것이 아니다.** 탄막이 위에서 내려오고 플레이어가 아래에 있는 종스크롤 슈팅에서 세로 화면은 장르 관례이며, §3.1의 좌표계는 그 구조에서 나왔다. 세로 비율을 보고 터치 조작을 전제해서는 안 된다.

**터치를 뺀 이유는 두 가지다.**

- **동시 입력.** 이동과 패리는 동시에 들어가야 한다(§16.1, §16.5). 드래그로 움직이면서 같은 화면을 탭해 패리하는 방식은 한 손가락이 두 역할을 다투게 만든다.
- **판정 가림.** 패리 등급은 탄환과 플레이어 중심 사이 거리로 정해지고(§5.3), 그래서 반경 10u 코어를 상시 표시하도록 요구한다(§15.1). 손가락이 캐릭터 위에 올라가면 그 판정을 볼 수 없다.

둘 다 조작 체계를 새로 설계해야 풀리는 문제이지 이 문서의 조작에 터치를 얹어서 해결되지 않는다.

모바일 안내를 넣는 것은 제출물이 **링크 클릭만으로 열리는 공개 웹 빌드**이기 때문이다. 심사자가 휴대폰으로 열어 볼 가능성이 있고, 그때 조작이 안 되는 화면을 그대로 두면 미지원이 아니라 고장으로 읽힌다.

## 17. 피드백 요구사항

기능적으로 **반드시 구분 가능해야 하는 상태**들. 표현 방법은 이 문서에서 규정하지 않는다.

| 사건 | 필수 피드백 |
|---|---|
| 패리 성공 | 등급별로 **명확히 다른** 시각·청각 신호. 세 등급이 서로 헷갈리면 안 된다 |
| 히트스톱 | 등급별 정지 길이 차이가 체감되어야 한다 (0.02 / 0.05 / 0.075초) |
| 반사탄 발생 | 적 탄환과 반사탄이 **색·형태로 즉시 구분**되어야 한다. 이것을 못 구분하면 게임이 성립하지 않는다 |
| 반사탄의 위험성 | 반사탄이 **플레이어에게도 유효하다**는 사실이 읽혀야 한다(HR-07). 아군 색으로만 칠하면 안전하다고 오해한다 |
| 자해 유예 | 반사 직후 0.15초 동안 무해하다는 사실과 그 유예가 끝나는 시점이 구분되어야 한다 |
| 재패리 | 일반 패리와 다른 신호. 특히 낮은 등급으로 받았던 탄을 높은 등급으로 다시 쳐냈을 때, 데미지가 올랐다는 사실이 읽혀야 한다 |
| 빈 패리 | 성공과 구분되는 별도 신호. **무적이 붙지 않았다는 사실이 그 자리에서 읽혀야 한다** — 이것을 오해하면 §5.4의 억제 구조가 전달되지 않는다 |
| 쿨다운 종료 | 다시 패리 가능해진 순간을 소리 또는 시각으로 알린다. 초당 4회 이상 반복되므로 신호가 피로하지 않아야 한다 |
| 피격 | 라이프 감소 + 무적 진입이 즉시 읽혀야 한다. 원인이 적 탄환인지 반사탄인지 구분되어야 한다 |
| 무적 종료 | 무적이 끝나는 시점이 예측 가능해야 한다 |
| 적 처치 | 반사탄이 유효했다는 사실이 확인되어야 한다 |
| 다수 동시 처치 | 반사탄 한 발이 여러 기를 정리한 사건이 **한 번에 읽혀야 한다.** 잡몹 상한을 20기로 올린 이유가 이 장면이다 |
| 적 발사 예비동작 | 궤적 예고가 없으므로(HR-05) **곧 쏜다는 사실**만은 확실히 읽혀야 한다. 예비동작이 배경에 묻히면 예고 없는 발사가 아니라 불공정한 발사가 된다 |
| 보스 페이즈 전환 | 패턴이 바뀐다는 사실을 사전에 알린다 |
| 패리 불가 대상 | 패리 가능 탄환과 **형태로 구분**되어야 한다. 색만으로 구분하지 않는다 |
| 장판 | 경계가 명확해야 한다. 피해 판정 범위와 표시 범위가 일치해야 한다 |
| 콤보 유지 시간 | 끊기기 직전임을 알린다 |

**사운드는 필수다.** 음소거 옵션을 제공하며(`M`, §16), 전환은 언제든 가능하다.

- 위 표에서 "시각·청각 신호"를 요구하는 항목은 **음소거 상태에서도 시각만으로 전부 구분 가능해야 한다.** 소리에만 실린 정보가 있으면 음소거가 곧 정보 손실이 된다.
- 반대로 소리가 유일하게 맡는 역할도 있다. 쿨다운 종료처럼 화면 밖에서 일어나는 사건은 시선을 뺏지 않고 알릴 수 있는 유일한 수단이 소리다. 음소거 시에는 이 항목들이 §15.1의 시각 표시로 대체된다.

## 18. 치트 모드 (개발·테스트 전용)

### 18.1 목적과 범위

**치트 모드가 조작하는 것은 진행 상태뿐이다.** 어느 스테이지에 있는지, 어떤 카드를 들고 있는지를 직접 정할 수 있을 뿐이고, 전투 규칙 자체는 하나도 바뀌지 않는다. §2의 하드 규칙, §5의 패리 판정, §11.6의 보정 순서와 불변 조건은 치트 모드에서도 전부 그대로 적용된다.

**왜 필요한가.** §14.3의 튜닝 규칙은 전부 특정 조건의 실측을 요구한다 — T-05는 최상급 카드 4장 빌드의 B5 격파 시간, T-06은 반사탄 자해 비율, T-07은 잡몹 20기 구간의 프레임률. 그런데 정상 진행으로 스테이지 5 보스에 도달하려면 약 6분이 걸리고, 카드 4장은 무작위 추첨이라 원하는 조합이 나올 때까지 반복해야 한다(리롤도 런당 1회뿐이다). **검증 1회에 수십 분이 드는 구조를 그대로 두면 §14의 수치는 실측되지 않은 채로 남는다.**

| 포함 | 미포함 |
|---|---|
| 스테이지·보스 페이즈 자유 입장 (§18.3) | 무적, 원턴킬, 탄환 소거 같은 전투 규칙 변경 |
| 업그레이드 카드 자유 선택 (§18.4) | 카드 최대 중첩 수를 넘어서는 부여 |
| 라이프 값 지정 (§18.3) | §14.1 스테이지 파라미터(HP 배율·탄속 배율) 변경 |

미포함 항목을 뺀 이유는 같다. **전투 규칙을 바꾼 상태의 플레이는 실측 데이터가 아니다.** 무적으로 도달한 보스 격파 시간은 T-01의 근거가 될 수 없고, 최대 중첩을 넘긴 빌드는 §11.6의 검산표가 전제하지 않는 조합이라 그 결과로 카드 계수를 조정할 수 없다.

### 18.2 진입과 종료

| 항목 | 값 |
|---|---|
| 진입·종료 입력 | **Shift + F9** |
| 진입 가능 시점 | 타이틀 화면, **일시정지 중**, 카드 선택 화면 |
| 진입 불가 시점 | 전투 진행 중 |
| 종료 | 같은 입력 또는 Esc. 메뉴만 닫히며 **이미 적용한 변경은 되돌아가지 않는다** |
| 게임 시간 | 치트 메뉴가 열려 있는 동안 모든 타이머·탄환·쿨다운 정지 (§13.4 일시정지와 동일) |

- 전투 중 직접 진입을 막은 것은 상태 정합성 때문이다. 탄환이 날아오는 도중에 스테이지가 교체되면 어느 스테이지의 파라미터로 계산된 탄환인지가 불분명해진다. 전투 중에 쓰고 싶으면 `Esc`로 일시정지한 뒤 열면 되므로 기능이 막히지는 않는다.
- **Shift + F9는 §16의 어떤 게임 조작키와도 겹치지 않는다.** F5(새로고침)·F11(전체화면)·F12(개발자 도구)와 Ctrl+Shift+I / Ctrl+Shift+J는 브라우저가 먼저 가져가므로 진입 입력으로 쓰지 않는다.

### 18.3 스테이지 자유 입장

| 항목 | 규칙 |
|---|---|
| 선택 대상 | 스테이지 1~5 |
| 진입 지점 | **스테이지 시작(W1 0:00)** / **특정 웨이브 시작** / **소강 구간 시작(보스 직전)** 중 선택 |
| 보스 페이즈 지정 | B1~B5의 임의 페이즈에서 시작. 보스 HP는 해당 페이즈의 상한값으로 설정 (예: B5 페이즈 3 지정 시 HP를 5100의 50%인 2550으로) |
| 스테이지 파라미터 | §14.1의 해당 스테이지 값을 **그대로 적용한다.** 치트로 건너뛰어도 적 HP 배율·탄속 배율·예비동작 시간·동시 탄환 상한은 정상값이다 |
| 라이프 | 기본은 진입 시점의 값을 유지. 1 ~ 현재 최대 라이프 범위에서 직접 지정 가능 |
| 콤보 | 0으로 초기화 (§12.2의 스테이지 전환 규칙과 동일) |
| 화면 정리 | 진입 시 기존 적·적 탄환·반사탄·장판을 모두 제거한다 |
| 카드 | **현재 보유 카드를 그대로 들고 간다. 건너뛴 스테이지의 카드가 자동 지급되지 않는다** |
| 리롤 | 사용 여부를 초기화할 수 있다. 카드 추첨 화면 자체를 반복 검증할 때 필요하다 |

마지막 항목이 중요하다. 스테이지 1에서 5로 점프하면 정상 플레이라면 카드 4장을 들고 있을 시점이지만, 자동으로 4장을 추첨해 주면 **무작위가 섞여 같은 조건을 두 번 재현할 수 없다.** 테스트에서 필요한 것은 "그럴듯한 빌드"가 아니라 "지정한 빌드"이므로, 카드는 §18.4에서 직접 지정한다.

- 보스 페이즈 지정은 가장 자주 쓰이는 기능이다. B5는 4페이즈이고 목표 격파 시간이 37초라, 페이즈 4 패턴 하나를 확인하려면 정상 진행으로 6분 + 보스전 28초를 지나야 한다.
- 스테이지 자유 입장은 §13.1의 진행 흐름을 건너뛰는 유일한 경로다. 정상 플레이에서 스테이지는 언제나 클리어를 통해서만 넘어간다.

### 18.4 업그레이드 카드 자유 선택

| 항목 | 규칙 |
|---|---|
| 선택 대상 | **31종 전체.** 등급 추첨 가중치(§11.2)와 제시 가능 조건을 무시하고 목록에서 직접 고른다 |
| 중첩 | 각 카드의 **최대 중첩 수까지** 자유롭게 쌓을 수 있다. **최대 중첩 수 자체는 넘을 수 없다** |
| 제거 | 개별 카드 제거, 전체 초기화 가능 |
| 반영 시점 | 변경 즉시 §11.6의 보정 순서 1~9를 다시 실행한다 |
| 상한·불변 조건 | INV-1·INV-2, 쿨다운 하한, 반경 상한, 이동 속도 상한, 반사탄 속도 상한이 **전부 정상 적용된다** |
| 즉발 효과 카드 | N14(라이프 +1)·R06(최대 라이프 +1, 라이프 +1)은 부여 순간 1회 발동한다. **제거해도 이미 오른 라이프는 되돌리지 않는다** |
| 실효 수치 표시 | 현재 빌드의 계산 결과를 함께 표시한다 — 활성 시간 / 쿨다운 / 패리 무적 / 패리 반경 / 등급 밴드 경계 / 반사탄 데미지 배수, 그리고 **어떤 상한이나 불변 조건이 값을 잘랐는지** |

**최대 중첩 수를 넘기지 못하게 한 이유.** §11.6의 최악 조합 검산 두 개는 "정상 플레이로 도달 가능한 가장 극단적인 빌드"를 가정하고 쓴 것이다. N04를 4중첩으로 만들 수 있게 하면 그 검산이 다루지 않는 조합이 생기고, 그 결과를 근거로 카드 계수를 조정하면 실제로는 존재할 수 없는 빌드에 맞춰 밸런스를 깎게 된다. **치트 모드로 만들 수 있는 빌드의 범위는 정상 플레이의 범위와 정확히 같아야 한다.**

**실효 수치 표시가 이 기능의 핵심이다.** §11.6의 보정 순서는 9단계이고 INV-1·INV-2가 서로 다른 방향으로 값을 자른다. 검산 1에서 N04 3중첩이 쿨다운을 0.197초로 내렸는데 INV-1이 0.23초로 되돌리는 것 같은 상호작용은, 숫자로 보이지 않으면 실측 중에 원인을 잘못 짚게 된다. 즉발 효과 카드의 라이프가 되돌아가지 않는 것도 같은 이유로 명시했다 — 되돌리면 라이프가 음수가 될 수 있다.

### 18.5 런 무결성

치트 모드를 **한 번이라도 연 런**은 오염된 런으로 표시한다.

| 항목 | 규칙 |
|---|---|
| 표시 시점 | 치트 메뉴를 연 순간부터. 아무것도 바꾸지 않고 닫아도 표시는 남는다 |
| 인게임 표시 | HUD에 상시 표시. 정상 플레이 중인지 아닌지가 언제나 보여야 한다 |
| 결과 화면 | §12.3에 오염 여부를 명시한다 |
| 점수 | 기록·순위 대상에서 제외한다 |
| 해제 | 런 도중에는 해제되지 않는다. 재시작해야 초기화된다 |

아무것도 바꾸지 않고 닫아도 표시가 남는 것은 판정을 단순하게 유지하기 위해서다. "무엇을 바꿨을 때만 오염"으로 만들면 오염 여부 자체가 또 하나의 판정 규칙이 되고, 그 규칙에 구멍이 생기면 §14의 실측 데이터에 치트 플레이가 섞여 들어간다. **오염 판정은 틀렸을 때 손해가 한쪽으로만 나야 한다** — 멀쩡한 런을 오염으로 표시하면 한 판 더 하면 되지만, 오염된 런을 정상으로 기록하면 그 수치가 튜닝 근거가 된다.

### 18.6 제출 빌드에서의 취급

**치트 모드는 제출 빌드에도 그대로 포함한다.** 진입 입력도 Shift + F9 그대로 둔다.

NAN 2026 사전 과제 제출물은 링크 클릭만으로 브라우저에서 바로 플레이되는 웹 빌드이고, 심사자가 직접 조작한다. 심사자가 우연히 열 위험은 진입 입력이 막는다 — Shift + F9는 §16의 게임 조작키 어디와도 겹치지 않으므로 정상 플레이 중 눌릴 일이 없다.

남겨 두는 편이 나은 이유도 있다. 스테이지 5까지 완주하려면 450초가 걸리는데, 심사자가 그만큼 붙어 있을 것이라고 가정할 수 없다. **후반 스테이지와 보스를 직접 보고 싶을 때 열 수 있는 입구가 있는 편이 낫다.**

**제출 영상에는 쓰지 않는다.** 공식 요건은 30~60초 영상이 실제 플레이 화면이어야 하고 조작·합성이 불가하다고 명시한다. 치트 모드로 만든 상황을 찍은 영상은 이 조건에 걸린다. 영상은 정상 진행으로 촬영하며, §18.5의 오염 표시가 HUD에 떠 있는 화면은 그대로 실격 사유가 되므로 촬영 전에 반드시 확인한다.

- 소스 코드에서도 지우지 않는다. 제출물에는 전체 소스와 커밋 기록이 포함되며, 개발 과정에서 실제로 쓴 도구를 삭제하면 커밋 기록과 어긋난다.
- AI 활용 기술 문서에 치트 모드를 **테스트 도구로 명시한다.** §14의 수치가 어떤 과정으로 실측됐는지를 설명하는 근거가 된다.
