# 기능 명세서 — 가칭 「환도(還刀)」

**장르**: 종스크롤 비행 슈팅 × 뱀파이어 서바이벌형 빌드 성장 × 패리 액션
**한 줄 규칙**: 플레이어는 공격 수단이 없다. 적이 쏜 탄환을 패리로 튕겨낸 반사탄만이 유일한 데미지원이다.
**배경**: 임진왜란 (1592~1598), 조선 검사

---

## 0. 이 문서의 범위

### 0.1 포함하는 것

- 게임이 만족해야 할 **기능 요구사항**과 그에 딸린 **수치**
- 시스템 간 인과 관계 (어떤 입력이 어떤 상태 변화를 일으키는가)
- 스테이지·적·보스·카드의 전체 목록과 파라미터 표
- 판정 규칙, 우선순위, 예외 처리

### 0.2 포함하지 않는 것

- 기술 스택, 엔진, 라이브러리, 파일 구조, 클래스 설계, 알고리즘 최적화
- 아트 스타일 가이드, 사운드 제작 지침, 스토리·대사·연출 각본
- 마케팅, 심사 전략, 팀 역할 분담

**구현 방법은 이 문서에서 일절 다루지 않는다.** 반사 각도 공식처럼 수식이 등장하는 곳은 "이런 결과가 나와야 한다"는 동작 정의이지 코드 지시가 아니다.

### 0.3 수치의 지위

이 문서의 모든 수치는 **초기값**이며 실측 플레이로 조정될 대상이다. 조정 시 §14의 튜닝 규칙을 따른다. 다만 §2의 하드 규칙(HR-01~HR-08)은 수치가 아니라 제약이므로 조정 대상이 아니다.

## 1. 용어 정의

| 용어 | 정의 |
|---|---|
| **논리 단위(u)** | 화면 해상도와 무관한 게임 내 좌표 단위. 플레이필드는 1080u × 1920u. |
| **패리** | 플레이어가 패리 입력을 넣어 주변 원형 판정 영역을 활성화하는 행위. |
| **패리 원** | 플레이어 중심을 원점으로 하는 반경 R의 원. 이 안에 들어온 적 탄환이 패리 대상이 된다. |
| **패리 등급** | 패리 성립 순간 탄환과 플레이어 중심 사이 거리로 결정되는 3단계 판정. NOT BAD / GOOD / GREAT. |
| **적 탄환** | 적이 발사한 발사체. 플레이어에게 피해를 준다. |
| **반사탄** | 패리로 소유권이 뒤집힌 발사체. 적에게만 피해를 준다. 플레이어에게 무해. |
| **반사기본위력(BRP)** | 탄환 종류마다 고정된 값. 반사탄 데미지 계산의 기준값. |
| **웨이브** | 스테이지를 구성하는 시간 구획. 정해진 시각에 정해진 적 편성이 등장한다. |
| **소강 구간** | 마지막 웨이브 종료와 보스 등장 사이의 무적 대기 구간. |
| **런(run)** | 스테이지 1 시작부터 게임오버 또는 스테이지 5 클리어까지의 1회 플레이. |
| **조준선** | 적이 발사 직전 표시하는 예고선. 발사 궤적과 일치한다. |
| **착탄 예고 원** | 곡사 공격이 떨어질 지점을 미리 표시하는 원. |
| **장판** | 지속 시간 동안 특정 영역에 머무는 피해 영역. 패리 불가. |

## 2. 하드 규칙

시스템 전체가 항상 만족해야 하는 제약. 밸런싱으로 완화할 수 없다.

| ID | 규칙 |
|---|---|
| **HR-01** | 플레이어는 직접 공격 수단을 가지지 않는다. 반사탄 외의 데미지 소스는 존재하지 않는다. |
| **HR-02** | 모든 웨이브 편성에는 **원거리 공격 적이 최소 1기 이상** 포함되어야 한다. 근접·돌격 전용 편성은 금지된다. 플레이어의 탄약 공급이 끊기기 때문이다. |
| **HR-03** | 게임 플레이 중 **적 탄환이 화면에 하나도 없는 상태가 2.0초를 초과할 수 없다.** 보스 페이즈 전환 연출 구간도 이 상한에 포함된다. |
| **HR-04** | 패리 불가 공격(장판, 관통 대창, 본체 접촉)은 **반드시 회피 가능한 안전 지대**를 남겨야 한다. 화면 전체를 덮는 패리 불가 공격은 금지된다. |
| **HR-05** | 모든 원거리 공격은 발사 전 **조준선 또는 착탄 예고 원**을 표시한다. 예고 없는 발사는 금지된다. |
| **HR-06** | 게임 내 모든 시간 파라미터는 밀리초(ms) 또는 초(s)로 정의한다. 프레임 수로 정의하지 않으며, 프레임률이 변해도 동일한 실시간이 유지되어야 한다. |
| **HR-07** | 반사탄은 플레이어에게 피해를 주지 않는다. 적 탄환은 다른 적에게 피해를 주지 않는다. |
| **HR-08** | 보스는 항상 플레이필드 상단 영역에 머문다. 반사탄이 위로 향했을 때 보스에 도달할 수 있어야 한다. (하단으로 밀고 내려오는 돌진 패턴은 예외이며, 이 구간에는 별도 안전 지대를 둔다.) |

## 4. 플레이어 사양

### 4.1 기본 파라미터

| 항목 | 값 | 비고 |
|---|---|---|
| 이동 속도 | 520 u/s | 8방향, 대각선 정규화(대각선이 빠르지 않음) |
| 가속/감속 | 없음 (즉시 최고속) | 입력 지연 0 |
| 피격 판정 반경 | 10u | 캐릭터 스프라이트 중심. 화면에 코어 점으로 상시 표시 |
| 시각적 크기 | 약 90u | 판정과 무관 |
| 초기 라이프 | 3 | 전 스테이지 공유 |
| 최대 라이프 | 5 | 카드로만 증가 |

### 4.2 피격 처리

플레이어 코어(반경 10u)와 적 탄환·적 본체가 겹치면 피격.

| 단계 | 동작 |
|---|---|
| 1 | 라이프 -1 |
| 2 | 플레이어 중심 반경 **280u** 내의 모든 적 탄환 즉시 소멸 (반사탄 아님, 점수 없음) |
| 3 | 무적 **1.5초** 부여 |
| 4 | 콤보 0으로 초기화 |
| 5 | 히트스톱 140ms |
| 6 | 라이프가 0이면 게임오버 처리(§13.3) |

- 무적 중에는 적 탄환·적 본체·장판 모두 무해하며, 무적 중에도 패리는 정상 동작한다.
- 무적 상태는 플레이어 표시로 구분 가능해야 한다(§17).

### 4.3 장판 피해

- 장판 영역 안에 플레이어 코어가 들어가면 **0.5초 간격**으로 피격 판정.
- 진입 즉시 1회 판정, 이후 0.5초마다 반복.
- 피격 시 §4.2와 동일하게 처리되므로 무적 1.5초 동안은 추가 피해가 없다.

## 5. 패리 시스템

### 5.1 입력과 상태

패리는 **방향 입력이 없다.** 한 개의 버튼으로 플레이어 주변 전 범위를 판정한다.

| 항목 | 값 |
|---|---|
| 패리 반경 R | **70u** (플레이어 중심 기준) |
| 활성 시간 | **150ms** |
| 쿨다운 | **380ms** (활성 시작 시점 기준) |
| 재입력 불가 구간 | 활성 종료 후 **230ms** |
| 선입력 버퍼 | 쿨다운 종료 **120ms 전**부터 입력 접수, 종료 즉시 발동 |
| 패리 중 무적 | 활성 150ms 전체 구간 |

- 입력은 눌림(press) 순간에만 접수한다. 누르고 있어도 활성이 연장되지 않는다.
- 쿨다운 중 입력은 선입력 버퍼 구간이 아니면 무시된다.

**불변 조건** — 카드로 파라미터가 변해도 아래 두 가지는 항상 성립해야 한다.

| ID | 조건 | 이유 |
|---|---|---|
| **INV-1** | `쿨다운 ≥ 활성 시간 + 100ms` | 위반 시 패리를 연타하는 것만으로 활성 구간이 끊기지 않고 이어져 영구 무적이 된다 |
| **INV-2** | `패리 유래 무적 총 지속 ≤ 쿨다운 × 0.6` | 같은 이유. 무적만 잘리며 **패리 판정 자체는 활성 시간 전체에서 정상 동작한다** |

두 조건은 카드 효과를 모두 합산한 **뒤에** 검사하며, 위반 시 각각 쿨다운을 늘리고 무적을 자르는 방향으로 보정한다.

### 5.2 패리 성립 조건

활성 구간의 매 프레임, 아래 조건을 **모두** 만족하는 적 탄환이 패리된다.

| 조건 | 내용 |
|---|---|
| C1 | 탄환 중심과 플레이어 중심 사이 거리 `d ≤ R` |
| C2 | 탄환이 플레이어에게 **접근 중**일 것 — 탄환 속도 벡터 `v`와 법선 `n`에 대해 `v · n < 0` |
| C3 | 탄환의 패리 가능 플래그가 참일 것 (§6 표의 "패리" 열) |
| C4 | 해당 탄환이 이번 활성 구간에서 아직 패리되지 않았을 것 |

`n = normalize(탄환위치 − 플레이어위치)`

- C2가 있으므로 이미 스쳐 지나간 탄환은 패리되지 않는다.
- 활성 구간 도중 새로 반경 안에 들어온 탄환도 그 진입 프레임에 판정된다. 따라서 **일찍 누르면 탄환이 원의 바깥 가장자리에서 걸려 낮은 등급이 나오고, 늦게 누를수록 탄환이 중심에 가까워져 높은 등급이 나온다.**

### 5.3 등급 판정

패리 성립 프레임의 거리 `d`로 등급을 결정한다.

| 등급 | 거리 조건 | 데미지 배수 | 반사 속도 배수 | 히트스톱 | 점수 |
|---|---|---|---|---|---|
| **NOT BAD** | 48 < d ≤ 70 | ×1.0 | ×1.3 | 25ms | 50 |
| **GOOD** | 28 < d ≤ 48 | ×2.0 | ×1.8 | 55ms | 150 |
| **GREAT** | d ≤ 28 | ×3.5 | ×2.6 | 90ms | 400 |

**타이밍이 곧 거리다.** 예를 들어 속도 600u/s 탄환이 정면으로 접근할 때, 반경 70u에서 28u까지 42u를 이동하는 데 70ms가 걸린다. 즉 GREAT를 노리려면 NOT BAD가 나오는 타이밍보다 70ms 늦게 눌러야 하고, 그보다 더 늦으면 탄환이 코어(10u)에 닿아 피격된다. 탄환이 빠를수록 이 창이 좁아진다.

**대형 탄환의 GREAT는 "맞기 직전"이 아니라 "이미 겹친 상태"다.** 등급 판정 거리 `d`는 탄환 **중심**과 플레이어 중심 사이 거리이므로, 반경이 큰 탄환일수록 GREAT를 받는 순간 탄환 몸통이 이미 플레이어 코어를 덮고 있다. 참격파(P5, 반경 34u)를 예로 들면 `d = 44` 지점에서 탄환 가장자리가 코어(10u)에 닿는데, GREAT 밴드는 `d ≤ 28`이라 그보다 한참 안쪽이다. 패리 활성 구간의 무적이 이것을 성립시킨다. 즉 **대형 저속탄은 "몸으로 받아내는" 감각이 되고, 소형 고속탄은 "스쳐 지나가기 직전에 쳐내는" 감각이 된다.** 의도된 차이이며, §14.2의 난이도 축 1(탄속)과 함께 스테이지별 체감을 만든다.

- 동일 활성 구간에 여러 탄환이 패리되면 **각 탄환이 자기 거리로 개별 등급**을 받는다.
- 히트스톱·점수·콤보는 그중 **최고 등급 기준으로 1회만** 적용한다.
- 등급 밴드 경계는 카드로 변경될 수 있다(§11). 변경 후에도 `GREAT 상한 < GOOD 상한 ≤ R` 순서는 항상 유지된다. 카드 조합으로 순서가 깨지면 상위 밴드를 하위 밴드 상한에 맞춰 자른다.

### 5.4 빈 패리

활성 구간에 패리된 탄환이 0개인 경우.

- 무적 150ms는 정상 부여된다.
- 콤보는 리셋되지 않는다.
- 점수·히트스톱 없음.
- 카드 N13 보유 시 쿨다운이 단축된다.

### 5.5 반사 방향

패리 성립 시 탄환의 속도 벡터를 아래대로 변환한다.

```
n  = normalize(탄환위치 − 플레이어위치)
v' = v − 2 (v · n) n
반사탄 속도 = |v'| × (등급별 반사 속도 배수) × (카드 보정)
반사탄 방향 = normalize(v')
```

동작 결과:

- 탄환을 **정면(중심 가까이)으로 받으면** `n`이 `v`와 거의 반대이므로 `v' ≈ −v`, 즉 쏜 적에게 그대로 되돌아간다.
- 탄환을 **가장자리로 스치게 받으면** `n`이 `v`에 가까워지므로 크게 꺾여 옆으로 튄다.

즉 **몸 위치가 조준이다.** 정확도가 높을수록(=GREAT) 반사탄이 곧게 되돌아가고, 데미지도 높다. 두 보상이 같은 방향을 가리킨다.

### 5.6 패리 불가 대상

| 대상 | 처리 |
|---|---|
| 화염 장판 (P9) | 패리 원 안에 있어도 무시. 무적 중이 아니면 피해. |
| 관통 대창 (P12) | 패리 불가. 무적 중에만 무해. |
| 적 본체 | 패리 불가. 무적 중에만 무해. |
| 이미 반사된 탄환 | 재패리 불가. 반사탄은 플레이어에게 무해하므로 판정 자체를 하지 않는다. |

## 7. 반사탄 사양

### 7.1 기본 동작

| 항목 | 값 |
|---|---|
| 소유권 | 적 전용 판정. 플레이어에게 무해 (HR-07) |
| 데미지 | `BRP × 등급 배수 × 카드 보정` |
| 속도 | `원래 속도 × 등급 반사 속도 배수 × 카드 보정` |
| 수명 | 3.0초. 이후 소멸 |
| 관통 | 기본 없음. 적 1기 명중 시 소멸 (카드로 변경 가능) |
| 화면 밖 | 경계 +150u 이탈 시 소멸 |
| 재패리 | 불가 |
| 유도 | 기본 없음 (카드 R03으로 부여) |

### 7.2 데미지 계산 순서

```
1. 기준값        = 탄환 BRP
2. 등급 배수 적용 = 기준값 × (NOT BAD 1.0 / GOOD 2.0 / GREAT 3.5)
3. 가산 보정      = 카드의 "+N%" 효과를 모두 더해 한 번에 곱한다
4. 조건부 배수    = R04(GREAT 시 ×1.5) 등 조건 만족 시 곱한다
5. 분열 감쇠      = R01·E01 등 분열 카드의 개별 계수를 곱한다
6. 최종 데미지    = 소수점 내림
```

예시: 조총탄(BRP 14)을 GREAT로 패리, 카드 N01 3중첩(+45%)과 R04 보유.
`14 × 3.5 × 1.45 × 1.5 = 106.5 → 106`

### 7.3 방패병 상호작용

- 방패병(§8)은 **정면 방향에서 들어오는 반사탄 1회를 무효화**한다.
- 무효화 후 방패는 파괴되어 이후 반사탄은 정상 피해를 준다.
- 측면·후면에서 들어온 반사탄은 방패를 무시한다. 즉 원형 거울 반사로 각도를 틀어 옆에서 때리는 것이 정답 행동이다.

## 9. 스테이지 구성

### 9.1 공통 구조

```
스테이지 시작
  → 웨이브 1..N (시간 기반 진행)
  → 소강 구간 (3초, 적 탄환 없음 — HR-03의 유일한 예외)
  → 보스 등장
  → 보스 격파
  → 스테이지 클리어
  → 업그레이드 카드 선택 (스테이지 1~4만)
  → 다음 스테이지
```

**웨이브 진행 규칙**

- 웨이브는 **시간 기반**으로 전환된다. 이전 웨이브의 적을 다 잡지 못해도 다음 웨이브가 시작된다.
- 잔존 적은 그대로 유지되며, 동시 잡몹 상한 12기에 걸리면 신규 스폰이 상한 아래로 내려갈 때까지 지연된다.
- 마지막 웨이브 종료 시점에 잔존 잡몹이 있으면 **4초간 유예** 후 화면 밖으로 강제 퇴장시킨다. 퇴장한 적은 점수를 주지 않는다.
- 소강 구간 3초 동안 플레이어는 무적이 아니며, 잔존 반사탄은 유지된다.

| 분열 계수 (R01·E01) | 마지막에 곱연산. 두 카드를 동시 보유하면 분열이 중첩되어 총 6발, 각 계수 `0.65 × 0.55 = 0.3575` |
| 상충 (R09 vs N08·E05) | 밴드 조정은 전부 가산 적용. 결과가 `GREAT 상한 > GOOD 상한`이 되면 GREAT 상한을 GOOD 상한 값으로 자른다 |
| 쿨다운 하한 | 어떤 조합으로도 **120ms 미만이 될 수 없다** |
| 쿨다운 vs 활성 | **INV-1** — 위 하한을 적용한 뒤에도 `쿨다운 < 활성 시간 + 100ms`이면 쿨다운을 `활성 시간 + 100ms`로 올린다 |
| 패리 무적 총합 | **INV-2** — `쿨다운 × 0.6`으로 자른다. 무적만 잘리고 패리 판정 창은 유지된다 |
| 패리 반경 상한 | 어떤 조합으로도 **150u를 초과할 수 없다** |
| 이동 속도 상한 | 900 u/s |

**보정 순서** — 상충이 생기면 아래 순서로 처리한다.

```
1. 같은 카드 중첩 가산
2. 카드 간 % 효과 가산 → 1회 곱연산
3. 조건부 배수 곱연산
4. 분열 계수 곱연산
5. 개별 상한 적용 (쿨다운 하한, 반경 상한, 이동 속도 상한)
6. 밴드 순서 보정 (GREAT 상한 > GOOD 상한이면 잘라냄)
7. INV-1 적용 (쿨다운 상향)
8. INV-2 적용 (무적 하향)
```

**최악 조합 검산** — E07(쿨다운 −45%) + R10(−22%) + N04 3중첩(−24%) + N05 3중첩(활성 +45ms) + N10 2중첩(무적 +0.24s)

```
쿨다운   380 × (1 − 0.91) = 34.2 → 하한 120ms
활성     150 + 45 = 195ms
INV-1    120 < 195 + 100  →  쿨다운 295ms 로 상향
무적     150 + 240 = 390ms
INV-2    295 × 0.6 = 177ms 로 하향
결과     활성 195ms / 쿨다운 295ms / 무적 177ms  →  무적 점유율 60%
```

## 13. 게임 진행·실패·재시작

### 13.1 진행 흐름

```
타이틀
  → 스테이지 1
  → [클리어] → 카드 선택 → 스테이지 2
  → [클리어] → 카드 선택 → 스테이지 3
  → [클리어] → 카드 선택 → 스테이지 4
  → [클리어] → 카드 선택 → 스테이지 5
  → [클리어] → 엔딩 · 결과 화면
```

### 13.2 라이프

- 라이프는 **5스테이지 전체를 관통하여 공유**된다. 스테이지 클리어로 회복되지 않는다.
- 회복 수단은 카드 N14(즉시 +1), R06(최대치 +1 및 즉시 +1), E03(보호막)뿐이다.

### 13.3 게임오버

라이프 0 도달 시.

| 단계 | 동작 |
|---|---|
| 1 | 즉시 게임 정지, 결과 화면 표시 (§12.3) |
| 2 | 재시작 선택 시 **스테이지 1**부터 시작 |
| 3 | **획득한 카드 전부 소실**. 라이프·최대 라이프·점수·콤보 전부 초기값으로 |
| 4 | 다음 런의 카드 추첨은 이전 런과 독립적이다 (기억하지 않는다) |

**중간 진행 저장은 없다.** 스테이지 3에서 죽으면 스테이지 1부터다. 이것이 매 런마다 다른 카드 조합이 나오는 구조를 성립시킨다.

### 13.4 일시정지

- 언제든 일시정지 가능. 모든 타이머·탄환·쿨다운 정지.
- 일시정지 중 재시작(런 포기) 가능.

### 14.2 난이도 상승 축

난이도는 아래 5개 축으로만 올린다. **적 HP를 올리는 것만으로 난이도를 만들지 않는다.**

| 축 | 상승 방식 |
|---|---|
| 1. 탄속 | 빨라질수록 GREAT 판정 창이 좁아진다 (§5.3) |
| 2. 예고 시간 | 짧아질수록 반응 여유가 준다 |
| 3. 동시 탄환 수 | 패리 쿨다운 때문에 모든 탄을 받을 수 없게 된다 |
| 4. 패리 불가 요소 | 패리만으로 해결되지 않는 위협을 섞는다 |
| 5. 위협 종류 전환 속도 | 보스 페이즈가 늘어나며 대응 전환 빈도가 오른다 |

### 14.3 튜닝 규칙

| 규칙 | 내용 |
|---|---|
| T-01 | 보스 HP는 **카드 미획득 상태의 추정 DPS × 목표 격파 시간**으로 산출한 뒤 실측으로 조정한다 |
| T-02 | 추정 DPS 계산 기준: 실제 패리 성공률 50%, 평균 등급 GOOD(×2.0) |
| T-03 | 스테이지 1의 **원거리 잡몹(E-A, E-B)** 은 NOT BAD 패리 3발 이내로 죽어야 한다. 초기 학습 구간에서 좌절을 만들지 않기 위함. 근접형(E-C, E-D)은 이 조건에서 제외한다 — 회피가 정답 행동이기 때문 |
| T-04 | 모든 스테이지에서 **그 스테이지에 실제로 등장하는 탄환**으로 GREAT 패리 1발을 냈을 때, 해당 스테이지 잡몹 최소 1종이 즉사해야 한다. 카드 없이도 성립해야 한다 |
| T-05 | 목표 길이 대비 ±15% 이상 벗어나면 웨이브 시간이 아니라 **적 HP 배율**을 먼저 조정한다 |
| T-06 | 카드 4장을 모두 최상급으로 받은 빌드가 스테이지 5 보스를 **20초 미만**에 격파하면 카드 계수를 낮춘다 |

### 14.4 초기값 검산

이 문서의 수치가 T-03·T-04와 T-01·T-02를 실제로 만족하는지 대조한 결과. 수치를 바꿀 때는 이 표를 다시 채워야 한다.

**T-03 검산 — 스테이지 1 원거리 잡몹**

| 적 | HP (배율 1.00) | NOT BAD 1발 | 필요 발수 | 판정 |
|---|---|---|---|---|
| E-A 조총병 | 30 | 조총탄 14 | 3발 (42) | 통과 |
| E-B 궁병 | 36 | 화살 10 | 4발 (40) | **경계** — 조총탄(14)으로는 3발. 실전에서는 두 탄종이 섞여 공급되므로 통과로 본다 |

**T-04 검산 — 스테이지별 GREAT 1발 즉사 대상**

| 스테이지 | HP 배율 | 사용 탄환 (최고 BRP) | GREAT 데미지 | 즉사 대상 | 대상 HP | 판정 |
|---|---|---|---|---|---|---|
| S1 | 1.00 | 조총탄 P2 (14) | 49 | E-A / E-B / E-D | 30 / 36 / 40 | 통과 |
| S2 | 1.35 | 조총탄 P2 (14) | 49 | E-A / E-F | 40 / 27 | 통과 |
| S3 | 1.80 | 함포탄 P6 (55) | 192 | E-A / E-B / E-D / E-F | 54~72 | 통과 |
| S4 | 2.40 | 대통 폭탄 P7 (70) | 245 | E-A / E-F / E-H | 48~96 | 통과 |
| S5 | 3.10 | 함포탄 P6 (55) | 192 | E-A / E-B / E-D / E-F | 62~124 | 통과 |

- S4에서 주력 공급탄인 불화살(P8, BRP 12)만 놓고 보면 GREAT가 42에 그쳐 E-F(48)조차 못 잡는다. T-04는 **대통 폭탄(P7)이 등장하는 보스 페이즈 2 이후**에 성립한다. 웨이브 구간에서 T-04를 성립시키려면 E-F의 기본 HP를 20 미만으로 더 내리거나 W1~W4에 P6/P7 공급원을 추가해야 한다 → **실측 후 결정 대상.**

**T-01·T-02 검산 — 보스 목표 격파 시간**

추정 기준: 패리 성공률 50%, 평균 등급 GOOD(×2.0), 쿨다운 380ms에서 최대 2.6회/초 → 유효 1.3패리/초. 카드 보정은 스테이지 1·2에서 0장~1장이므로 S1은 1.0배, 이후 회차당 +15%로 잡는다.

| 보스 | HP | 목표 시간 | 필요 DPS | 주력 탄 BRP | 추정 DPS | 여유 |
|---|---|---|---|---|---|---|
| B1 | 900 | 24s | 37.5 | 조총탄 14 → GOOD 28 | 36.4 | −3% (빠듯) |
| B2 | 1400 | 27s | 51.9 | 참격파 30 / 수리검 12 → 평균 GOOD 42 | 54.6 × 1.15 = 62.8 | +21% |
| B3 | 2000 | 29s | 69.0 | 함포탄 55 → GOOD 110 | 143 × 1.30 = 186 | +170% (포문 각도 제약으로 실효 하락, 실측 필요) |
| B4 | 2400 | 32s | 75.0 | 혼합 평균 BRP 25 → GOOD 50 | 65 × 1.45 = 94 | +25% |
| B5 | 3200 | 37s | 86.5 | 혼합 평균 BRP 45 → GOOD 90 | 117 × 1.60 = 187 | +116% |

- B1은 여유가 음수다. 실측에서 24초를 넘기면 T-05에 따라 **보스 HP를 800으로 내린다.**
- B3·B5는 추정 여유가 과도하다. 실제로는 반사 각도가 맞지 않아 빗나가는 비율이 크므로 **명중률 축을 실측한 뒤** HP를 재산정한다. 추정치만으로 HP를 올리지 않는다.

## 17. 피드백 요구사항

기능적으로 **반드시 구분 가능해야 하는 상태**들. 표현 방법은 이 문서에서 규정하지 않는다.

| 사건 | 필수 피드백 |
|---|---|
| 패리 성공 | 등급별로 **명확히 다른** 시각·청각 신호. 세 등급이 서로 헷갈리면 안 된다 |
| 히트스톱 | 등급별 정지 길이 차이가 체감되어야 한다 (25 / 55 / 90ms) |
| 반사탄 발생 | 적 탄환과 반사탄이 **색·형태로 즉시 구분**되어야 한다. 이것을 못 구분하면 게임이 성립하지 않는다 |
| 빈 패리 | 성공과 구분되는 별도 신호 |
| 쿨다운 종료 | 다시 패리 가능해진 순간을 소리 또는 시각으로 알린다 |
| 피격 | 라이프 감소 + 무적 진입이 즉시 읽혀야 한다 |
| 무적 종료 | 무적이 끝나는 시점이 예측 가능해야 한다 |
| 적 처치 | 반사탄이 유효했다는 사실이 확인되어야 한다 |
| 보스 페이즈 전환 | 패턴이 바뀐다는 사실을 사전에 알린다 |
| 패리 불가 대상 | 패리 가능 탄환과 **형태로 구분**되어야 한다. 색만으로 구분하지 않는다 |
| 장판 | 경계가 명확해야 한다. 피해 판정 범위와 표시 범위가 일치해야 한다 |
| 콤보 유지 시간 | 끊기기 직전임을 알린다 |

## 부록 B. 참고한 외부 자료

수치의 근거로 참조한 자료. 이 문서의 값은 참조값을 그대로 쓰지 않고 본 게임 구조에 맞게 재설정한 것이다.

**패리 판정 창**

- Sekiro: Shadows Die Twice — 디플렉트 창 12프레임(60fps 기준), 약 200ms — [Fextralife Wiki](https://sekiroshadowsdietwice.wiki.fextralife.com/Deflection)
- Nine Sols — 퍼펙트 패리 0.133초(약 8프레임), 부정확 패리 0.5초 확장 창, 부정확 시 내부 데미지 50% — [Switchblade Gaming](https://www.switchbladegaming.com/action-rpg/parry-timing-guide/)
- Clair Obscur: Expedition 33 — 난이도별 패리 창 0.25 / 0.15 / 0.15초, 회피 창 0.35 / 0.22 / 0.22초 — [Steam Community](https://steamcommunity.com/app/1903340/discussions/0/592898892338594952)
- Where Winds Meet — 퍼펙트 / 이른·늦은 / 실패 3단계 결과 분기 구조 — [Buffget](https://buffget.com/news/where-winds-meet-parry-guide-timings-and-frame-data)

**게임 필(히트스톱·스크린셰이크)**

- 히트스톱 통상 40~80ms, 무거운 타격 확정 시 60~80ms — [Egmatic](https://egmatic.com/blog/how-to-make-your-game-feel-good), [Valdemird](https://valdemird.com/blog/game-feel-on-the-web/)

**탄막 패턴 분류**

- 조준(Aimed) / 정적(Static) / 무작위(Random) 3분류, 링·확산·나선·레이저 구성 요소, 레이저는 반드시 예고선을 둘 것 — [Sparen's Danmaku Design Studio](https://sparen.github.io/ph3tutorials/danmakudesign.html)
- 탄막 밀도 설계 — [Sparen's Guide A4](https://sparen.github.io/ph3tutorials/ddsga4.html)

**슈팅 게임 히트박스 관례**

- 캐릭터 스프라이트 30~40px에 대해 실제 피격 판정은 중심부 수 px. 판정을 점으로 상시 표시하는 것이 관례 — [Boghog's bullet hell shmup 101](https://shmups.wiki/library/Boghog%27s_bullet_hell_shmup_101), [Shmups Wiki Glossary](https://shmups.wiki/library/Help:Glossary)

**로그라이트 카드 추첨 구조**

- Vampire Survivors — 아이템별 rarity 값이 곧 가중치, 풀 전체 가중치 합으로 확률 산출, 레벨업당 3~4장 중복 없이 제시 — [Vampire Survivors Wiki](https://vampire.survivors.wiki/w/Level_up)

**역사 고증**

- 조총 — 살상 거리 40~50m, 유효 타격 거리 70~80m, 재장전 30~45초 — [나무위키 조총](https://namu.wiki/w/%EC%A1%B0%EC%B4%9D), [위키백과 조총](https://ko.wikipedia.org/wiki/%EC%A1%B0%EC%B4%9D)
- 조선 화포 — 현자포 사거리 2,000보, 황자포 1,900보 — [우리역사넷 16~17세기 무기 개발](https://contents.history.go.kr/front/km/print.do?levelId=km_014_0060_0020_0010_0010)
- 판옥선 — 2층 갑판 구조, 1층 노, 2층 장대, 갑판 둘레 방패와 화포 — [나무위키 판옥선](https://namu.wiki/w/%ED%8C%90%EC%98%A5%EC%84%A0)
