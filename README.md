# 환도 還刀

**나에게는 무기가 없다. 적이 쏜 것만이 내 칼이다.**

임진왜란을 배경으로 한 종스크롤 탄막 패리 액션. 플레이어에게는 공격 버튼이 없고,
적의 탄환을 패리로 튕겨낸 반사탄만이 유일한 데미지원이다.

PC 브라우저에서 실행된다. 설치할 것은 Node.js 하나이고, 게임 자체는 외부 라이브러리와
외부 에셋을 쓰지 않는다.

| | |
|---|---|
| 분량 | 5스테이지 · 보스 5기 · 업그레이드 카드 31종 · 한 판 약 7분 30초 |
| 플랫폼 | PC 브라우저 (Chrome · Firefox). 키보드 필요. 모바일·터치 미지원 |
| 만든 계기 | NHN NAN 2026 해커톤 사전 과제 |
| 런타임 의존성 | 0개 |
| 외부 에셋 | 0개 — 빌드에 이미지·음원·폰트 파일이 없다. 도형과 Web Audio 합성으로 전부 만든다 |

> 게임 소개서(A4 7쪽 PDF)는 [`docs/submit/게임_소개서.pdf`](docs/submit/게임_소개서.pdf)에 있다.
> 개요·플레이 방법·실행 방법을 화면과 함께 정리한 문서다.

## 이 게임은 무엇인가

위에서 적이 내려오고 탄환이 쏟아지는 종스크롤 슈팅의 화면이지만, 쏘는 버튼이 없다.

패리 버튼을 누르면 플레이어 주위에 원이 잠깐 열린다. 그 안에 들어온 적 탄환은 소유권이
뒤집혀 **반사탄**이 되고, 튕겨나간 방향에 있는 적에게 피해를 준다. 적을 죽이는 방법은
이것뿐이다. 그래서 적이 쏘지 않으면 이길 수 없고, 탄막이 짙어질수록 쓸 수 있는 탄약이 많아진다.

규칙 세 개가 이 게임의 전부다.

1. **몸 위치가 조준이다.** 탄환을 몸 정면으로 받으면 쏜 적에게 그대로 되돌아가고,
   가장자리로 스치게 받으면 크게 꺾여 옆으로 튄다.
2. **탄환 중심이 몸에 가까울 때 누를수록 좋은 등급이 나온다.** 등급이 높으면 반사탄의
   데미지와 속도가 함께 오른다. 늦으면 등급이 아니라 피격이다.
3. **반사탄은 나에게도 유효하다.** 되돌린 탄을 따라가면 내가 맞는다.

빈 패리에는 무적이 붙지 않는다. 탄환이 없는 자리에서 버튼을 난사해도 아무것도 얻지 못한다.

## 플레이 방법

### 조작

전투 중 쓰는 키는 이동과 패리 둘뿐이다.

| 동작 | 키보드 | 마우스 |
|---|---|---|
| 이동 | `WASD` 또는 방향키 | — |
| 패리 | `Space` 또는 `J` | 좌클릭 |
| 보유 카드 보기 | `Tab` (누르고 있는 동안. 게임은 멈추지 않는다) | — |
| 음소거 | `M` | — |
| 일시정지 | `Esc` | — |

카드 선택 화면

| 동작 | 입력 |
|---|---|
| 카드 이동 | `←` `→` 또는 `A` `D`, 마우스 올리기 |
| 확정 | `Enter` · `Space` · 클릭 (두 번째 입력이 확정이다) |
| 다시 뽑기 | `R` — 한 판에 한 번만 |
| 보유 카드 보기 | `Tab` |

타이틀·일시정지·결과 화면

| 동작 | 입력 |
|---|---|
| 시작 | `Enter` · `Space` · 클릭 |
| 메뉴 이동 | `↑` `↓` 또는 `W` `S` |
| 실행 | `Enter` · `Space` · 클릭 |

키 리매핑은 없다. 이동과 패리에 각각 대체 입력이 이미 두 개씩 있다.

### 패리 등급

패리가 성립한 순간, 탄환 중심과 플레이어 중심 사이 거리로 등급이 갈린다.
거리 단위 u는 화면 해상도와 무관한 게임 내부 좌표이며, 플레이필드가 1080u × 1920u다.

| 등급 | 거리 | 반사 데미지 | 반사 속도 | 점수 |
|---|---|---|---|---|
| NOT BAD | 48u 초과 ~ 120u | ×1.0 | ×1.3 | 50 |
| GOOD | 28u 초과 ~ 48u | ×2.0 | ×1.8 | 150 |
| GREAT | 28u 이하 | ×3.5 | ×2.6 | 400 |

패리 원의 반경은 120u, 열려 있는 시간은 0.15초, 쿨다운은 0.24초다.
플레이어의 피격 판정은 반경 20u 코어 한 점이고 화면에 항상 보인다. 스프라이트 전체가
아니라 그 점만 맞으면 피격이므로, 큰 탄환은 몸으로 받아내는 감각이 되고 작고 빠른 탄환은
스쳐 지나가기 직전에 쳐내는 감각이 된다.

점수에는 콤보 배수가 곱해진다. 배수는 콤보 10마다 0.1씩 올라 최대 ×3.0이고,
마지막 패리 후 3초가 지나거나 피격당하면 콤보가 0으로 돌아간다.

### 한 판의 흐름

```
타이틀 → 스테이지 1 → 클리어 → 카드 1장 선택 → 스테이지 2 → … → 스테이지 5 → 결과
```

| # | 스테이지 | 길이 | 배우는 것 |
|---|---|---|---|
| 1 | 부산진 새벽 | 70초 | 패리 입력, 등급, 정면으로 받으면 되돌아간다 |
| 2 | 동래성 성곽 | 85초 | 방패병 — 정면이 막히므로 각도를 튼다 |
| 3 | 한산도 앞바다 | 90초 | 저속 대형 함포탄. 고등급 반사 한 발이 여러 기를 정리한다 |
| 4 | 행주산성 야전 | 95초 | 패리로 지울 수 없는 화염 장판. 공간을 관리한다 |
| 5 | 노량 밤바다 | 110초 | 앞의 넷을 동시에 |

각 스테이지 끝에 보스가 있고, 보스는 HP 구간마다 패턴이 바뀐다.
스테이지 1~4를 클리어하면 카드 3장 중 1장을 고른다. 총 4번 고르고, 31종 중에서 나온다.
카드는 반사탄의 데미지·개수·관통·유도 같은 것을 바꾸며 겹쳐 쌓인다.

라이프는 5로 시작해 5스테이지 전체를 관통한다. 스테이지를 클리어해도 회복되지 않고,
회복 수단은 카드뿐이다. 라이프가 0이 되면 스테이지 1부터 다시 시작하며 카드는 전부 사라진다.
중간 저장은 없다.

패리 불가 공격이 셋 있다. 화염 장판, 관통 대창, 적 본체다. 이 셋은 회피만이 답이며,
그래서 이 셋에만 예고 도형이 붙는다. **예고 도형이 보이면 피하고, 안 보이면 받아친다.**

## 실행 방법

### 필요한 것

| | 요구 사항 | 확인하는 방법 |
|---|---|---|
| Node.js | **20.19 이상** 또는 **22.12 이상** (22 LTS 권장) | `node -v` |
| npm | Node.js를 설치하면 함께 깔린다 | `npm -v` |
| 브라우저 | Chrome 또는 Firefox 최신 버전 | — |
| 입력 장치 | 키보드. 모바일·태블릿에서는 안내 화면만 나온다 | — |
| 디스크 | 약 90 MB (`npm install`이 받는 개발 도구 75 MB 포함) | — |

Node.js가 없으면 [nodejs.org](https://nodejs.org/)에서 LTS 버전을 받아 설치한다.
설치 후 터미널을 새로 열고 `node -v`를 실행해 `v22.x` 같은 숫자가 나오면 준비가 끝났다.

인터넷은 처음 `npm install`을 할 때만 필요하다. 그 뒤로는 오프라인에서 돌아간다.

### 처음부터 끝까지

터미널에서 이 저장소 폴더로 들어간 뒤 순서대로 실행한다.

```bash
npm install     # 1. 개발 도구를 받는다. 최초 1회, 1~2분
npm run dev     # 2. 개발 서버를 띄운다
```

두 번째 명령이 아래처럼 주소를 찍는다.

```
  VITE v7.3.6  ready in 143 ms

  ➜  Local:   http://localhost:5173/
```

그 주소를 브라우저 주소창에 붙여 넣으면 타이틀 화면이 뜬다. `Space`를 누르면 시작한다.
서버를 끌 때는 터미널에서 `Ctrl + C`를 누른다.

### 파일 하나로 만들기

```bash
npm run build
```

`dist/index.html` 한 장이 나온다. 약 240 kB이고, 이 안에 코드와 그림이 전부 들어 있다.
**이 파일은 서버 없이 더블클릭해서 열어도 돌아간다.** 다른 사람에게 게임을 넘길 때 이 파일
하나만 보내면 된다.

빌드한 결과를 서버로 확인하려면 `npm run preview`를 쓴다.

### 명령 요약

| 명령 | 하는 일 |
|---|---|
| `npm install` | 개발 도구 설치. 최초 1회 |
| `npm run dev` | 개발 서버. 코드를 고치면 브라우저가 새로 그린다 |
| `npm run build` | `dist/index.html` 한 장 생성 |
| `npm run preview` | 빌드 결과를 서버로 확인 |
| `npm test` | 단위 테스트 511건 |
| `npm run typecheck` | TypeScript 타입 검사 |
| `npm run lint` | ESLint. 계층 의존 규칙 검사를 포함한다 |
| `npm run balance` | 헤드리스 밸런스 시뮬레이션 리포트 (아래 참조) |

## 잘 안 될 때

| 증상 | 원인과 조치 |
|---|---|
| `node: command not found` | Node.js가 없거나 터미널이 옛 환경을 들고 있다. 설치한 뒤 터미널을 새로 연다 |
| `npm install`이 실패한다 | Node 버전을 먼저 확인한다. `node -v`가 20.19 미만이면 이 프로젝트의 빌드 도구가 거부한다 |
| `Port 5173 is already in use` | 다른 프로그램이 그 포트를 쓰고 있다. `npm run dev -- --port 5200` 처럼 다른 번호를 준다 |
| 화면이 검다 | 브라우저를 새로 고친다. 그래도 검으면 개발자 도구 콘솔(F12)의 첫 줄을 확인한다 |
| 「PC 브라우저에서 열어 주세요」만 뜬다 | 정밀 포인터를 못 찾은 경우다. 그 화면에서 아무 키나 누르면 판정이 뒤집히고 게임이 시작된다 |
| 글꼴이 다르게 보인다 | 게임은 글꼴을 이름으로만 요청한다. 시스템에 Gowun Batang·IBM Plex가 없으면 대체 글꼴로 그리며 배치는 유지된다 |
| 소리가 안 난다 | 브라우저 정책상 첫 입력 전에는 소리가 나지 않는다. `M`으로 음소거 상태를 확인한다 |

## 빨리 후반부를 보고 싶을 때

한 판을 완주하면 7분 30초가 걸린다. 그만큼 앉아 있기 어려우면 치트 메뉴를 쓴다.

`Shift + F9` — 타이틀·일시정지·카드 선택 화면에서 열린다. 전투 중에는 열리지 않으니
`Esc`로 멈춘 뒤 누른다.

메뉴에서 스테이지 1~5, 진입 지점(스테이지 시작 / 웨이브 / 보스 직전), 라이프, 카드 31종을
직접 지정할 수 있다. 스테이지 5 · 보스 직전으로 들어가면 최종 보스를 바로 볼 수 있다.

치트 메뉴를 한 번이라도 연 판은 **오염된 런**으로 표시되고 HUD와 결과 화면에 그 사실이 남는다.
지운 것이 아니라 의도한 것이다. 실측 데이터에 치트 플레이가 섞이지 않게 하려고 판정을 한쪽으로만
틀리게 만들어 두었다.

## 저장소 구조

```
src/

  core/       루프, 고정 스텝 시계, 입력, 난수, 스윕 충돌
  sim/        게임 규칙. 패리 판정, 반사, 웨이브, 보스, 카드 효과
  render/     Canvas 2D 렌더러. 스프라이트를 미리 굽고 매 프레임 합성한다
  screens/    타이틀·전투·카드 선택·일시정지·결과 화면과 전이
  audio/      Web Audio 절차 합성. 음원 파일 0개
  boot/       캔버스 준비, 플랫폼 판정, 스프라이트 굽기
  dev/        치트 메뉴, 헤드리스 봇, 밸런스 리포트, 입력 기록·재생
tests/        단위 테스트 511건 + 시각 회귀 + 성능
docs/
  spec/       기능 명세서. 규칙과 수치의 원본
  sample_image/  인게임 화면 15장. 스펙을 실행해서 그린 그림이다
  plan/       구현 기획안 13종
  work_log/   실제로 만든 것과 남은 것의 기록
  submit/     제출용 게임 소개서 (HTML · PDF)
  research/   주제 선정 전에 한 조사
  ideation/   후보 아이디어와 탈락 기록
```

소스 138파일, 약 33,000줄. TypeScript strict 모드이고 게임 프레임워크를 쓰지 않는다.
시뮬레이션은 1/120초 고정 스텝으로 돌고 화면은 그 사이를 보간한다. 같은 시드에 같은 입력을
넣으면 같은 결과가 나오며, 타이틀 화면의 어트랙트 루프가 그 성질로 실제 플레이를 재생한다.

## 검증

```bash
npm run typecheck && npm test && npm run lint
```

세 개 모두 통과한다. 테스트는 511건 중 510건 통과, 1건 건너뜀이다.

`npm run balance`는 성격이 다르다. 헤드리스 봇으로 여러 시드를 완주시켜 하드 규칙 위반과
난이도 목표 달성을 재는 내부 리포트이고, **현재 판정 실패 7건으로 종료 코드 1을 낸다.**
빌드가 깨진 것이 아니다. 봇이 사람보다 훨씬 약해서 보스 격파 시간 같은 축을 측정할 수 없는
것이 실패의 대부분이고, 남은 원인은 전부 밝혀져
[`docs/work_log/05_난이도_조정.md`](docs/work_log/05_난이도_조정.md)에 적혀 있다.
그래서 `npm run verify`(타입 검사 + 테스트 + 밸런스)도 지금은 1로 끝난다.

`src/config/`의 수치는 명세서 §14의 초기값이 아니다. 직접 플레이하며 축마다 따로 세운
값이며 차이표가 같은 문서에 있다.

## 에셋과 라이선스

**게임 빌드(`dist/index.html`)에는 이미지 파일, 음원 파일, 폰트 파일이 하나도 들어가지 않는다.**

- **그림** — 전부 Canvas 2D 도형이다. 적과 보스 30종의 스프라이트는 실행 시점에 도형으로
  그려 캐시에 굽는다.
- **소리** — Web Audio 노드로 합성한다. 배경음도 절차 생성이다.
- **글꼴** — Gowun Batang · IBM Plex Sans KR · IBM Plex Mono를 이름으로만 요청한다.
  시스템에 없으면 대체 글꼴로 그리며 레이아웃은 유지된다.
- **런타임 의존성** — 없다. `package.json`의 의존성은 전부 개발 도구
  (Vite, Vitest, TypeScript, ESLint)이고 빌드 결과물에 들어가지 않는다.

저장소 안에서 외부 파일을 가진 곳은 `docs/submit/fonts/` 하나다. 게임 소개서 PDF를 오프라인에서
같은 모습으로 다시 만들기 위한 웹폰트 하위 집합이고, 세 글꼴 모두 SIL Open Font License 1.1이다.
게임은 이 파일들을 읽지 않는다.

임진왜란은 실제 역사이고 등장하는 함선·무기 이름은 사료에 있는 일반 명사다.
특정 작품이나 IP를 참조하지 않았다.
