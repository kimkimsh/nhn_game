# 밸런스 데이터

이 폴더의 파일은 전부 숫자 표다. 로직은 없다.

- 값을 고치고 저장하면 `npm run dev`가 브라우저를 **새로고침한다.** HMR이 아니다 — 이 폴더에 로직이 없어서
  `import.meta.hot.accept` 경계를 선언할 수 있는 모듈이 없기 때문이다(`docs/plan/12_통합_계약.md` §8-8). 그래서 런이 타이틀로 돌아간다.
  `dev/capture.ts`가 마지막 치트 진입 지점을 `sessionStorage`에 적어 두므로, 새로고침 뒤 같은 자리에서 다시 시작한다.
- 타입 에러가 나면 그 자리에 잘못된 ID나 빠진 필드가 있다는 뜻이다.
- 스펙 절 번호(§)가 붙은 값은 `docs/spec/기능_명세서.md`의 해당 절이 근거다.
  그 절의 이유부터 반박하지 않고 바꾸면 다른 곳이 깨진다.

## 이걸 고치려면 어디를 열까

| 고치고 싶은 것 | 파일 |
|---|---|
| 게임이 너무 어렵다 / 쉽다 | `difficulty.ts` (스테이지별 배율. 보스 HP는 여기 없다 — `docs/plan/12_통합_계약.md` §5) |
| 패리가 너무 후하다 / 빡빡하다 | `parry.ts` (반경, 활성 시간, 등급 밴드) |
| 특정 잡몹이 너무 세다 | `enemies.ts` (해당 ID 줄의 `hp`) |
| 특정 보스가 너무 오래 산다 | `bosses/boss-N-*.ts` (`hp`) |
| 보스 패턴을 바꾸고 싶다 | `bosses/boss-N-*.ts` (페이즈별 패턴 배열) |
| 어느 웨이브에 뭐가 나오는지 | `stages/stage-N-*.ts` |
| 탄이 너무 빠르다 / 느리다 | `bullets.ts` (기본 속도) 또는 `difficulty.ts` (스테이지 배율) |
| 카드 효과 수치 | `cards/{normal,rare,epic}.ts` |
| 카드가 잘 안 나온다 | `cards/draw-table.ts` (회차별 등급 가중치) |
| 히트스톱이 짧다 / 길다 | `parry.ts` — 등급 밴드의 `hitstopSec`가 단일 소스다(`docs/plan/12_통합_계약.md` §5). 피격 히트스톱만 `feel.ts`의 `playerHit`이고, `player.ts`는 이 값을 갖지 않는다(§10 E-13) |
| 흔들림·파티클이 약하다 / 과하다 | `feel.ts` (셰이크 티어·파티클 강도) |
| 소리가 마음에 안 든다 | `audio.ts` (신스 파라미터) |
| 색을 바꾸고 싶다 | `palette.ts` — **단, 색 하나에 규칙 하나다. 규칙 없는 색은 추가하지 않는다.** 목업의 `tokens.css`는 이식하지 않으므로 이 파일이 유일한 색 소스다(`docs/plan/12_통합_계약.md` §3.2) |
| HUD 위치·크기 | `ui.ts` |
| 라이프 개수, 무적 시간 | `player.ts` |
| 점수 배분 | `scoring.ts` |
| 화면 전체 상한 (장판 6개, 잡몹 20기 등) | `playfield.ts` — **동시 적 탄환 상한만 여기가 아니라 `difficulty.ts`**의 스테이지별 칸이다. 그 값은 난이도 축 3이라 스테이지마다 다르다(`docs/plan/12_통합_계약.md` §10 E-13) |

## 이 폴더의 규칙 다섯 줄

1. **로직 없음.** `if`도 `for`도 계산식도 없다. 선언과 주석뿐이다.
2. **import는 두 개뿐.** 같은 폴더의 `ids.ts`와 `types.ts`.
3. **모든 값에 단위와 스펙 절 번호.** 시간은 초, 거리는 `u`, 속도는 `u/s`.
4. **`as const satisfies T`.** 값은 리터럴로 좁혀지고 형태는 타입이 검사한다.
5. **유도된 값은 저장하지 않고 식으로 적는다.** 같은 숫자가 두 곳에 살면 반드시 어긋난다.
   같은 파일 안의 값을 빼고 더하는 한 줄이 규칙 1의 유일한 예외다.

`tests/guards.test.ts`가 이 폴더를 훑어 파일 헤더 3줄과 값별 `§` 번호를 검사한다.

`types.ts`는 배럴이고 실제 정의는 `types-gameplay.ts` · `types-content.ts` · `types-cards.ts` ·
`types-feel.ts` · `types-ui.ts` · `types-audio.ts`에 나뉘어 있다. 값 파일은 이 여섯을 직접
import하지 않는다 — 언제나 `./types` 하나다.
